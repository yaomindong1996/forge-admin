# 一级导航多色图标

## 目标与边界

按用户要求同步改造社区版和 ForgePro 的一级菜单图标：统一 24px 网格和线宽，
使用按功能语义固定的双色描边、轻量填色，增强辨识度，不增加彩色背景块、图片请求或依赖。

- 仅显示层的一级导航启用 `forge-color:`，兼容原 `forge:` 配置；子菜单保留原图标。
- 所有布局共享同一渲染入口，折叠、悬停和选中不退回单色；深色模式使用对应亮色调色板。
- 普通 `ForgeSymbol`、插件卡片、关于系统继续保持现有主题色，不扩大多色范围。
- 此为用户明确要求的导航图标配色例外，文字、选中背景、工具图标仍遵循 DESIGN 的主题规范。
- 不改权限、菜单接口、路由、租户配置、数据库、版本号；保留已有未提交改动。
- 日常开发，版本保持 1.2.0，写入 Unreleased；本轮不提交、推送或部署。

## 验收与回滚

1. 每个一级符号包含两种语义色，未知名称安全回退；菜单映射幂等、子菜单不受影响。
2. 白色/深色导航及折叠菜单、悬停、选中可辨识，无裁切和外部图片请求。
3. 两个工程相关单测、ESLint、构建和浏览器预览完成，记录实际证据及跳过项。
4. 回退本轮前端文件即可恢复，无数据库和配置迁移。
