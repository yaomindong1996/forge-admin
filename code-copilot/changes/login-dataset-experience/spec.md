# 登录与数据集体验整理

## 需求与边界
- 以用户提供的 React 登录视觉为参考：桌面蓝色品牌轮播 + 紧凑登录表单，移动端只保留登录与支持入口。
- 重新生成安全权限、低代码搭建、流程协作三张独立插画。禁止复制示例中的模拟验证码、模拟登录和未经验证的性能数字。
- 登录页“遇到问题？请联系系统管理员”打开社区二维码弹窗，包含已配置的群二维码及现有维护者/维护支持二维码。
- 首页社区支持前移到欢迎区后，用紧凑入口打开同一个弹窗。
- 数据集采用公共主从工作区，简化分类、筛选、表格及编辑步骤，保持真实接口、字典、发布/下架、访问权限和行级权限协议不变。

## 实现约束
- 保留登录、租户选择、密码找回、图形/滑块/短信/群验证码及第三方登录行为。
- 数据集现有 editSchema 仅使用 datasetEditor 插槽；删除不再引用的旧插槽，按配置域拆分编辑面板，共享上下文使用 Pinia。
- 不改变业务状态、权限或数据库；所有发布、删除与保存仍经过原有处理函数。
- 使用 Naive UI 弹窗/图片预览，避免另建弹出层。
- 只提交本次文件，保留用户 .DS_Store 变更；不自动推送。

## 验收
- 三张轮播图不同且可切换；桌面/手机无横向溢出，输入与按钮对齐。
- 登录页与首页支持入口均可打开、关闭二维码弹窗，配置群图优先使用后端配置。
- 数据集分类/筛选联动不变，每行至多两个直接操作，其余进入更多。
- 数据集四个编辑步骤完整，只读、SQL预览、字段配置与权限保存协议不变；修改的 SFC 不超过 1000 行。
- 执行增量单测、定向 lint、生产构建及浏览器视觉检查；无法连接测试服务的项目如实记录。

## 本轮修正：轮播指示器可见性

- 左侧保持固定视口高度，右侧登录表单独立滚动，避免表单将整行撑高后轮播控件落到首屏之外。
- 将箭头与三个指示器移到轮播裁切区域之外的独立控制行，当前项使用明显白色短条。
- 控制行与 Naive UI 轮播共用 currentIndex，自动轮播、箭头和指示器切换同步。
- 保留减少动态效果、移动端隐藏品牌区及认证逻辑，不改动数据集等无关页面。
