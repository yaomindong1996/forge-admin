# 增量验证计划

本变更新建验证基线，复用现有 DataScopeFailClosedTest 与前端 Vitest 配置。

## P0

- 状态 DTO 校验、管理员访问边界、仅更新 enabled、旧状态并发条件。
- 事务提交后刷新、回滚不刷新、刷新失败如实反馈。
- 已禁用规则在严格模式下跳过过滤，未配置规则仍拒绝。
- 跨实例通知、本机跳过、消息不循环、重新订阅补载。
- 列表开关取消不保存、成功后更新、失败恢复、请求期间禁止重复提交。

## P1

- 手动刷新权限反馈与列表刷新区分。
- 编辑技术配置可展开，新增默认展开，字段/字典回显正确。
- 前端定向 ESLint、Vitest、pnpm build；后端使用 JDK 17、-Penable-tests 跑目标测试，Admin 聚合 package 跳过测试。
- 使用独立本地预览和模拟 API 的真实组件验证亮色、暗色、窄屏及确认对话框；截图存放当前变更目录。真实数据库接口验证视本地服务可用性记录，不启动会自动执行 Flyway 的真实 Admin 服务来做纯 UI 验证。
