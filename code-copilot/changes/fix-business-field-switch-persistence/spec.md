# 业务对象字段切换持久化修复
> status: apply
> created: 2026-08-03
> complexity: simple

## 1. 问题

业务对象设计器的数据结构面板中，字段类型等属性只保存在属性子组件的局部表单。修改字段后切换左侧设计面板时，外层仅展示通用“未保存变更”提示；确认继续后属性组件被卸载，局部字段值丢失，再次进入时恢复为服务端旧值。

字段属性的保存操作位于属性栏底部。当前对象设计器存在外层滚动和属性栏内层滚动，在部分视口高度下底部操作区会离开可视范围。

## 2. 修复范围

- 单独跟踪当前字段属性是否存在未保存修改。
- 从数据结构切换到其他面板时，先保存当前字段；保存成功后继续切换，保存失败或校验不通过时保持当前面板。
- 字段自动保存期间展示统一保存状态并阻止重复切换。
- 将“还原、保存字段”操作移到字段属性栏顶部可见区域。
- 其他表单、列表、关系等面板继续使用原有未保存确认逻辑。

## 3. 非目标

- 不修改字段保存 API、数据库同步和发布规则。
- 不改变数据结构中新增、删除、排序字段的交互。
- 不重构其他设计面板的草稿协议。

## 4. 验收标准

- 修改字段类型后直接切换面板，不再出现会丢失字段局部值的通用确认。
- 字段保存成功后才完成面板切换，重新进入数据结构时字段类型保持新值。
- 字段校验失败或接口失败时不切换面板。
- 字段保存按钮在属性栏顶部持续可见，窄屏抽屉内也可操作。

## 5. HARD-GATE

- 确认状态：已确认
- 确认依据：用户明确要求修复字段切换回退和保存按钮不可见问题。
- 确认范围：仅本 Spec 所列前端状态协调、操作区布局和针对性测试。
