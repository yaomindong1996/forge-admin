# 验证范围

| 验证面 | 预期结果 |
| --- | --- |
| Skill 路由 | 两个独立 Skill 可发现，入口与引用有效，代码型 CRUD 可按需加载 |
| Flyway | 基线库可增量升级，空库可迁移到同一版本，重复运行无待执行 SQL，历史校验通过 |
| 采购列表 | 列表权限独立，返回记录与分页总数只包含当前组织的有效采购单 |
| 采购导出 | 解析 Excel 行并与列表范围比对，验证筛选、其他组织和其他租户同组织编号 |
| 权限拒绝 | 匿名、仅列表、仅按钮以及仅 API 的请求均不返回附件，取得授权的普通账号导出成功 |
| 方法与绑定 | 非 POST 请求不可导出。相同角色标识出现在其他租户时不取得本租户新增的授权 |

测试使用本地隔离库和测试登录入口。数据库、资源匹配、SQL 拦截和文件写入使用实际组件。
