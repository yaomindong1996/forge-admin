# Forge 权限与迁移 Skill

为菜单、按钮、API 授权及 Flyway 迁移提供独立开发指引，并接入仓库的 Skill 路由、`/test` 与 `/review`。采购列表导出作为可重复验证样例。

## 验收

- 新建菜单或接口时能定位 `sys_resource` 类型、客户端、父菜单、角色关联、服务端守卫及数据范围配置。
- 增量 SQL 指引涵盖三库版本分配、旧库升级、空库初始化、历史校验、权限种子和故障排查。
- `/test` 分层执行并记录证据。`/review` 同时检查需求和实现，对权限、行范围及迁移给出可定位的发现。
- 普通采购角色能导出当前授权组织内符合筛选条件的采购单。仅有列表权限、仅有按钮或仅有 API 权限的身份无法生成文件。组织、租户和逻辑删除边界在工作簿中验证。

## 变更与回退

采购导出使用测试专用路由、账号和 H2 数据库。测试迁移只写入临时库。回退取回本次 Skill、命令、测试文件的改动即可。
