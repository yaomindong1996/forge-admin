# 插件中心、一级导航与关于系统视觉统一

状态：已提交、推送 main 并部署生产 Admin UI；发行版本保持 1.2.0。
用户于 2026-10-10 要求直接优化上述三个区域。

## 范围与设计

- 插件中心增加小幅透明底模块组装插画，沿用系统主色、灰阶和 Naive UI。
  卡片改为统一的能力模块：语义图标、名称/标识、真实来源、简介、能力提示、版本和两项操作。
  不增加营销横幅、虚假统计、在线安装或后台管理入口；保持自适应网格，不固定窄列造成右侧留白。
- 一级导航使用统一 24px 网格、同线宽、currentColor 的矢量符号，随所在布局的主题颜色显示。
  在导航数据适配处替换展示图标，覆盖侧栏、折叠栏及共用数据的顶部导航；不改菜单 ID、权限、路由、排序。
  子菜单保留配置；未知一级业务菜单提供同风格兜底；不修改数据库原始 icon。
  旧图片同时存在于通用图标选择器，无法证明无数据库引用，不删除公共图片资源；一级导航不再使用它们。
- 关于系统增加模块标识、主版本信息区、分组图标和清晰的构建信息卡片。
  保持当前 Pinia/API、前后端分别展示、未知/错误/不一致提示、刷新、复制与纯文本说明。
- 插画用内置图像生成；图标为仓库原生 SVG 路径（不引入新依赖、不用模糊位图做小尺寸图标）。
  浅色、深色和窄屏均可用，装饰对辅助技术隐藏。

## 边界与回滚

开发范围仅 PC 前端与变更文档，不执行迁移、不改 H5 或 website。
本轮属于日常开发，读取当前 revision=1.2.0，保持不升版，记录 CHANGELOG Unreleased。
用户追加“提交并部署”后，提交/推送本轮改动到 main，并仅部署 Admin UI。
保留已有 .DS_Store 和其它任务的文档改动；不升版、不创建标签、不重启后端。
部署前备份现有 UI，核对上传摘要并保留旧哈希资源；失败时恢复本轮备份，不修改业务数据。

## 验收

菜单层级/链接/权限不变，一级图标风格一致且无图片请求；插件详情与安装说明可达，
未知插件不冒用内置资料；关于系统诊断信息与操作保持正确。目标测试、lint、构建通过，
用真实组件的隔离预览检查明暗主题/窄屏，模拟数据不等同真实后端验收。
