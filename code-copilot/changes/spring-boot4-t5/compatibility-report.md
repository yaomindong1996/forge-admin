## 使用与升级注意

1. 页面/工具卡查询结果仍须既有 ai:image:generate，历史仍须 ai:image:page；
   后端还验证可信用户/租户所有者。普通 Agent 用户不自动获得图片/模型/MCP 权限。
2. 5 分钟暂停只是停止当前查询，不代表后台失败或已取消；“重新查询”不会重新提交。
   提交连接未确认时不自动重发，需查记录/联系管理员，不能假设后台没有执行。
3. 客户端不使用工具返回任意 endpoint，任务/文件 ID 经过严格 Long 标识验证；
   成功但缺少有效文件、未知状态或错任务响应会暂停，不伪造成功图片。
4. V1.0.218 只在已安装且未删除的图片状态字典下写默认租户 1，NOT EXISTS 防重复。
   已在 H2 验证，但真实 MySQL/Flyway 由用户后续执行；不修改历史 SQL、不 repair。
5. 仍为 1.2.0 日常验证版本、Unreleased；Boot 4 升级正式发版版本需要另行确认。
   本地有未提交改动，四服务与 PC 产物不是已提交发布版本，未部署。

## 仍存在的独立边界

- 真实 Redis Lua/Cluster/故障切换、MySQL/Flowable 表升级、真实供应商/COS 与 PC/H5 业务 E2E 未验证。
- 旁路 SSE 仍需粘性路由，没有跨节点总线或重放保证；不能凭本轮直接流测试宣称无粘性部署可用。
- 图像队列没有持久化崩溃重试；lease 失效/节点崩溃的旧消息数据库清理与写入 fencing 未实现。
- lease 与确认/Token 原子消费不等于跨系统 exactly-once，已经发出的业务副作用仍需业务动作幂等。
- 既有 Agent MCP/capability 注册桥与客户端委托按用户此前选择保留边界，不伪造已支持。
