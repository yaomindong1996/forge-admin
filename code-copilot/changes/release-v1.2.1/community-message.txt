Forge Admin V1.2.1｜本周更新整理（10.12—10.17）

这周主要把低代码搭建、流程处理和日常使用体验又打磨了一轮，整理了几个大家能直接感受到的变化：

1. 低代码设计更顺了
完善自由布局 CRUD、表单属性和字段映射，打通草稿预览到设置、发布的衔接，减少设计页重复加载。修复字段编码重复、自动编号发布丢失等问题。

2. 流程审批更清楚了
待办、已办、我发起的、抄送菜单增加数量提醒；修复流程超时处理后的状态、节点配置保存和抄送操作等问题。

3. 打印设计更省心了
新组件自动避让已有组件，不再直接叠在一起；保留当前自由画布，修复打印来源扩展字段影响发布快照的问题。

4. 左下角加了「最近下载」
接入真实下载记录，支持分页、实际接收进度和失败重试。清空只隐藏当前浏览器已加载的记录，不删除后台审计或文件。

5. 界面和移动端继续打磨
统一深色模式，优化插件中心、流程卡片、数据集和表单布局；修复菜单高亮异常、表格撑宽，以及 H5 登录跳转循环。

6. 底座和 AI 兼容升级
代码底座升级至 Spring Boot 4.1.1、Flowable 8.0.0、Spring AI 2.0.1，完善 OpenAI/通义 Agent 工具调用、异步图像处理和会话并发保护。

7. 权限与初始化加固
加强消息、文件、配置等访问控制，保护内置管理员/角色/默认租户；修复纯净版基础数据缺失及流程引擎表冲突问题。

本周 main 共整理 36 条非合并提交，V1.2.1 正在做发布准备。
注意：这次包含底座大版本升级，不能按无感小补丁直接覆盖。请先备份数据库、核对插件兼容并在测试环境演练；正式标签、安装包及环境验收完成后再安排生产更新。
