## 1. 目标与实现边界

实现 Forge 自有打印能力，与现有 Vue 3/Naive UI/Pinia、业务对象、低代码表单、应用发布和 Flowable 流程衔接。设计器、模板协议与排版代码由本项目维护。

- hiprint 仅作为功能研究参考，不引入其 npm 包，不复制 `hiprint.bundle.js`，不要求模板格式兼容。
- 复用已有二维码、条形码基础依赖时记录用途与来源；不因“自主实现”推导第三方代码许可结论。
- 首期以单条已保存业务单据打印为完整闭环；输出为同一 HTML/SVG 分页结果的预览和浏览器打印。
- 应用/流程业务状态保持原语义；打印不提交表单、不发起/完成/撤回审批、不写业务字段。
- 本次不改变现有设计预览打印行为，不整体替换低代码录入布局。

## 3. 首期用户路径

### 3.1 设计与发布

应用工作台 → 选择表单/业务对象 → 打印模板 → 新建或复制 → 拖拽字段/明细 → 合成数据预览 → 保存草稿 → 校验 → 发布模板 → 应用发布引用固定模板版本。

普通用户使用“表单、字段、明细、审批记录”语言；objectCode、providerKey、schemaVersion 放在内部协议或高级设置中。模板编码自动生成。

### 3.2 业务使用

已发布应用的列表行/详情 → 打印 → 选择可用模板（唯一时直接进入预览）→ 服务端读取授权记录 → 完成字体/资源加载与分页 → 预览 → 浏览器打印。

未保存记录、未发布模板、字段失效、权限不足或分页失败时不给出成功状态。首期不将未保存编辑内容自动写回业务记录。

### 3.3 流程使用

待办、已办、我发起的业务详情 → 打印 → 服务端解析当前任务/实例与业务记录关联 → 应用/节点模板选择规则 → 权限过滤 → 附审批记录/签名 → 预览与打印。

首期支持当前主子表低代码业务及现有采购代码表单示例。其它代码业务通过明确的打印数据提供方接入，不能对任意 formUrl 页面直接截图宣称完成集成。

### 4.1 首期分页规则

- 首期只有一个纸张配置；页眉/页脚可选择每页显示，页码由第二遍排版填充。
- 页正文按有序 section 排版。固定区块内部使用绝对坐标；流式文本和表格按实际高度排列。用户拖动区块改变顺序，拖动固定区块内部元素改变坐标。
- 表格支持固定多行表头与表头横向合并；动态数据区首期不支持跨行/跨页合并、嵌套表格。
- 文本按真实浏览器测量换行并允许按行续页；表格明细按整行换页，空表有明确空数据行为。
- 表尾合计使用平台计算/格式化后的值，不在模板里执行任意脚本；合计仅在表尾显示。
- 单行/固定区块高于单页可用区域时阻止打印，定位问题区块并提示缩小/调整；不能无限分页或直接截断。
- 建议首期保护上限：每次单据总明细 500 行、输出 50 页、资源等待 10 秒；均属于安全上限，不是性能承诺。超过时明确失败。基准验证后如需调整，先更新本 Spec。

### 4.2 显示与资源

- 数值 0、布尔 false、空字符串、null 的显示策略必须明确，不能用 truthy 判断统一丢失。
- 金额使用既有“分”数据语义，输出层定点格式化，避免浮点金额运算；长整型 ID 全程按字符串传输。
- 模板支持白名单格式化器，不提供任意 JS、SQL、HTML 脚本或任意远程 URL 取数功能。
- 图片/签名以 fileId 受控读取；允许的内联资源格式有大小限制，不把长期 token 写进模板或打印 HTML。
- 首期认证资源失败、缺字字体或超时应阻止正式输出并提示，不用空白图片代替签名。
- 页面外壳适配明暗主题；纸张输出使用明确的白底打印样式。

### 4.3 M2 阶段保存边界

- M2 提供本地草稿及可注入的异步保存适配器；默认入口明确显示“本地草稿”，浏览器只存模板协议，不存预览上下文。服务端资产保存/版本发布仍由 M3/T28 实现。
- 本地保存失败保留修改；保存期间继续编辑时仅将已提交的那份版本标为已保存，后续编辑仍保持未保存。新建、恢复、导入和离开有未保存保护。
- 编辑画布显示区块和字段占位；真实换行、图片和页数在复用 M1 的预览中计算。纸张样式保持白底，工作台跟随主题。

### 4.4 设计器视觉基线补强（2026-09-19 用户反馈）

- `vue-plugin-hiprint` 只作为交互和信息架构参考；本项目继续使用自有协议、Vue 3、Naive UI 和 Pinia，不复制其 bundle 或模板协议。
- 设计页必须让用户直接感知纸张尺寸和元素坐标：顶部/左侧显示毫米标尺，纸张显示 1mm 辅助网格与 5mm 主网格，页边距和页眉/页脚分界线可见。
- 顶部工具栏直接提供 A4/A5、横竖旋转、网格开关、缩放、撤销重做、预览和保存；左侧物料使用紧凑图标宫格，中央纸张与外部工作区形成清晰层级，右侧属性区保持固定工作台结构。
- 合成浏览器入口只用于无后端视觉验证。正式入口必须落在当前统一应用页面的“应用设置 → 打印模板”，并由应用中心“更多 → 打印模板”提供快捷入口；废弃工作台的 `section=printing` 和 `workspace.html` 均不得表述为正式业务入口。

### 4.5 设计工作台与预览收敛（2026-09-19 第二轮反馈）

- 顶部操作收敛为单行紧凑命令栏：高频编辑命令使用带提示和无障碍名称的图标按钮，纸张和缩放使用下拉选择，低频的新建、复制、恢复和协议导入导出进入“更多”菜单，保存保留明确主操作。
- 左侧区块行只显示名称与必要排序操作，复制、删除等低频操作进入行级菜单；左右面板可独立收起，窄窗口不再依赖固定 1080px 工作区和整页横向滚动。
- 定位线必须由拖动/缩放计算产生并参与吸附，候选包含纸张内容边界、其它元素的左中右/上中下与毫米网格；未发生吸附时不得常驻红色十字线。手势结束、取消、切换区块或加载模板时清除定位线。
- 预览使用独立文档查看工作台，提供适合宽度、缩放、页码与页数信息；每页显示在有层级的中性画布上，纸张尺寸和分页结果仍与正式打印共用同一布局树，不在预览层另做分页。

### 4.6 设计内容同源与基础能力补齐（2026-09-19 第三轮反馈）

- 设计画布不得把 `main.number`、`children.items.name` 等内部绑定路径当成纸面正文；绑定元素显示字段中文名对应的示例值，路径只在属性面板中用于配置。没有真实样本时，由字段目录生成不含业务数据的示例上下文，设计画布和模板预览必须消费同一份示例上下文并明确标注“字段示例数据”。
- 固定文本、页码、线框和椭圆在设计态直接复用正式输出渲染器；条码和二维码复用正式编码器。图片没有可读取样本时显示明确的设计占位，不伪装成已经加载的业务图片。流式文本和表格至少使用相同绑定值、格式化器、列样式和示例行，减少设计态与分页预览的视觉漂移。
- 左侧基础物料按用户意图提供标题、固定文本、图片、横线、竖线、矩形、椭圆、条码、二维码和页码预设；长文本和明细表格保留为可分页区块。预设可复用同一协议类型，但新增椭圆必须同时进入前后端协议白名单和共享兼容测试。
- 画布上方提供与当前选择相关的紧凑命令：全选、复制、粘贴、复制一份、置顶、置底和删除；仍支持键盘快捷键、框选、多选、六向对齐和等距分布。命令不得依赖右侧属性面板是否展开。
- 纸张预设补齐 A3、B4、B5；属性区补齐斜体、下划线、背景、边框和内边距等协议已有白名单能力。HTML、自定义 JavaScript、任意远程资源、静默客户端、服务端 PDF 和 hiprint JSON 继续不进入本次范围。

### 4.7 元素级编辑能力（2026-09-19 第四轮补齐）

- 固定区块元素支持以中心点旋转、水平镜像、垂直镜像和锁定；设计态和正式预览/打印使用相同 transform。旋转和镜像只改变视觉变换，不隐式改写毫米坐标、尺寸或分页占位。
- 锁定元素仍可选择和查看属性，但禁止拖动、缩放、键盘移动、对齐、层级变化和删除；解锁操作必须始终可达。复制锁定元素时，新副本默认解锁，避免产生无法继续编辑的副本。
- 画布支持元素/空白区域右键菜单，提供复制、粘贴、复制一份、旋转、镜像、层级、锁定/解锁、全选和删除；所有变更进入既有撤销历史，不建立第二套命令实现。
- 图片支持包含、覆盖、拉伸和缩小适配；条码支持协议已有 CODE128/CODE39/EAN13/EAN8/ITF14；页码支持当前页与当前页/总页数。边框支持实线、虚线、点线和圆角，继续受前后端白名单约束。

### 4.8 高级设计能力（2026-09-19 用户选择优先项 1/2/3/5）

- 新增可自由定位的空白表格元素。表格以受限行、列和单元格矩阵持久化，支持画布内选择/编辑内容、增删行列、矩形区域合并、拆分及逐单元格样式；所有单元格必须完整覆盖且不得重叠，禁止用 HTML 表格片段或脚本作为模板内容。
- 正文支持显式手动分页区块；设计画布按纸张正文高度和手动分页符展示多张独立纸张、页码、自动/手动分页提示及重复页眉页脚。设计分页是使用示例数据的可编辑估算，正式预览/打印仍以共享分页引擎的结果为准。
- 提供代码侧业务打印组件注册机制。业务模块只能注册受信任的组件工厂，展开为 Forge 原生元素或区块并通过现有协议校验后入模；模板 JSON 只保存展开后的标准协议，不保存 Vue 组件名、动态 import、HTML、函数或脚本。
- 提供打印校准与验收工具：生成带毫米标尺、边距、方向和纸张信息的校准页，检查当前浏览器打印基础能力并记录人工纸张/缩放/边距核对项。系统只能确认打印对话框已打开，物理尺寸和出纸结果必须由用户在目标浏览器与打印机上回填。
- 本阶段继续不实现任意 HTML/JavaScript、hiprint JSON 兼容、静默打印客户端、服务端 PDF 或批量打印队列。

### 4.9 并行分支 Flyway 版本冲突修复（2026-09-19 启动日志反馈）

- 目标数据库已执行流程分支的 V1.0.168–V1.0.170，打印分支独立开发时误用了同一组版本号，导致 Flyway 校验将已执行流程脚本与本地打印脚本视为 checksum 被篡改并阻止启动。
- 禁止用 `flyway repair` 把流程脚本 checksum 改成打印脚本，也禁止改写数据库历史记录。打印分支必须完整收录已执行流程脚本的原始文件和校验和，再把四份打印迁移顺延到 V1.0.171–V1.0.174。

### 4.12 设计器中间操作栏与拖拽手感（2026-09-20 对照 sv-print 反馈）

- 画布上方中间操作栏补齐高频编辑命令：撤销/重做、六向对齐、水平/垂直分散、固定间隙、同步宽高（min/avg/max）、层级四级、字号加大/减小、加粗/斜体/下划线、文字左/中/右对齐、文字色/背景色/边框色、锁定、克隆/复制/剪切/粘贴、删除、清空当前区块、缩放、纸张旋转与网格开关。
- 字号、加粗、斜体、下划线、对齐与颜色同时作用于选中元素、空白表格选中单元格和流式文本区块；右侧属性面板继续保留完整外观配置，中间栏只暴露高频入口。
- 选中框提供八向缩放锚点，支持从任意边/角反向拖动改位置与尺寸；命中区加大，悬停高亮。
- 水平方向仍限制在纸张内容区；垂直方向允许向下拖出当前固定区块并自动撑高该区块，避免“拖不动”的硬边界感。默认保留吸附；拖动/缩放时按住 Alt 关闭吸附；Ctrl/⌘ + / - / 0 可缩放画布。
- 页眉、页脚与固定区块共用同一套垂直自由拖拽：元素可向下拖出当前高度并自动撑高对应条带；吸附不再贴死条带底边。页眉/页脚增高时保留至少 20mm 正文区，避免把整页占满。
- 空白表格单元格属性补齐字重/斜体/下划线/边框色/内边距；线/矩形/椭圆在元素行为面板提供描边与填充快捷配置；文本类与图片/表格的右侧外观面板按元素类型分流，避免图形元素误出字体配置。
- 框选支持最小拖动阈值，避免单击误清空；框选过程显示“已选 N”计数，并支持 Shift/⌘/Ctrl 累加选择。
- 中间栏提供吸附开关与参考线开关：关闭吸附后拖动不再贴齐；开启参考线后常显纸张内容区边框与中心十字线。拖动时仍可按住 Alt 临时关闭吸附。
- 页眉/页脚空白区显示可编辑占位；高度为 0 时提供“点击展开为 12mm”；左侧结构树与纸张面板展示高度/重复策略，并可一键跳转编辑。
- 画布优先布局：左侧组件约 220px、右侧属性约 260px；关闭任一侧时用动态 grid，避免属性面板占满全屏。中间操作条加高可读。
- 空模板自动生成「自由画布」FIXED 层；组件可拖到纸张/画布并自由摆放撑高。页眉页脚支持展开与收起。
- 属性面板按折叠分组（位置/行为/绑定/外观/表格），减少一次堆叠。
- 多页模板在画布底部提供页码缩略导航，滚动视口时同步当前页高亮，点击可平滑跳转。
- 画布左下角提供可开关的「概览图」：缩略纸张与元素块、视口框拖动同步滚动、点击定位、复位左上角、缩小/隐藏；顶栏地图按钮与中间栏「更多」均可开关。
- 锁定元素常显锁角标，选中态不必再额外依赖文字“锁”。

### 4.13 表达式、表格汇总、连续纸/拼版、套打/水印、溢出与客户端 PDF（2026-09-21）

- 绑定来源新增白名单 `EXPRESSION`。表达式只允许四则运算、比较、括号、点路径、以及 `SUM/AVG/COUNT/MIN/MAX/ABS/ROUND/IF/CONCAT/TEXT/MONEY/UPPER/RMB`；禁止 `eval`、任意 JavaScript/SQL、赋值和未登记函数。金额大写走格式 `MONEY_UPPER`（整数分）或函数 `UPPER`（元）/`RMB`（分）。
- 明细表除末页合计（`footer`）外，支持每页小计（`subtotal`）。小计按当前页数据行聚合，合计按全部明细聚合；`SUM(字段)` 在对应带区求值。
- `paper.kind=CONTINUOUS` 时按内容撑高单张连续纸，高度上限仍为协议纸张上限。`paper.tiling` 把标签页按行列间隙拼到目标纸张；单页时可 `repeatToFill` 铺满。
- `paper.designBackground` 是套打底图：设计画布和预览可见，默认不进入浏览器打印和 PDF。`document.watermark` 在预览、打印和 PDF 中绘制。
- 固定文本 `style.textFit`：缺省仍超出报错；`CLIP` 截断、`SHRINK` 缩小字号、`AUTO_HEIGHT` 撑高。
- 预览「PDF」必须下载 PDF 文件，不得再打开系统打印对话框。导出截取预览已排版纸张（浏览器排版，不是 html2canvas 重排），事件为 `PDF_DOWNLOADED`，不等于服务端归档、静默打印、不可篡改或物理出纸。
- `exportFileName` 可在设计器「纸张」面板配置。支持 `{{main.字段}}`、`{template}`、`{timestamp}`；留空时默认「模板名-业务名称-时间戳」。未写 `{timestamp}` 时导出仍追加本地时间戳。文件名不能包含路径分隔符。
- 元素 `style` 对象：安全的基础类型展示属性（含 `opacity` 以及前端多传的同类数值/颜色）原样入库，不再因未知键拒绝保存。仍拒绝 `backgroundImage`/`url()` 等可执行 CSS。设计器「样式」透明度用 0–100% 滑块。
- 选中空白表格单元格时，画布快捷面板跟随单元格包围盒，而不是整张表。表格四边拖动手柄改行高/列宽；选中框不再用八向锚点挡住外沿。
- 属性面板字号（含表头/表体/列/最小字号）用预设 pt 下拉，不用数字输入框。
- 空白表格「样式 → 表头背景」写 `headerStyle`，并清掉第一行格子上的默认白/灰底，避免文字色生效、背景色被盖住。
- 字体栈按整串校验：本机没有 `STHeiti` / `Microsoft YaHei` 时，只要后面还有 `PingFang SC`、`Heiti SC` 或 `sans-serif` 等回退，预览和保存不得失败。只有没有任何具名字体且没有 generic 回退时才报「打印字体未安装」。

## 5. 模板归属、版本与流程配置

- 模板归属于应用，绑定一个业务数据源身份；页面/表单绑定与底层 objectCode 同时维护，表单重命名不靠展示名称关联。
- 一个表单可有多模板；绑定可设置默认模板，只有可用且已授权的模板进入选择列表。
- 草稿可编辑；发布生成新的不可变版本，继续编辑不覆盖旧版本。重复发布同一内容返回已有版本，乐观锁防止覆盖其他人的草稿。
- 应用发布快照存固定 templateVersionId 与绑定规则；应用回滚恢复旧引用。停用模板阻止新打印，不能通过指定旧版本绕过。
- 已发布应用引用中的模板不允许直接删除，需先解除引用/重新发布；删除用逻辑删除保留历史。
- 节点模板限制在现有流程设计器的节点面板配置，继承应用默认，限制列表取应用已发布模板的子集；不建立第二套节点配置 UI。
- 同一记录多次发起必须选择明确 processInstanceId；应用业务流程还保留 runId/processVersionId。服务端核验它们的实际关联。
- 首期打印使用当前已保存数据与当前可读审批记录，标记生成时间/流程状态；不宣称历史原样复现。

## 6. 权限与状态变更审查项
