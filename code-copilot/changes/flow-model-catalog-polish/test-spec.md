# 测试计划

复用流程设计器 50 文件/439 用例基线，按本轮新增列表、Mapper/DTO 和批量接口差异扩展；不重新规划真实后端 E2E。

## P0

- 发布快照 tenant/model/version/deployment/processDefinition/del_flag 均受约束，大小写敏感比较 BPMN/表单，未知/无快照不猜状态。
- 批量绑定最多 100 Key、校验空白/长度、可信租户、原 ai:businessFlow:config 权限不变；返回按请求 Key 正确分组，SQL 参数化。
- 一页最多两次业务请求、无统计/逐模型调用；关键词/分类/状态/分页、并发先后顺序、错误重试/保留旧结果、卸载防回写。
- 卡片未发布/已同步/草稿变更/待核对，正确发布动作、真实版本/Long 字符串 ID、排序/忙碌禁用；无匹配与无数据不同。

## P1

- 主界面实际组件的本地合成夹具，桌面、390/320px 与深色截图；筛选/清空/排序/更多动作可达，不调用真实业务写接口。
- 相关 Maven 测试/编译，JS/Vue ESLint、Vite 构建、Flyway 重号/占位符/幂等检查、git diff --check。

真实 DB/Flowable/接口部署验收由用户执行；不填造生产测试结果。
