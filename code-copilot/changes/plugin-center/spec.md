### P1 本轮：运行插件清单

- 内置业务插件 JAR 携带 `META-INF/forge-module.json`，仅此资源过滤 Maven 版本/模块坐标。
  不扫描源码目录，不将模块目录或配置文件存在误认为服务已部署。
- starter-plugin 的不可变运行目录合并内置声明和已有外部 PluginRegistry，重复 ID/坏声明启动失败。
- 清单按当前实例 classpath 展示；加载成功只代表描述/类路径装配，不代表健康检查通过。
  外部描述没有 server 的只能显示「仅元数据」，不能冒充后端已加载。
- API 提供核心版本、发行标识、分页/名称或 ID 查询、来源筛选、详情、声明功能及当前 Gate 结果。
  不读取许可证、凭据、源码路径、数据库连接或任意工作区文件。
- `GET /system/plugin/page` 和 `GET /system/plugin/{id}`；平台超级管理员限制与 RBAC 注解同时检查。

- 前端 `/system/plugin`：紧凑筛选/表格、真正详情、刷新、错误重试、空状态、窄屏/明暗主题。
  来源、发行版、加载状态用系统字典；不加入无实现的安装/升级/卸载按钮。
- 本轮清单范围明确为**当前后端服务**。纯前端插件/current UI build manifest 在 P2 补齐，

### P2：安装工作台与部署差异

- 受控 ZIP 上传、元数据/兼容/哈希/路径/大小预检、变更及冲突预览、显式确认。
- 区分源码登记、当前 UI 构建清单、当前服务 Registry，展示版本/部署差异。
- 持久化审计任务及状态机；复用 CLI，不在生产 Web 进程执行上传代码或构建命令。

#### P2 本轮执行契约（2026-10-07）

- Web 预检不接受客户端目标目录/tenantId/命令。ZIP ≤8 MiB、单文件 ≤4 MiB、
  展开总量 ≤32 MiB、条目 ≤2000，仅 stored/deflate；拒绝链接、特殊文件、加密、ZIP64、
  路径穿越、大小写/NFC 冲突、本地头不一致/范围重叠/CRC 失败；只在有界内存解析。
- 复用 starter-plugin 的描述与版本校验；根描述必须与后端 runtime 描述完全一致。
  校验单模块 POM（禁 DTD/外部实体）、UI 组件存在、组件不重叠/无保留文件；
  拒绝本地配置、构建产物/隐藏仓库目录，避免上传密钥（仍不声称自动内容审计）。
- 包 SHA-256、当前核心版本/运行清单快照、预览、文件摘要存入任务；ZIP 私有 BLOB 不出普通 API，
  页面预览最多 200 项且明确截断。无文件下载/执行接口。任务记录默认逻辑删除且不提供删除动作。
- 状态机：待确认→待构建，或待确认/待构建→已取消；有已知冲突→预检阻断。
  确认需任务 revision+SHA-256，服务端重新验证包及当前核心/运行快照，CAS 防并发；
  同一上传 requestId 幂等，同 requestId 不同字节拒绝；重复确认不重复创建任务。
- 仅当前租户上下文的平台管理员：上传/确认/取消/任务查询新增独立 RBAC，不给普通角色授权。
  新权限属于用户已批准的插件管理范围，上线前人工审查迁移；不自动执行共享数据库变更。
- 检查已知 ID/模块/内置冲突及版本降级；源码目标路径、未提交定制、构建依赖和 UI/API/SQL
  实际影响仍标为待执行器预检，绝不把运行目录比较冒充完整源码差异。社区 Web 不受理 ee 包。
- UI manifest 由 Vite 构建时读取真实安装登记/组件所有权，不接受后端/上传包伪造 UI 已部署。
  显示 UI/后端构建声明对比；源码工作区未连接明确显示不可核验。
- 新 V1.0.211 建任务审计表/权限/字典；清理模板时清空任务包，不携带客户上传代码。
  生成工程沿用格式和 CLI；最终源码安装仍由 P3 通过现有 CLI 做完整宿主检查。
- 本轮不提供运行安装/卸载、自动部署、商业授权校验，也不调用 shell/Node 子进程或读取源码工作区。

### P3：独立构建执行器

- 独立低权限工作区/容器，固定命令、超时、有界日志、无生产 Secret/数据库/宿主 Docker socket。
- 状态为预检→待确认→安装→构建验证→待部署→部署→运行核验；失败可解释、恢复可审计。
- 升级/卸载保留恢复副本；卸载不删数据库，Flyway 失败不自动 repair，不宣称源码回滚能回滚数据库。
- 部署需后续单独确认目标环境及权限，不由本轮「开始开发」推定生产部署授权。

#### P3.1 本轮：离线执行器核心（2026-10-07）

- 交付 `forge:plugin-build check/run`；输入为运维本地配置、固定 Git commit、ZIP SHA-256，
  不接受 Web 命令或目标目录。先只读检查，run 必须显式 `--reviewed`；不连接任务 BLOB/API。
- 从干净 Git 工作区复制已提交普通文件，逐文件核对 Git blob，拒绝链接/子模块/本地配置、
  构建产物、开发接入。只在独占临时副本预检并调用原安装器，不改原源码或数据库。
  已安装源码摘要有客户定制（即使已提交）仍阻断；整包替换须显式 `--force`。
- 源快照最多 30000 文件、单文件 64 MiB、总量 512 MiB；包沿用 CLI ZIP 边界。
  Git 信息/配置不进入容器；受审查的公开 `.env`/环境模板可复制，本地覆盖和私钥拒绝。
  该规则不等于内容级 Secret 扫描，源码、ZIP、镜像仍必须人工审查。
- 仅专用非 root 用户的本地 rootless Docker daemon；预装镜像必须指定 sha256 digest、
  `--pull=never`、无网络、只读根、cap-drop/no-new-privileges、资源/时间限制。
  容器内 UID 0 仅映射专用非 root 宿主用户，挂载只读快照/包/工具及独占输出；
  不挂生产目录、数据库配置、宿主 socket 或 credentials，不以宿主构建作降级。
  socket 父目录须私有；要求 cgroup v2/systemd 及内存/交换/CPU quota/PID 控制可用，
  防止 rootless 环境静默忽略资源限制，未满足时直接阻断。
- 固定离线 Maven/pnpm/Vite 命令；镜像预备 Node20.19+/Java17/Maven/pnpm 与公开依赖缓存。
  不运行服务器、Flyway 或部署脚本。缓存缺失直接失败，不开放网络补依赖。
- 有界子进程输出与超时、只清理本次随机名称和标签匹配的容器；SIGINT/SIGTERM 转失败并清理。
  stdout 只输出结构化状态/错误码，不回传原始源码编译日志；结果 JSON 绑定包/源码/镜像摘要，
  核对真实产物路径、大小及 SHA-256。产物最多 4096 文件、单个 512 MiB、总量 1 GiB。
  构建通过不表示健康、授权或部署完成，不信任包提供的产物清单/回执。
- P3.2 再实现认证领取、租约/CAS、包下载及回写与工作台；P3.3 为人工确认的部署/健康核验。
  本轮无任务状态/权限/SQL 变更，P2 队列不会自动执行；Docker 缺失时明确未验收真实容器。
- 生成后的工具在改名后原样复制；修正把管理端 build 源码插件目录当产物忽略的旧规则，
  防止新 Git 工程的受审查快照漏掉 Vite helper，保留真正的 dist/target 忽略规则。
- full 实测发现独立 Report UI 字体库约509 MiB，完整导入超过512 MiB快照上限。
  不增加限额：源码固定视图收敛为后端根目录、Admin UI、根包管理配置及原模块 catalog；
  排除独立前端/部署/文档与历史 `<Admin UI>/dist.zip`，结果声明 admin-build 范围及排除数量。
  仍校验全仓 Git 干净状态、路径/链接/本地配置；不支持构建依赖宿主范围外的自定义工作区。

#### 用户路径与登记边界

- 运维在现有私有封存目录逐文件复验，通过拟新增的 `prepare-registration` CLI 导出小型登记元数据。
  平台管理员在插件任务详情导入、检查摘要并显式确认，再登记到当前审批任务。
  CLI 不联网、不调用登记 API、不输出私有目录或凭证、不修改原清单/回执；生成工程原字节交付。
- 登记元数据 ≤64 KiB、严格固定字段及协议版本，拒绝重复/未知键和非法类型。
  固定 taskId/revision/reviewId/serverResultSha256、releaseId/manifestSha256、repositoryId、
  原 result.json SHA、插件/核心版本、操作、源码 commit/SHA、包/镜像摘要和成功构建报告。
  不携带完整逐文件清单、文件字节、源码、日志、身份、凭证、URL 或可执行命令。
  原始报告文件 SHA 与服务端报告 SHA 分开显示，releaseId 必须对应 manifestSha256。
- repositoryId 仅为本地私有仓库标签，不是经过认证的远程仓库；不允许将其转换成下载地址。
  元数据来自人工导入，平台只能验证与当前任务报告的一致性，不能证明本地实际文件存在/未篡改。
  界面明确区分「管理员登记」「当前审批匹配」「服务端未读取实际制品」「未部署」。
  CLI 的真实文件复验不能被描述为平台独立复验，登记不是制品上传/远程发布或部署许可。

#### 权限、事务与幂等

- 拟新增加解密 POST `/system/plugin-task/{id}/artifact`、明确 DTO/VO；
  仅可信当前租户的平台管理员且拥有独立 `system:plugin:artifact:register` 权限可登记。
  读取同任务的登记摘要复用 `system:plugin:task:detail`，无批量跨租户查询或下载接口。
  不给普通角色自动授权，不扩大现有 worker 过滤器、Token 或 `/internal/plugin-build` 能力。
- 登记请求另包含 requestId、人工核验/尚未部署确认和简短核查说明，不接受客户端 tenantId/userId。
  写事务沿用 build→task 行锁顺序，锁定查询按租户/主键、不加 ORDER BY/LIMIT；
  在锁内重新验证当前 release_ready、有效审批/修订、四项原审查确认、已结束构建、占用、
  当前核心版本及包/全部成功报告摘要，再写登记审计；不复用只读核验的 checkedAt 作为授权。
  登记与关闭竞争只能串行完成；关闭先提交则新登记拒绝，登记先提交则随后关闭保留历史。
  不修改任务状态/revision/active_plugin_id，不远程调用或执行构建/迁移命令。
- 同租户/任务/操作人/requestId 绑定规范请求摘要；同内容重试返回原登记，不重复写入。
  同 requestId 异内容拒绝；每个审批仅保留一个候选登记，已有登记不允许以其它请求覆盖。
  并发登记冲突必须可解释；历史幂等返回保留原操作者，并重新计算当前审批是否匹配。
  后续关闭/核心漂移不能让历史记录被误显示为仍有效，也不自动删除、更新或重新批准。

### P3.3a 本轮：构建验收与失联关闭治理（2026-10-08）

- 本轮实现部署前治理，不执行实际部署：平台管理员的独立 `system:plugin:review` 权限、
  加解密 POST `/system/plugin-task/{id}/review`，明确 DTO，不接受租户/用户/机器命令。
  只在归属本租户、已有构建审计的任务上操作；机器凭证不能调用此管理端能力。
- approve_build：仅 built 且有真实成功报告；人工核对包/当前 revision/结果 SHA，确认执行器停止、
  产物及迁移影响已经审查、尚未部署，转 release_ready（已审查/待部署），仍保留插件占用。
  此标记是管理员的审查记录，不等于平台独立复验、商业许可或已部署。
- close_task：仅 built/build_failed/release_ready 或租约/硬期限已过的 building；
  活跃构建不能关闭。必须明确确认本次执行器/容器已停止、尚未部署并填写核查说明。
  系统无法远程证明容器停止，界面/审计须如实展示人工确认来源，不宣称已自动清理。
- 关闭将状态设 closed、释放 active_plugin_id；私有包、产物及构建/审查记录不删除。
  对未上报终态的失联构建，在原构建行锁内封存 finished_time，但不伪造 worker 结果/失败摘要。
  heartbeat/finish 的原 finished_time CAS 拒绝旧在途回写，防止关闭后租约复活。
  锁定查询只按租户/主键 FOR UPDATE，无 ORDER BY/LIMIT，保持原租户拦截。
- 审查事件追加到 sys_plugin_task_review；请求 UUID+规范 DTO 摘要绑定身份/任务，
  同请求同内容幂等，异内容拒绝；task CAS、封存和审查插入在同一写事务，失败整体回滚。
  任务详情最多返回最近20条说明（文本转义，禁止记录凭证）；不出原包/日志/本地路径。
- 新 V1.0.213 表/字典/最小平台权限资源，tenant=1、防重复及客户菜单冲突保护；
  不覆盖已有资源/不授权普通角色。回滚先隐藏新按钮/停用能力，保留审计，不修改已执行迁移。
- 前端按现有 Naive UI 提供就近审查/关闭表单、明确勾选、错误/重试和历史；
  网络结果不确定时保留同一个请求 ID/内容，先刷新核查，不盲目重复执行。
  复用已有测试矩阵及 fresh full 生成工程；不改源安装器/构建器、不假装完成P3.3实际部署。

### P3.2 本轮：认证租约与构建回写（2026-10-08）

- 仅处理管理员已确认的选定任务，不自动扫描/执行全部队列。独立 worker 仍需本地
  `--reviewed`，固定源码 commit、镜像 digest 和包 SHA；replace 仍须显式 --force。
- 新机器入口 `/internal/plugin-build/{id}/{claim,archive,heartbeat,finish}` 不复用管理员 Token。
  专用过滤器先认证，Controller 的 SaIgnore 仅避免用户登录链重复拦截，不代表匿名开放。
  默认禁用；开启需运维配置 worker ID、正数租户 ID、256-bit 随机 Bearer 的 SHA-256 及到期时间。
  强制服务端可信 HTTPS，常量时间比对，过期/普通登录 Token/缺配置拒绝；客户端不传租户/用户。
  私有凭证仅从 worker 环境读取，不进入容器、公开响应、URL、日志或生成工程配置。
  权限影响仅此固定构建能力，不开放通用内部调用/部署/角色授权；真实开启前人工安全审查。
- 新 sys_plugin_build 审计表与任务一对一，保留私有租约摘要、机器身份、固定源码/镜像、
  起止时间/阶段和结构化结果；逻辑删除，不提供删除接口。claim 用任务 revision/SHA CAS，
  同一随机租约可幂等恢复，不产生第二次执行。包下载只给已认证且持有本任务有效租约的 worker。
- queued→building→built/build_failed；90 秒租约、30 秒续期、25 分钟硬期限。
  过期不能续期/回写、不能自动抢占重试；仍保留插件占用，界面提示人工核查，不冒充安全取消。
  阶段只允许单向推进，结果绑包/源码/镜像/租约，终态重复同结果幂等，异结果拒绝。
  原确认/取消 CAS 不受续期影响；构建中不能直接取消，构建通过/失败也先保留占用等待后续处置。
- ZIP ≤8 MiB，下载前重新查摘要；worker 禁重定向、仅固定 HTTPS origin、3 秒有界请求，
  不接服务端命令/路径。租约续期失败/信号中止本次构建，沿用独占容器清理，不在宿主降级。
  网络不确定时记录本地结构化结果，保留审计/产物，不自动重新领取。
- 回写仅有界元数据：源快照摘要、产物数量/总字节/清单摘要、阶段与稳定错误码，无源码、
  原始日志、私有路径或可执行下载 URL。校验实际产物仍在 worker；服务端不将上报当作独立复验。
  built 表示构建通过/待部署，不代表已安装、健康或商业授权；大产物留私有工作区，后续另接制品仓库。
- 工作台新增阶段/机器/租约/结果详情与刷新，状态/阶段用系统字典；无假进度百分比，
  不把下载凭证或租约摘要传到普通 API。新增 V1.0.212，不修改已交付迁移，不赋普通角色权限。
  生成工具仍原样复制，clean-db 清空构建审计；真实容器/MySQL/HTTPS部署链待目标环境验收。

不创建未确认的 Pro 名称/groupId/包名，不实现动态 JAR 热安装，不推送、不合并 main。
