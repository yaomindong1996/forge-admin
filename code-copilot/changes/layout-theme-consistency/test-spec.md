# 增量测试计划

基线复用 `forge-business-workbench-layout` 的 12 项菜单/设置测试及已有租户工作区测试。

## P0

- 自动配色：深浅背景、低对比自定义、合法/非法颜色、暗色主题、旧 JSON 与未知字段保留。
- 租户外观编辑/保存回环：三个基础色、自动/高级模式、原暗色分组不丢失。
- 空白布局恢复入口与路由强制布局隔离。
- 菜单搜索：父目录命中保留全部子项，叶子命中保留祖先，空结果和权限菜单顺序。
- 所有后台布局的主题角色接入；Logo 无颜色滤镜。
- `git diff --check`、修改文件 ESLint、前端生产构建。

## P1

- 浏览器：通用深浅顶栏、折叠菜单、沉浸式菜单搜索、业务工作台菜单图标。
- 个人设置：预设/三色调整、切空白再切回、深浅模式；登录入口不出现恢复按钮。
- 1440/1280/窄屏尺寸：导航与工具不撑破，抽屉内搜索固定、菜单滚动。
- 不执行真实租户配置保存，不启动后端/数据库。

## 最终结果

- P0 自动化项通过：新增 20 项 + 既有回归 18 项，共 38 项；ESLint、差异检查、生产构建通过。
- P1 使用隔离预览检查十种布局、三种浅色方案/暗色模式和 1440/1280/1024px 窗口，通过。
- 真实租户保存与实际后端数据端到端未执行，不能将隔离预览等同于线上验收。

## 第二阶段增量矩阵

- P0：恢复租户布局/配色保留暗色和扩展配置，不修改源对象；非法颜色安全降级；系统默认与租户默认分离。
- P0：通知样式无固定品牌绿色和亮色表面，Nexus 不强制覆盖暗色导航；工具复用身份切换组件。
- P0：预览深浅切换不 emit 草稿、不影响系统主题；旧三基础色/布局过滤与空白恢复回归。
- P1：浏览器浅/深通知浮层、工作台多租户/组织入口、更多工具、两种恢复、Nexus 自定义暗色、空白切回。
- P1：1280/1024/768px 工具区不越界；菜单和标签搜索提示清晰；构建和修改文件 ESLint。
- 复用原 38 项测试和隔离预览；真实身份切换/消息写入/租户保存不执行。

## 第二阶段结果

- 自动化八个文件 60 项通过：原 38 项 + 新增 17 项 + 通知协议回归 5 项。
- 七种顶栏在隔离预览正常接入；工作台 1280/1024/768px 无水平溢出，两种恢复、取消确认、独立预览、空白返回已点击验证。
- 通知浅/深表面、蓝色及松石绿主按钮跟随系统主题；Nexus 自定义深色导航未被覆盖。
- 差异 ESLint、`git diff --check` 和生产构建通过。真实租户配置保存、身份切换及消息/审批写接口未执行。
