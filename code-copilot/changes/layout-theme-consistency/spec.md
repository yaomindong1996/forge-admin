# 布局外观与租户主题统一

## 范围与约束

- 基线：`9aff6ba9`；复用业务工作台已有菜单模型、权限路由和主题变量。
- 统一所有可选后台布局的顶栏/导航色彩、工具交互与原始 Logo 展示。
- 配色入口收敛为品牌主色、顶栏背景、导航背景；文字、图标、悬停和选中颜色自动推导。
- 兼容已有 `themeConfig` JSON，保留高级自定义与未知配置，不改变后端接口、权限或数据库。
- 租户管理大页先拆分外观区与用户弹窗，组件目标不超过 1000 行。
- 沉浸式菜单保留真实授权菜单，改为紧凑分组、搜索、路径定位和独立滚动。
- 空白布局保留个人布局恢复入口；登录、错误页、应用门户等路由强制布局不显示该入口。
- 业务工作台使用统一顶栏配色和真实菜单图标，小面积选中态点缀，不增加装饰插画。

## 验收

1. 深/浅顶栏下工具、收起图标、用户文字、Tab 均可辨识，文字对比度有自动兜底。
2. 通用、全屏、顶部菜单、混合、沉浸、Nexus、便当盒、简约和业务工作台使用一致主题角色。
3. Logo 不再滤成白色、不套蓝底、不产生嵌套链接。
4. 外观设置默认只有三个颜色；预设一键应用，高级项默认收起，并显示当前布局适用范围。
5. 主题/布局切换即时生效，租户保存沿用原 JSON 并保留暗色和未知扩展字段。
6. 空白布局可切回，路由专用空白页无设置按钮；菜单搜索保留可访问父目录的完整子项。
7. 增量单测、Lint、构建和浏览器点击/尺寸验证通过，服务清理，自动本地提交但不自动 push。

## 风险

- 历史低对比文字会被调整为可读颜色；不覆盖租户保存数据，调整只发生在渲染时。
- 纯前端变更，不执行真实租户配置写入或权限操作；浏览器使用隔离预览验证。

## 实现结果

- 共用主题解析器与外观编辑器，六种预设 + 三个基础色；无顶栏布局隐藏顶栏颜色，空白布局只显示品牌色。
- 高级自定义默认折叠；既有配置保留 `navigationMode=custom`，新增自动配色不迁移数据库。
- 顶栏工具、Tab、租户/组织切换器使用区域化颜色，正文和弹窗不继承顶栏前景色。
- 个人外观抽屉统一挂在 App 层，跨布局切换保留；空白布局保留恢复按钮。
- 租户页从 1764 行拆至 306 行，Nexus 侧栏复用公共菜单，工作台/便当盒使用真实菜单图标。
- 暗色模式保留独立表面配置；普通自定义色取可读前景，六种预设通过对比度契约测试。
