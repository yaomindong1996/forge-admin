# 认证与流程身份安全加固
> status: apply
> created: 2026-09-02
> complexity: 🟡中等

## 1. 目标

1. 匿名重置密码不能只靠图形验证码。短信/邮件找回必须先确认全局通道已启用。
2. 流程待办/已办/签收/抄送的 userId 只信 Session。
3. 匿名注册默认关闭；删除无鉴权调试接口。

## 2. 重置密码规则

- 通道来自 `sys_sms_config` / `sys_email_config` 的启用配置（`SmsConfigProvider` / `EmailConfigProvider`）。
- 未启用的通道直接拒绝，不降级到图形验证码。
- 两个通道都未启用时，接口明确返回「未启用找回密码通道」。
- 发码成功对外文案统一，不暴露账号是否存在。

## 3. 第二阶段（P1）

1. 公告/消息等 `v-html` 必须先消毒，菜单搜索高亮先转义。
2. Actuator 仅匿名开放 `/actuator/health`，默认只暴露 health。
3. 租户管理接口去掉类级 `@ApiPermissionIgnore`；仅当前用户切换/选项保留豁免。
4. 登录页仅在 `resetPasswordChannels` 非空时展示找回密码；新密码走登录 RSA。

## 4. 第三阶段（P1 续）

1. 角色/用户/资源/客户端/数据权限/监控/密文迁移去掉类级 `@ApiPermissionIgnore`。用户资料 `profile` / `updateProfile` 保留方法级豁免。
2. 流程实例终止、删除只信 Session userId。
3. 报表过滤器 `new Function` 禁止访问 `window`/`document`/`fetch` 等浏览器全局能力。

## 5. 第四阶段（P1 续）

1. 系统配置、配置分组、API 配置、缓存策略、文件存储、短信/邮件通道配置去掉类级豁免；短信邮件配置增加超级管理员校验。
2. 组织/岗位/字典/公告/消息/区划去掉类级豁免；选择器和当前用户接口保留方法级豁免。
3. 消息发送需权限；收件箱仍对当前登录用户开放。

## 6. 第五阶段（P1 续）

1. 通用文件接口去掉类级豁免；上传/下载/URL/分片/删除保留方法级豁免（登录用户可用）。存储桶接口仅超级管理员。
2. 删除文件必须是上传者或管理员；下载不改为仅上传者，避免头像、公告附件、表单文件对其他登录用户失效。
3. 文件分组、文件元数据、Excel 导入导出配置去掉类级豁免；文件选择器使用的 `byFileId` / `rename` 保留方法级豁免。批量删除补所有权校验。
4. 报表请求 URL 模板在 `new Function` 前走与数据过滤器相同的危险全局对象拦截。图表事件脚本仍允许访问 `window`。
5. 系统未使用 Swagger/Knife4j。Sa-Token 不再匿名放行 `/doc.html`、`/webjars/**`、`/swagger-ui/**`、`/v3/api-docs/**`。
