- 表单 Tabs 可新增多个 tab，并可将字段拖入每个 tab
- 列表 Tabs 新增 tab 默认拥有 children，画布拖入当前 tab
- 保存/加载及运行时渲染保留非首个 tab 的 children

## 2026-08-12 增量验证

- 表单右侧属性连续点击“新增页签”两次：`appendDesignerLayoutChild` 必须在同一个 Tabs 节点保留三个 `tabPane`，每个页签都有唯一 ID、`name` 和 `children: []`。
- 表单页签内容投放：普通组件只允许投到当前 `tabPane` 的内容区，不能被 Tabs 外层截获后错误写入第一个页签。
- 应用运行时编辑页：从组件目录拖到带有 `data-grid-container-id` / `data-grid-tab-key` 的当前页签后，组件必须写入该 Tabs 的对应 `props.tabs[].children`；投到其它区域仍追加到页面根级。
- 浏览器自动化在当前受限环境启动 Chromium 时被 `SIGTRAP` 终止，因此本轮以 schema 单测、ESLint、构建和本地 Vite 响应检查替代真实点击验收；需要在已有登录会话的浏览器中按上述三项复验。
