# 外部连接器与数据集运行时加固测试规格

## 1. 测试目标

验证运行策略真实生效、密钥和敏感业务数据不泄露、外部目标经过统一安全校验、数据集失败语义可靠，且现有成功接口结构保持兼容。

## 2. 外部连接器用例

| ID | 场景 | 预期 |
|---|---|---|
| EXT-01 | 权限开启但权限码为空 | 失败关闭，不发送请求 |
| EXT-02 | 当前用户没有所需权限 | 返回权限不足，不发送请求 |
| EXT-03 | 限流开启且超过 QPS | 拒绝本次调用 |
| EXT-04 | 限流开启但基础设施异常 | 失败关闭 |
| EXT-05 | 缓存 Key 生成 | 不包含手机号、Token、订单号等原值 |
| EXT-06 | GET 缓存命中 | 不再调用外部客户端 |
| EXT-07 | GET 首次成功 | 写入有限 TTL 缓存 |
| EXT-08 | GET 遇到网络异常/503 | 按上限重试并退避 |
| EXT-09 | POST 遇到网络异常/503 | 不自动重试 |
| EXT-10 | 4xx/业务错误 | 不重试、不缓存 |
| EXT-11 | URL/请求/响应含敏感键和数组嵌套 | 持久化与运行日志均脱敏 |
| EXT-12 | 危险 Header 或未授权目标 | 统一出站策略拒绝 |

## 3. 密钥用例

| ID | 场景 | 预期 |
|---|---|---|
| SEC-01 | 新增外部系统凭据 | Mapper 收到版本化密文，不含明文 |
| SEC-02 | 编辑时凭据为空/为掩码 | 保留旧密文 |
| SEC-03 | 分页、详情、列表查询 | 凭据字段仅为固定掩码或空值 |
| SEC-04 | 运行外部调用 | 认证策略收到解密后的值 |
| SEC-05 | 存量明文 | 兼容运行并输出不含原值的迁移告警 |
| SEC-06 | 密文损坏 | 明确失败，不回显底层密文/算法详情 |

## 4. 数据集用例

| ID | 场景 | 预期 |
|---|---|---|
| DATA-01 | 数据集/请求 maxRows 为空、负数、超上限 | 归一到 1～10000 范围且请求不能放大配置 |
| DATA-02 | timeout 为空、负数、超上限 | 归一到 1～120 秒 |
| DATA-03 | JDBC 查询 | 尝试设置只读，资源全部关闭 |
| DATA-04 | JDBC 抛异常 | 抛出业务异常，不返回成功空数组 |
| DATA-05 | 日志记录 | 不包含参数值和渲染 SQL，只含键集合与摘要 |
| DATA-06 | 缓存 Key | 绑定租户、用户、数据集、字段、参数摘要且无原值 |
| DATA-07 | 缓存命中 | 不访问数据库 |
| DATA-08 | 缓存异常 | 降级查询，不影响成功结果 |

## 5. 脚本用例

| ID | 场景 | 预期 |
|---|---|---|
| SCRIPT-01 | JavaScript Engine 不存在 | 明确业务错误，无 NPE |
| SCRIPT-02 | 脚本语法/执行失败 | 明确业务错误，不泄露输入数据 |

## 6. 验证层级

1. 新增类和核心分支单元测试。
2. Maven 定向模块测试。
3. 受影响模块聚合编译。
4. 静态检查：日志中不得打印 `params`、完整 URL query、响应原文或凭据。

## 7. 非本机自动执行项

- 真实 Redis 限流竞争压测；
- 真实出站白名单、代理和不同 TLS 服务联调；
- 真实外部 OAuth2 服务联调；
- 存量明文凭据批量迁移；
- 真实业务数据库只读账号权限验收。

这些项目需在部署环境补验，不能表述为本地已通过。
