# H5 移动工作台与待办闭环重构

## 目标

将 `forge-h5-ui` 从多层渐变、玻璃拟态和装饰动画收敛为简洁的企业移动工作台；待办以 Flow 服务现有 `TaskFormInfo` 与业务任务表单接口为准完成移动端审批闭环。

## 范围

- 建立单一蓝色主色、灰白表面、统一间距/圆角/边框的移动端设计令牌，移除光晕、网格、扫光、持续浮动等非业务装饰。
- 重构登录页、首页、消息页、我的页及共享按钮/弹层/导航组件；首页展示真实待办数，主导航提供首页、待办、我的。
- 消息详情只展示用户可理解的正文、状态与操作，不暴露流程类型、业务键或内部 UUID；首页仅保留待办和消息两类优先事项，不展示菜单、权限或同步等技术指标。
- 公共底栏采用图标与文字清晰分层的三项导航，消息筛选采用可横向浏览的宽触达标签，避免数字和标签相互挤压。
- 共享搜索与表单输入控件使用紧凑高度、明确边框和可见焦点态；个人资料中的联系方式只在后端返回真实值时显示，不以占位符伪造数据。
- 首页保留后端授权菜单与组件演示固定入口；尚未编译专属 H5 页的后端路径进入统一应用承接页，禁止隐藏正式菜单或提示“页面未注册”。
- 待办、消息及所有复用分页/选择列表的首次异步查询统一使用骨架屏；待办页面复用消息页的标题、搜索、筛选和卡片层级，避免形成另一套视觉语言。
- 所有公共空状态统一使用 `src/static/images/no-data.png`，不使用默认图标容器、模拟按钮或与业务无关的装饰。
- 将待办拆为紧凑列表页与全屏详情页。列表采用固定筛选、单行任务信息与明确签收入口，支持关键词、流程分类、任务状态和刷新；详情分为业务内容和审批记录，候选任务先签收，底部只保留当前场景的关键动作。
- 消费 `TaskFormInfo` 的 `allowApprove/Reject/Delegate/Return/Terminate`、`requireComment`、`requireSignature` 和表单数据；不可在移动端安全完成的表单不得绕过后直接提交。
- 对业务对象表单复用 `/ai/business/flow/task-form-context`、保存接口和 `/ai/business/flow/task-action`；动态表单仅在受支持字段类型下渲染，其他情形明确阻断并保留 PC 处理入口。
- 移动端流程工作台提供待处理、已处理、我发起的三个真实列表入口；已处理和我发起的详情使用只读业务表单上下文，不暴露办理动作。我发起的运行中流程允许按既有权限撤回。
- 对节点要求的手写签名和附件字段提供 H5 采集/上传能力；转办独立收集转办说明、签名（如要求）和可分页检索的成员选择，所有动作继续受节点策略和后端校验约束。

## 非目标

- 不改变 BPMN、节点策略、业务状态机或 Flow 服务的既有审批语义。
- 不在本轮新增数据库迁移、流程模型或独立的节点配置界面。
- 不自动启动真实 Flow 服务、数据库或执行会改变流程运行态的数据验证。

## 验收标准

1. 所有 H5 主页面不再使用页面级光晕、网格、渐变背景、玻璃模糊或持续扫光动画；主色只用于关键操作和选中态。
2. 首页待办数来自 `/api/flow/task/todo`，不再复用未读消息数。
3. 待办详情不再以长底部弹层承载；任务权限、必填意见、签名和表单均在提交前校验。
4. H5 不会为动态/业务/签名表单跳过必填信息直接调用通用审批接口。
5. 前端生产构建通过；真实流程链路由用户在其本地环境回填验收。
6. 所有待办入口均使用 tab 跳转或独立详情页跳转，不再出现“移动端待办页暂未接入”或“待办页面未注册”的兜底文案。
7. 消息详情不展示 `bizType`、`bizKey`、流程编码或内部 ID；首页不展示菜单数、权限数、同步状态等非业务信息。
8. 公共输入控件有清晰边框且不使用过高的移动端尺寸；首页不注入未注册、无法访问的后端快捷入口。
9. 首页会保留后端授权菜单；未编译专属页的菜单可进入统一应用承接页，不出现“页面未注册”；组件演示入口保持可访问。
10. 待办、消息和复用列表在首次查询时展示骨架屏，待办页面的搜索、筛选和列表视觉与消息页保持一致。
11. 消息及复用列表的空状态使用统一图片占位，不展示默认收件箱图标和无意义操作按钮。
12. 待办详情对要求签名、可编辑附件、日期/日期时间字段具备实际 H5 提交能力；无法解析的可编辑字段继续失败关闭。
13. H5 可浏览已办和我发起流程，并用只读表单、审批记录和流程节点进度查看历史；不在只读详情展示审批操作。

## 风险与决策

- 移动端不机械复制 PC 批量操作；单任务闭环是 P0。批量审批需在任务表单、签名和候选签收校验完整复用后再单独交付。
- `BUSINESS_CODE_FORM` 可能只提供 PC 组件路径，移动端没有对应 Provider 时必须失败关闭，不展示可提交按钮。
- 转办需要受权限保护的用户选择接口；若当前 H5 无可复用接口，本轮不伪造用户列表，保留“请在 PC 转办”的明确说明。
