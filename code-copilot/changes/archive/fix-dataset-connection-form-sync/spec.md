# 数据集连接表单同步修复

## 背景

数据与报表模块新增数据集时，用户已经在自定义编辑工作台中选择数据连接，但保存仍提示“请选择数据连接”。

## 根因

数据集编辑器整体渲染在 `AiCrudPage` 的自定义 slot 中。连接选择器只直接修改 slot 内部的 `formData.connectionId`，没有通过 slot 提供的 `updateValue` 触发 `AiForm` 整体模型同步。父级表单重渲染或提交时可能继续读取旧模型，导致界面选中值与提交值不一致。

此外，数据连接主键为后端 Long，选择器值与详情回显需要统一使用字符串，避免 JavaScript 大整数精度和 Naive UI 选项类型不一致。

## 变更范围

- 数据集自定义编辑器中的基础字段变更统一触发表单模型同步。
- 数据连接切换时同步连接 ID、清空的数据表和行权限映射。
- 数据表切换时同步表名和被清空的行权限映射。
- 数据连接选择器与详情回显统一使用字符串 ID。

## 非目标

- 不修改数据集后端保存协议。
- 不修改数据连接、数据集或报表数据库结构。
- 不调整数据集页面布局和权限规则。

## 验收标准

1. 新增数据集选择数据连接后，保存不再错误提示“请选择数据连接”。
2. TABLE 类型选择连接和数据表后，提交模型包含正确的 `connectionId` 与 `tableName`。
3. 切换数据连接后，旧数据表和依赖旧表的行权限字段不会残留。
4. 编辑已有数据集时，连接 ID 可以稳定回显并提交给后端 Long 字段。
