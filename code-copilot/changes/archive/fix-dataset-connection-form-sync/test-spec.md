# 增量验证计划

## P0 手工验证（由用户执行）

1. 打开“数据与报表 → 数据集”，点击“新增数据集”。
2. 输入名称和编码，选择一个数据连接。
3. TABLE 类型继续选择数据表并保存，确认不再提示“请选择数据连接”。
4. 重新编辑该数据集，确认数据连接和数据表正确回显。
5. 切换为另一个数据连接，确认旧数据表被清空并要求重新选择。

## P1 静态检查（本轮执行）

- 检查相关 Vue 文件和变更文档不存在补丁空白错误。
- 检查本轮差异未混入现有能力开放、登录加密等工作区改动。

## 跳过项

- 不启动前后端服务，不执行浏览器联调和构建；用户已明确由其自行测试。
