# 流程经手可见

## 背景

角色数据范围「个人数据」只按负责人/创建人过滤。审批人、抄送人回到业务列表时看不到自己经手过的单据。

## 口径

- **数据范围**仍是全部 / 本组织 / 个人等，不新增「个人数据（含流程）」。
- **流程经手可见**是对象级只读附加能力：在所选范围之外，还能看到自己发起、实际审批过、被抄送的单据。
- 看见 ≠ 拥有。改、删、命令门禁不加经手 OR。
- 待办不进业务列表；候选人未办理不算经手。

## 配置

- 对象适配（跟随系统数据权限时）：开关「流程经手人可查看单据」，默认开。
- 角色授权：不新增范围选项；对象已开启且当前不是全部/本租户时，显示说明。
- 列表：经手行标记「我的 / 我审批 / 抄送」，编辑删除禁用。

## 实现

- 表 `sys_flow_record_participant`，流程启动写发起人，任务完成写实际办理人，抄送写抄送人。
- 低代码查询/详情对 SELF/ORG/REGION 等非全量范围 OR 经手主键；写路径不加。
- 业务 Mapper 拦截器同样只在查询上 OR 经手表；不改业务表字段，用发起流程的 `businessType:记录ID` 对齐 `sys_flow_record_participant`。
- `sys_data_scope_config` 增加经手开关、流程业务类型、单据主键列；默认关闭，避免用户列表等非流程查询被放大。
- 经手查询走平台主库，不依赖租户业务库 JOIN Flowable 表。
