# 低代码应用门户 UI 样式改造指南

> 目标：让「应用工作台 / 设计应用 / 应用设置 / 应用发布 / 应用中心」在视觉上贴近宜搭的产品化体验，同时保留 Forge 控制台的专业感。
> 原则：**功能层已落地，表现层再打磨**；不改动业务逻辑，只改布局、色彩、圆角、阴影、间距、字体层级。

---

## 1. 宜搭截图视觉特征提炼

### 1.1 整体氛围

- **画布背景**：浅灰 `#f5f6f7` 或 `#f2f3f5`，而不是纯白。
- **内容载体**：大面积白色圆角卡片，靠留白和极淡阴影分隔，不靠重边框。
- **信息密度**：中低密度，标题与正文层次清晰，按钮密度低。
- **状态表达**：用「左侧彩色竖条 / 大图标 + 状态标题 + 描述」的状态卡片，而非密集的标签页。

### 1.2 关键页面映射

| 宜搭页面 | Forge 对应页面 | 核心视觉差距 |
|---|---|---|
| 应用发布 | `application-publish.[applicationCode].vue` | 缺少“状态大卡片”；链接/二维码区域太技术化；分发入口没有卡片化 |
| 应用设置 | `application-settings.[applicationCode].vue` | 左侧菜单样式偏控制台；右侧表单未按“基础/访问/导航/权限/高级”分组卡片化 |
| 页面管理 | `application-runtime.[applicationCode].vue` | 顶部操作按钮过多；左侧页面树太宽；画布边框感重 |
| 应用工作台 | `application.[applicationCode].vue` | Header 按钮拥挤；侧边栏与内容区分割感强；Overview 缺少卡片 Dashboard |
| 创建应用 | `AppCreateWizard.vue` / `app-center/index.vue` | 创建入口应该是大弹窗/全屏模态；模板卡片尺寸和阴影需对齐 |

## 2. 设计 Token（Design Tokens）

建议在 `forge-admin-ui/src/styles/` 或组件内使用 CSS 变量，统一以下 token。若项目已有变量，覆盖对应值即可。

## 4. 页面级改造要点

### 4.1 应用发布页 `application-publish.[applicationCode].vue`

#### 4.1.1 当前问题

- 状态信息通常用普通表单或行布局展示，缺少「一眼看清应用状态」的大卡片。
- 访问链接像普通 input，不够产品化。
- 分发入口若用列表或按钮堆砌，缺少卡片化和状态标签。

#### 4.1.2 目标布局

```
┌────────────────────────────────────────────────────────────┐
│  应用发布                                           返回   │  ← 简洁顶部
├────────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────┐  │
│  │  [icon]  已启用 / v1.0.3                              │  │  ← 状态卡片
│  │          最近发布：2026-08-18 14:32  by  admin       │  │
│  │                              [停用] [查看历史版本]   │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  组织内发布                                                │  ← 分组标题
│  ┌──────────────────────────────────────────────────────┐  │
│  │  组织内访问                                            │  │
│  │  [ https://.../app/sales       🔗  📋  👁 ]           │  │
│  │  [二维码]  复制链接  新窗口打开                        │  │
│  │  仅授权用户可访问                                      │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  应用助手（Beta）                                          │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  [icon]  未创建应用助手                                │  │
│  │          配置后可通过自然语言查询、填单、分析          │  │
│  │                                          [立即创建]  │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  分发入口                                                  │
│  ┌────────────────────┐ ┌────────────────────┐            │
│  │ Forge 工作台       │ │ 钉钉工作台         │            │
│  │ 未分发             │ │ 待接入             │            │
│  │ [配置投放]         │ │ [保存配置]         │            │
│  └────────────────────┘ └────────────────────┘            │
└────────────────────────────────────────────────────────────┘
```

#### 4.1.3 关键改造点

1. **页面标题**：左侧大标题 18px，右侧只有「返回」或「关闭」，不放发布按钮（发布按钮放在状态卡片内）。
2. **状态卡片**：使用 `.app-status-card`；图标按状态变色；右侧按钮用 `n-button` secondary/primary。
3. **访问链接**：使用 `.app-link-display`；左侧显示链接，右侧图标按钮组：复制链接、复制二维码、新窗口打开。
4. **AI 助理卡片**：紫色渐变图标背景，加 `Beta` 标签；未创建时显示引导文案 + 创建按钮。
5. **分发入口**：每个分发目标一张 `.app-card`，内含状态标签 + 操作按钮；钉钉/企微显示「待接入」灰色状态。
6. **历史版本**：可折叠列表，版本号加粗，发布时间用 `app-text-tertiary`。

### 4.2 应用设置页 `application-settings.[applicationCode].vue`

#### 4.2.1 当前问题

- 左侧菜单可能直接使用 `n-menu`，样式偏 Naive UI 默认，缺少产品化氛围。
- 右侧表单字段平铺，缺少「基础属性」「访问地址」「导航设置」「应用权限」等分组卡片。
- 主题色、水印、权限等控件没有形成统一的设置项视觉。
- 权限配置分散在旧应用工作台的「权限」Tab，未与应用设置归集。

#### 4.2.2 目标布局

```
┌─────────────────────────────────────────────────────────────┐
│  应用设置                                            关闭   │
├──────────────────┬──────────────────────────────────────────┤
│                  │  基础属性                                │
│  基础属性        │  ┌────────────────────────────────────┐  │
│  访问地址        │  │  应用图标 / 名称 / 编码 / 描述       │  │
│  导航设置        │  │  主题色  [蓝] [青] [紫] [自定义]     │  │
│  应用权限        │  │  水印开关 + 水印内容                 │  │
│  全球化          │  │  应用状态  启用 / 停用               │  │
│  高级            │  └────────────────────────────────────┘  │
│                  │                                          │
│                  │  应用权限                                │
│                  │  ┌────────────────────────────────────┐  │
│                  │  │  应用管理员                          │  │
│                  │  │  可见范围：全员/角色/部门/用户       │  │
│                  │  │  页面权限：页面树 × 角色/部门/用户   │  │
│                  │  └────────────────────────────────────┘  │
│                  │                                          │
│                  │  访问地址                                │
│                  │  ┌────────────────────────────────────┐  │
│                  │  │  Slug 输入框 + 校验                │  │
│                  │  │  访问链接展示                        │  │
│                  │  │  二维码                              │  │
│                  │  └────────────────────────────────────┘  │
│                  │                                          │
│                  │  导航设置                                │
│                  │  ┌────────────────────────────────────┐  │
│                  │  │  导航风格单选图                      │  │
│                  │  │  显示 Logo / 显示名称 / 允许收起     │  │
│                  │  │  页面排序                            │  │
│                  │  └────────────────────────────────────┘  │
└──────────────────┴──────────────────────────────────────────┘
```

#### 4.2.3 关键改造点

1. **左侧菜单**：使用 `.app-settings-menu`，去掉 `n-menu` 默认的缩进和图标尺寸，改成图标 + 文字一行，选中态用背景色而不是边框。
2. **右侧分组卡片**：每个设置分组一个 `.app-card`，卡片标题 16px 加粗，下方紧跟 `.app-card-desc` 说明。
3. **基础属性卡片**：
   - 应用图标放在表单第一项，图标尺寸 64px，圆角 12px，下方「更换图标」小字链接。
   - 主题色用圆角小方块单选组，当前选中带 `2px` 主色边框。
   - 水印：开关 + 输入框联动，关闭时输入框置灰。
4. **访问地址卡片**：
   - Slug 输入框带前缀 `/app/`，实时校验通过右侧绿色 ✓ 提示。
   - 访问链接只读展示，右侧复制/打开按钮。
   - 二维码用 `qrcode` 组件，尺寸 120px，下方说明文字。
5. **应用权限卡片**：
   - 应用管理员：人员选择器，可多选。
   - 可见范围：全员 / 指定角色 / 指定部门 / 指定用户，单选 + 条件选择器。
   - 页面权限：左侧页面树，右侧权限矩阵（角色/部门/用户 × 查看/编辑/删除），用卡片或表格展示。
6. **导航设置卡片**：
   - 导航风格用「图标示意图 + 单选」形式（左侧导航 / 顶部导航 / 折叠导航）。
   - 页面排序用可拖拽列表，行高 40px，拖拽 handle 用灰色六点图标。

### 4.3 页面管理主入口 `application-runtime.[applicationCode].vue`

> 废弃 `application.[applicationCode].vue` 应用工作台，将 `application-runtime.[applicationCode].vue` 升级为页面管理主入口。创建完应用后直接打开此页面。

#### 4.3.1 当前问题

- Header 是 3 列 grid，中间 designer sections，右侧 actions，信息密度高。
- 左侧导航树把「列表页」「表单页」作为不同节点展示，不符合宜搭「一个业务对象就是一个页面」的感知。
- 缺少系统页面（个人工作台、待办、已办等）的固定入口。
- 右侧默认进入设计态画布，用户必须先理解设计器才能看到数据。

#### 4.3.2 目标布局

```
┌────────────────────────────────────────────────────────────────────┐
│  ←  [icon] 进销存管理                              [设置] [发布]   │
│  草稿 · 未启用                                          [运行应用] │
├───────────────┬────────────────────────────────────────┬───────────┤
│               │                                        │           │
│  系统页面     │                                        │           │
│  ○ 个人工作台 │          右侧内容区                    │  页面     │
│  ● 我的待办   │                                        │  属性/    │
│  ○ 我已办的   │          - 选中系统页：工作台/         │  操作     │
│  ○ 我发送的   │            待办/已办/发送/抄送视图     │  面板     │
│  ○ 抄送我的   │                                        │  (可选)   │
│               │          - 选中用户页：               │           │
│  我创建的页面 │            数据列表/表单预览           │           │
│  + 新建页面   │            点击「编辑」进入设计态      │           │
│  ○ 客户管理   │                                        │           │
│  ○ 订单管理   │                                        │           │
│               │                                        │           │
└───────────────┴────────────────────────────────────────┴───────────┘
```

#### 4.3.3 关键改造点

1. **Header 产品化**：
   - 左侧：返回按钮 + 应用图标 + 应用名称 + 状态标签。
   - 右侧：主按钮「运行应用」；次按钮「设置」「发布」；其余操作（保存、编辑、代码）收到页面上下文或「更多」下拉。
2. **左侧导航分两段**：
   - **系统页面**：固定置顶，包括个人工作台、我的待办、我已办的、我发送的、抄送我的。图标统一使用线性图标，选中态左侧 3px 主色竖条。
   - **我创建的页面**：扁平展示，不再区分列表页/表单页。一个业务对象对应一个页面项。支持拖拽排序、重命名、隐藏。
   - 两段之间用 1px 分隔线 + 12px 间距。
3. **右侧预览态（默认）**：
   - 选中系统页面：渲染对应工作台/待办/已办/发送/抄送视图。
   - 选中用户页面：默认展示数据列表（CRUD 表格）或自定义编排页预览；表格上方有「新增」「导入/导出」「编辑页面」操作。
   - 点击表格行或「新增」时，在当前区域弹出表单抽屉或打开表单页，不跳转新路由。
4. **右侧设计态**：
   - 页面项 hover 显示「编辑」图标按钮，点击后右侧切换为设计态画布。
   - 设计态 Header 增加「保存草稿」「预览」「退出设计」按钮。
   - 画布四周留 16px 灰色边距，画布白色带极淡阴影，形成悬浮感。
5. **新建页面**：
   - 左侧底部「+ 新建页面」按钮，点击后弹出选择页面类型：数据管理页 / 自定义页面 / 外部页面。
   - 数据管理页自动生成列表和表单视图，但在页面树中只显示为一个页面项。

设计器布局：

```
┌────────────────────────────────────────────────────────────────┐

│   多行文本    │  │                       │    │  [name]      │
│   数字        │  │  联系电话             │    │              │
│   日期        │  │  [                  ] │    │  字段类型    │
│   下拉选项    │  │                       │    │  [单行文本 ▼]│
```

- **顶部**：
  - 返回/页面名称。
  - 业务对象信息：「数据对象：customer（客户管理）」，点击可展开编辑对象名称/编码。
  - 操作：预览、保存、发布。
- **左侧组件库**（标签页切换）：
  - **字段组件**：单行文本、多行文本、数字、日期、日期时间、下拉单选、下拉多选、开关、附件、成员、部门、关联记录（P2）。
  - **对象字段**：展示当前业务对象下已创建的所有字段，可直接拖拽到画布复用。
  - **布局组件**：标题、分组、分栏、分割线。
  - **高级组件**：子表、统计卡片（P2）。
- **中间画布**：
  - 表单页：纯表单区域，白色卡片背景。
  - 列表+表单：画布上方固定列表区（自动生成列），下方/抽屉为表单区。

  - 选中字段组件时显示字段标题、字段编码、字段类型、是否必填、默认值、占位提示。
  - 字段编码和字段类型直接可见、可编辑。
  - 底部提供「查看对象结构」和「进入高级对象设计器」链接。

字段组件行为：

- 拖拽字段组件到表单画布 → 自动创建对应业务对象字段。
- 从「对象字段」标签页拖拽已有字段到画布 → 直接绑定已有字段。
- 已存在数据的字段，禁止删除和类型变更，并给出提示。
- 保存页面时原子完成：保存布局 → 创建/更新对象和字段 → 生成/更新列表视图 → 绑定导航。

#### 4.6.4 列表页设计器

- 画布为表格区域。
- 左侧组件库支持标签页切换：
  - **列类型**：文本列、数字列、日期列、标签列、操作列。
  - **对象字段**：展示当前业务对象下已创建的字段，直接拖为表格列。
- 拖拽列类型到表格 → 自动创建业务对象字段。
- 拖拽已有对象字段到表格 → 直接绑定为列。
- 右侧配置列宽、排序、筛选、操作按钮。
- 顶部固定「新增」按钮，点击后弹出对应表单（使用同对象的表单视图）。

#### 4.6.5 自定义页面

- 不强制绑定业务对象。
- 自由拖拽组件：文本、图片、图表、按钮、IFrame、数据卡片等。
- 可作为应用首页或 Dashboard。

#### 4.6.6 字段组件与样式

#### 4.6.7 与 Excel 导入的衔接

- Excel 导入解析表头后，生成默认字段组件列表并填充到表单设计器中。
- 用户在设计器中调整字段类型和布局后保存。
- 保存时一键创建业务对象 + 页面。
