## 3. 核心概念

### 3.1 页面形态

> **一个页面就是一个业务对象的一种形态。**

| 形态 | 说明 | 典型用途 |
|---|---|---|
| 表单页 | 纯表单 | 报名表、登记页 |
| 列表页 | 纯列表 | 数据看板、查询页 |
| 列表+表单 | 上方列表，下方/抽屉表单 | 客户管理、订单管理 |
| 自定义页面 | 不强制绑定对象 | 首页、Dashboard |

### 3.2 字段组件与对象字段

- **字段组件**：单行文本、数字、日期等，拖拽到画布自动创建业务对象字段。
- **对象字段**：展示当前对象已有字段，可直接拖拽复用。
- **两者共存**：设计器左侧组件库支持标签页切换。

### 3.3 业务对象不隐藏

- 创建页面时自动生成业务对象。
- 设计器顶部始终显示对象信息（编码和显示名称），用户可编辑。
- 字段编码、字段类型在属性面板直接可见、可编辑。
- 提供「查看对象结构」和「进入高级对象设计器」入口。

## 4. 实施顺序建议

优先实现 **Task 18：页面形态与字段组件**，这是当前体验最核心的断点。

### 最小闭环（建议先实现）

1. **页面形态选择弹窗**
   - `PageTypeSelector.vue`
   - 输入页面名称，自动推导业务对象编码
   - 选择形态（表单页/列表页/列表+表单/自定义页面）

2. **表单页设计器**
   - 顶部显示对象信息
   - 左侧字段组件库（5 种基础字段：单行文本、数字、日期、下拉、开关）
   - 中间画布
   - 右侧属性面板（字段标题、编码、类型、必填、默认值）
   - 支持从「对象字段」标签页复用已有字段

3. **后端原子保存接口**
   - `POST /ai/business/application/{id}/design-page`
   - 接收页面布局 + 字段列表
   - 原子创建/更新业务对象、字段、列表视图、表单视图

4. **保存后回到页面管理主入口**
   - 新页面出现在左侧
   - 右侧展示数据列表/表单预览
   - 可新增数据

## 6. 验收标准（Task 18）

- [ ] 空白应用进入页面管理主入口后能看到引导卡片

- [ ] 左侧组件库支持「对象字段」标签页，可复用已有字段
- [ ] 表单/列表设计器支持拖拽字段组件到画布，自动创建业务对象字段
- [ ] 字段属性面板支持编辑字段名称、编码、类型、必填、默认值；编码自动生成且可编辑
- [ ] 已存在数据的字段禁止删除和类型变更，并给出明确提示
- [ ] 保存后后台原子创建/更新对象、字段、列表视图、表单视图，无中间失败残留
- [ ] 新页面出现在页面树中，右侧可预览数据列表/表单/列表+表单，并可新增数据

---

## 7. 注意事项

- **不要完全隐藏业务对象**：设计器顶部要显示，属性面板要展示字段编码和类型。
- **页面编码即对象编码**：创建页面时页面名称和编码同步给对象。
- **已存在数据的字段保护**：禁止删除和类型变更。
- **保存时原子操作**：布局 + 对象 + 字段 + 视图一起保存，避免中间失败残留。
