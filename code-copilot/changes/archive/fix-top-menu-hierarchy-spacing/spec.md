# 顶部菜单层级与间距优化

## 背景

顶部菜单的子菜单被压平成一层，并把父级路径拼成“父级 / 子级”文案。多级菜单无法按真实层级展开，菜单项之间的间距也过小，影响扫描和定位。

## 变更范围

- 顶部菜单下拉数据保留真实父子层级，不再拼接斜杠路径。
- 下拉层支持目录继续展开子菜单，叶子菜单保持原有路由跳转和权限过滤。
- 顶级菜单之间增加可感知但克制的间距。
- 保持顶部菜单的滚动、当前路由高亮、外链和 SSO 跳转行为。

## 验收标准

1. 顶部菜单打开后，父级目录和子级菜单分层显示，不再出现“父级 / 子级”。
2. 多级目录可以继续悬停或聚焦展开，点击叶子菜单仍进入原页面。
3. 当前页面对应的顶级菜单、目录和叶子菜单均能保持高亮。
4. 顶级菜单之间有清晰间距，窄屏下菜单仍可横向滚动。
