# 流程模型配置与业务绑定修复

## 背景

流程模型新增弹窗中模型 Key 被两列布局压缩，审批退回和待办跳转等低频配置占用基础信息区域；流程列表对已绑定业务流程的旧数据和业务表单引用识别不完整。

## 范围

- 模型 Key 独占整行并保留校验说明。
- 审批退回、待办跳转迁移到流程设计页“更多设置”的审批与待办面板；新模型预填默认待办详情地址。
- 流程绑定反查兼容 FLOW/APPROVAL 绑定、应用关联字段和业务表单引用兜底，不改变运行时绑定语义。

## 验收标准

- 新增/编辑弹窗不再展示审批退回和待办跳转，模型 Key 不拥挤。
- 设计页可保存 allowMultiReturn 和 todoDetailUrlTemplate，空地址仍由后端默认处理。
- 已绑定业务应用的模型卡片显示应用/对象信息，不再误报未绑定。
