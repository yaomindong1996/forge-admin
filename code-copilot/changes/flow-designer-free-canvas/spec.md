# 流程编排自由画布（拖拽节点 + 手动连线）

## 已确认需求

用户对照两张编排设计稿，要求 `/flow/model` 设计器从「钉钉式自动串链」改为可自由布局：

- 节点可拖拽移动；连线可手动创建 / 调整，复杂流程不再被自动布局挤乱。
- 左侧节点货架拖入画布创建节点，不必只能点连线「＋」插入。
- 删除中间节点只移除该节点并重连入出边；删除条件/并行网关不得级联删除分支上的后续审批节点。
- 保留现有节点配置抽屉、撤销/重做、BPMN 往返与发布能力；可选「自动布局」一键恢复树状排版。

## 范围与约束

- 只改前端 `flow-designer` 与相关 DESIGN 说明；不改后端协议、鉴权、数据库。
- `flowJson` 节点增加可选 `uiPosition: { x, y }`；BPMN 导出写入 `BPMNShape` Bounds，导入回读，保证保存后布局不丢。
- 连线上的「＋」插入与网关加分支仍可用；货架拖入默认不自动串链，由用户手动连线或继续用「＋」。
- 网关删除改为软删：只删网关，入边接到原各分支出口，保留分支条件元数据与分支节点。
- DingFlowDesigner 主 SFC 不超过 1000 行；交互抽 composable / 子组件。
- 本轮日常开发，不升版、不提交除非用户另行授权；可感知变更记入 `CHANGELOG.md` Unreleased。

## 验收

1. 拖拽节点后位置保持；刷新/重新打开已保存模型后布局一致。
2. 端口拖出可连到另一节点；重复连线被拒绝；可删边不删节点。
3. 删除条件网关后分支审批节点仍在，上游接到原分支入口。
4. 「自动布局」清除手动坐标并恢复树状布局。
5. 相关 Vitest、ESLint、设计器主路径不回归。

## 风险

查看器只读复用布局；无 `uiPosition` 时仍走自动布局。游离未连线节点可设计但发布前需用户自行连成可执行图（与现有校验一致，本轮不新增后端校验）。
