# 审批流程设计器：低饱和工作台改版

## 已确认需求

2026-10-20，用户确认按最新设计稿第一张 `a-canvas-soft-v3.png` 落地：白色节点卡片、低饱和语义图标、蓝色交互、居中的流程与顶部页签、紧凑的添加节点菜单、右下角画布工具栏。

## 范围与约束

- 只改管理端流程设计界面及其相关组件；当前分支 main，保留其他未提交工作。
- 顶部展示真实流程名称和状态；返回、更改记录、AI、保存、发布沿用现有动作。
- 画布白卡双行排版、去左侧色条/整块彩底/重阴影，主操作跟随系统主题；类型颜色仅限小图标。
- 添加菜单将常用审批/分支前置，高级类型默认折叠但全部保留。
- 缩放、适应画布、全屏、移动说明、撤销/重做入口保持可用，窄屏和深色主题不得溢出。
- 条件分支以清晰的条件卡展示真实配置；复杂回流场景保留紧凑标签，不能改变分支顺序或 BPMN 拓扑。
- 节点配置保留所有页签、草稿取消/确认、全局保存前提交草稿行为。不新增业务规则、不改后端/数据库/鉴权/部署。
- 顶部工具栏独立拆分，存量编排页降到 1000 行以内；不新增跨层状态透传，不扩大存量业务状态重构。
- 本轮是日常开发，不升版本、不提交/push、不部署；可感知变更记入 Unreleased。

## 验收

1. 与第一张稿保持相同的信息层级、白卡、图标语义和克制配色，不复制示例数据到真实页面。
2. 主路径新增、配置、取消、删除、撤销/重做、XML 往返不回归。
3. 菜单不会被缩放/视口裁切；高级节点可展开；键盘焦点可见。
4. 适应画布使用真实内容边界，不是简单重置原点。
5. ESLint、设计器相关 Vitest、前端构建通过；使用本地组件验证页进行真实浏览器点击/截图，不调用真实业务写接口。

## 风险

设计器与只读查看器共用部分节点组件：通过 readonly 与局部主题变量保持状态徽章和只读行为。画布坐标调整仅作用编辑器，不修改 BPMN 序列化布局/协议。真实环境流程发起/发布不在本轮验证范围。
