## 技术决策

| 决策 | 选择 | 放弃的方案 | 原因 |
|---|---|---|---|
| 表数据接入 | 复用已发布数据集 | 打印模块直接查任意表/SQL | 复用 ACL、行范围、参数 schema，降低注入风险 |
| 业务接入 | Provider + sourceCode | 前端传 Bean 名/接口 URL | 服务端受控注册和授权 |
| 页面来源身份 | 按租户用 sourceCode 运行时解析 | 页面写死业务来源数据库 ID | 配置稳定，避免跨环境 ID 不一致 |
| 页面传值 | 后续短时数据会话 | URL/请求直接携带任意正文 | 不把客户端正文默认视为权威业务数据 |
| 兼容策略 | 应用来源和独立来源双路径 | 一次性重写旧表/旧协议 | 降低低代码与流程打印回归风险 |
| 菜单迁移 | 新增 V1.0.205 修复并复用原 `/print` 资源 | 回改 V1.0.204 或删除重建资源 | 保持 Flyway 校验和与既有角色授权，避免应用总览再次被子路由挤掉 |
