# 工作台与资产列表插画优化

日期：2026-10-03。分支：`codex/workbench-illustrations`，基于最新 `origin/main`。

## 需求与范围

首页过于单一，应用中心和流程模型卡片缺少轻量视觉点缀。生成同系列的蓝白灰透明插画，接入真实页面。

- 首页：欢迎区加入工作台插画、优化文字与统计层级；待办与应用空状态使用同系列插画。
- 应用中心：卡片正文加入小幅应用插画，保留后端配置图标；常用编辑/发布/运行操作固定显示。
- 流程模型：对象识别区使用流程插画，空状态保持相同主题；搜索、排序、发布逻辑保持既有协议。
- 扩展复用：应用访问入口卡片、打印中心及模板空状态采用统一组件。
- 首页和应用中心先将样式分离，使 SFC 规模回到 1000 行以内。
- 修正本轮涉及的 scoped 暗色选择器作用范围，避免卡片样式落到 html 根节点；提高暗色操作文字的对比度。

## 视觉边界

沿用 DESIGN.md 的紧凑后台卡片、主题色、浅边框、明暗主题和常用操作规则。用户本轮明确要求插画，因此允许小幅静态资产插画点缀；不添加装饰色条、随机配色、营销标签或持续动画。

插画为装饰性资源，使用 `alt=""` / `aria-hidden`，不替代真实业务名称、状态、后端图标和权限数据。窄屏缩小欢迎区插画；正文和操作不被图片覆盖。

## 验证与交付

目标文件 ESLint、生产构建、现有首页应用入口测试、实际组件的桌面/窄屏/暗色浏览器预览。线上地址当前需要登录，预览样例须明确标识；不宣称真实后端联调通过。不更改后端、数据库、菜单和权限。

资源只提交压缩后的透明 WebP，提示词保存在本变更目录。完成后自动 commit，push 等用户请求。
