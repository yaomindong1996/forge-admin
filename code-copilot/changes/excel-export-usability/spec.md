# Excel 导出配置易用性优化

## 目标

优化 `/system/excel-export-config` 及其“列配置”弹窗，让业务管理员以“导出方案”的方式理解和维护配置，减少配置键、Bean、查询方法等技术字段对日常操作的干扰。

## 用户体验

- 列表首屏优先展示方案名称、用途（导出/导入）、文件名、列数/配置状态和最后更新时间；配置键、数据源 Bean、查询方法等作为辅助信息或详情中的高级设置。
- 搜索使用“方案名称 / 用途 / 状态”等业务文案，技术键名收纳到“更多条件”。
- 新增/编辑分为“方案信息”“导出内容”“导入模板”“高级设置”，根据用途动态显示；默认值和示例文案帮助非技术人员完成配置。
- 状态在列表直接切换，停用和删除有明确影响说明；复制配置说明副本会默认停用。
- 列配置弹窗展示“导出列预览”，使用列名作为主信息、字段名作为辅助信息；提供上移/下移、编辑和删除，保存按钮明确提示未保存变更。
- 亮色/暗色、小屏抽屉或弹窗布局保持紧凑、可访问，不使用营销式渐变或大卡片。

## 范围

- 前端：`excel-export-config.vue`、`excel-column-config.vue`、必要的页面测试和验证预览。
- 后端 API/数据库协议保持兼容；只在前端做文案、排序、状态交互和表单体验优化。

## 验收标准

- 业务人员无需理解 configKey、Bean、queryMethod 即可完成常用导出方案配置和列配置。
- 列表操作不超过两个直显常用操作，其余进入“更多”；状态切换成功后列表显示权威状态。
- 导出测试、复制、删除、列配置保存等现有能力不回归。
- ESLint、前端构建和关键交互测试通过。
