# 运行时许可证验证基线

> apply · 2026-10-08 · 与 website/plugin-commercial-platform T3 共用协议

用户确认客户账号 ID＋项目安装 UUID 绑定，同项目多节点，不绑定 IP/MAC。
本轮在既有 starter-plugin 中新增可移植、默认关闭的验证能力，不猜测 Pro 品牌与包名。

- Ed25519 签名原始 payload 字节；协议 v1，固定算法、受信任 keyId、公钥固定配置。
- 载荷绑定客户/项目、精确插件与 ee 功能、使用期限和独立维护期限。
- 每次 Gate 查询检查使用期限；维护到期不停止永久使用。
- 多份许可证叠加；缺失/无效单份授权失败关闭，社区功能不受影响。
- 新自动配置先于社区默认 Gate；用户自定义 Gate 优先，不改变已有 Web 鉴权。
- 文件限大小、拒绝符号链接，严格 JSON/重复键/未知字段，验签后解析载荷。
- 仅离线验证；撤销需后续状态同步，源码交付不承诺不可破解。
- 不签发真实客户授权、不创建生产密钥、不授予权限、不部署或 push。

权限人工审查：用户已确认商业授权能力与绑定；本轮仅实现默认关闭的签名验证扩展。
回滚：关闭 forge.license.enabled，恢复社区 Gate；保留原授权文件供审计，不删除业务数据。
既有未提交 plugin-center 等改动不混入本轮提交。

## L4 客户项目授权诊断（2026-10-09）

在既有插件中心增加“运行时授权”只读页签，闭合部署后的可观察性，不扩展交付/部署权限。

- 诊断复用启动时真实验签结果，与 FeatureGate 使用同一份不可变快照和同一状态判断。
  刷新仅重新判断当前期限，不读文件、不热加载、不访问授权服务器。
- 展示实际 Gate 模式（社区/许可证/自定义/不可用）、合法配置绑定、公钥成功/失败数量，
  按配置顺序显示文件序号、有效/未生效/过期/绑定不符/无效及匹配绑定的授权范围和期限。
- 未验签及绑定不符的文件不返回声明的 ID、范围、期限；所有情况都不暴露路径、载荷、签名、密钥或异常文本。
- 查询复用 system:plugin:list 与 SessionHelper.assertAdmin，保持仅平台超级管理员可查；
  不新增角色授权，不因许可证失效阻止查询，不支持前端传入客户/租户/文件位置。
- V1.0.215 仅补诊断状态与模式字典，tenant_id=1、NOT EXISTS；不修改已有迁移、菜单归属或业务记录。
  状态是内存读视图，不做数据库状态流转，不签发或撤销授权。
- UI 沿用 Naive UI、DictTag/useDict 和主题变量，独立 Pinia 管理查询，防止权限/账号切换后的旧响应回填。
- 用户“继续”沿用已确认的授权体系；本轮没有新增付费权益、权限放开、资金或运行态写入。
  不连接共享库，不自动执行迁移、部署、push 或创建未确认名称的 Pro 工程。

回滚：回退新增页签和接口；诊断字典保留无害，不删除历史数据；原验签功能及签名协议保持兼容。
