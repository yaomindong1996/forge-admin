## 已完成修复

- 恢复五项长期排除的 Java 测试源码；修正旧反射、编码、构造参数、H2 结构与 Mock 夹具。
- 低代码字段计算辅助方法不再污染 JSON，旧辅助标志不能覆盖实际类型/只读属性。
- 打印固定版本快照保留 isDefault；来源 DTO 的新字段只允许 null，非空独立来源不能混入应用来源。
- LOOKUP 错误降级值保留在结果中，同时保留失败/错误 trace；公式配置错误按既有规范阻断发布。
- Agent 首次请求先用可信身份占用会话，再校验/创建所属会话、读取历史、绑定模型和落消息。
  外来/已删除/冲突 ID 被拒绝；竞争请求不能提前修改会话，首条消息标题保持原协议。
- SSE 复用 ai:engine:stream，并从已存储会话验证所有者；用户/租户隔离、多读者、旧断连/新注册、终止清理通过。
- 图像工具读取服务端 extraConfig.imageModelId，校验当前 Agent、启用模型及供应商、图像类型和租户。
  支持存量 image 类型；参数不能指定其它 modelId/providerId/API Key。无配置明确失败，不自动选择付费模型。
- 用户确认保持现有 MCP 客户端鉴权；不伪造客户端、确认 exchange 或额外授权。
- 列表设计器先等待布局初始化再选中嵌套组件；布局更新不反复覆盖手动选择，空节点抽屉不读 null。
- 幂等 Token 只接受明确 UNUSED；缺失/未知/已消费拒绝，日志不再记录 Token 正文。

## 图像配置示例（服务端）

在有 Agent 维护权限的页面设置 extraConfig，填当前租户已启用的图像模型数据库 ID：

```json
{"imageModelId": "<当前租户的图像模型ID>"}
```

此 ID 不是供应商 modelName，也不是 providerId；模型生成的参数不能覆盖它。
