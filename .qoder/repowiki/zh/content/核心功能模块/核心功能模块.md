## 简介
本文件面向 Forge Admin 的核心功能模块，覆盖系统管理、AI 能力中心、低代码平台、工作流引擎、AI 数据大屏等模块。文档从功能概述、核心特性、使用场景、技术实现、模块间依赖与数据流转、配置选项与使用示例等方面展开，并辅以架构图、时序图、流程图和类图，帮助开发者快速理解各模块的作用与集成方式。

## 项目结构
Forge Admin 采用“微内核 + 插件化”的分层架构：
- 后端分层：forge-framework（Starter 基础能力）+ forge-plugin-parent（业务插件）+ 应用服务（聚合插件对外暴露接口）。
- 前端工程：后台管理前端 forge-admin-ui、AI 大屏前端 forge-report-ui、移动端 H5 forge-h5-ui。
- 报告服务：独立的 AI 大屏报表服务 forge-report-server，提供大屏项目、模板、素材等能力。
- 流程服务：独立流程服务 forge-flow（Flowable 编排），通过客户端与服务端协作完成建模与执行。

## 核心组件
- 系统管理：用户、角色、菜单、部门、岗位、租户、字典、日志、任务、文件、通知等基础管理能力，支持多租户隔离与 RBAC。
- AI 能力中心：智能体管理、供应商管理、会话管理、提示词模板库、能力开放平台（能力目录、客户端、授权与安全调用）。
- 低代码平台：对象设计器、表单/列表设计器、页面构建、业务流程编排、一键发布到门户。
- 工作流引擎：基于 Flowable 的流程建模、发起、审批、时间轴追踪；JSON→BPMN 转换与可视化编辑。
- AI 数据大屏：自然语言生成大屏、组件拖拽、主题定制、数据接入、事件交互、一键发布。

## 架构总览
整体采用前后端分离与多服务协同：
- 后台管理前端通过统一网关访问主后台服务、流程服务与大屏服务。
- 主后台服务承载系统管理与通用能力，并通过插件体系扩展。
- 流程服务独立部署，提供 BPMN 建模与执行能力。
- 大屏服务提供项目、版本、模板、素材等能力，并与 AI 能力中心联动生成大屏。

## 详细组件分析

### 系统管理模块
- 功能概述：提供用户、角色、菜单、组织、岗位、租户等基础管理能力，支持批量导入导出、操作审计、敏感字段脱敏。
- 核心特性：
  - 用户全生命周期管理：分页查询、详情、新增、修改、删除、状态管理、密码重置、资料更新。
  - 多维绑定：用户-角色、用户-组织、用户-岗位、用户-租户的灵活绑定与解绑。
  - 审计与脱敏：操作日志记录、前后快照对比、手机号/邮箱/身份证脱敏。
  - 多租户上下文：根据登录用户类型与租户上下文返回可访问租户集合。
- 使用场景：企业后台的用户与权限治理、SaaS 租户隔离、RBAC 资源控制。
- 技术实现要点：
  - Controller 层提供 RESTful 接口，结合 Service 层完成业务逻辑。
  - 通过 OperationAuditContext 记录操作前后数据差异，便于审计追溯。
  - 对敏感字段进行统一脱敏处理，避免泄露。
  - 租户维度数据隔离与可见性控制。

### AI 能力中心
- 功能概述：统一管理 AI 能力目录、客户端、授权与安全调用，支撑智能体、流程动作、高风险审批等能力的开放与治理。
- 核心特性：
  - 能力目录：能力编码、协议工具名、名称、描述、来源、版本、行为、风险等级、可见性、发布状态等。
  - 客户端管理：机器客户端注册、密钥轮换、签名密钥轮换、撤销、用户断言映射。
  - 安全与审计：能力调用日志、授权校验、高风险审批策略。
- 使用场景：将 AI 能力以标准化方式对外暴露，供流程动作、低代码平台、外部系统集成调用。
- 技术实现要点：
  - 控制面表结构与迁移脚本维护能力元数据与索引。
  - 前端通过能力 API 进行启用/禁用、更新、下载 OpenAPI/Markdown、客户端管理等。

### 低代码平台
- 功能概述：通过对象设计器、表单/列表设计器、页面构建器，实现低代码应用快速搭建与发布。
- 核心特性：
  - 对象建模：领域划分、数据模型、字段与关系设计。
  - 页面构建：表单与列表可视化设计、联动规则、视图配置。
  - 业务流程编排：将低代码对象与流程模型绑定，实现审批与自动化。
  - 一键发布：将应用发布到独立门户，支持预览与分享。
- 使用场景：企业内部管理系统、审批流业务、数据录入与展示。
- 技术实现要点：
  - 前端通过对象设计器与表单/列表设计器维护页面 Schema。
  - 后端通过业务应用服务构建页面资产，支持表单设计器 Schema 与视图 Schema 的统一管理。

### 工作流引擎
- 功能概述：基于 Flowable 的流程建模与执行，支持 JSON→BPMN 转换、可视化编辑、节点配置、变量与权限控制。
- 核心特性：
  - JSON→BPMN 转换器：将前端流程 JSON 转换为标准 BPMN XML，包含流程属性、节点与连线、图形布局。
  - 节点配置：用户任务、条件分支、抄送、自动审批模式等。
  - 可视化编辑器：拖拽式画布、实时预览、版本管理。
- 使用场景：请假、采购、合同、报销、工单等需要流程编排的业务。
- 技术实现要点：
  - 前端转换器负责生成 BPMN XML，确保 process id 与 diagram 元素正确指向。
  - 后端 Flowable 引擎负责流程部署、启动、任务流转与时间轴追踪。

### AI 数据大屏
- 功能概述：通过自然语言生成大屏草稿，再经可视化编辑器调整组件、数据源、主题与交互，最终发布为可访问页面。
- 核心特性：
  - AI 智能生成：对话式生成大屏结构、组件布局与基础配置。
  - 组件素材库：图表、文字、图片、视频、滚动表格、装饰边框、数字翻牌等。
  - 主题定制：深浅主题、背景、全局滤镜、画布尺寸与自适应方式。
  - 数据接入：静态数据、动态 HTTP 请求、数据池。
  - 事件交互：点击、双击、鼠标进入/移出、生命周期事件与自定义 JavaScript。
  - 一键发布：生成预览链接，便于分享、嵌入与交付。
- 使用场景：数据驾驶舱、运营监控大屏、营销看板。
- 技术实现要点：
  - 后端记录 AI 生成明细（项目、供应商、模型、画布尺寸、提示词、响应、统计指标等）。
  - 前端提供 AI 生成接口与流式生成能力，支持 SSE 推送。
  - 大屏项目控制器提供项目 CRUD、版本管理、发布与回滚。

- 性能考虑：

## 故障排查指南
- 首次启动报数据库或 Redis 连接错误：
  - 检查 application-dev.yml 是否正确复制并配置 MySQL、Redis 连接信息。
- 前端请求后端失败：
  - 确认后端端口已启动，检查 .env.development 中的代理目标地址是否指向本地服务。
- 新增配置项注意事项：
  - 本地敏感配置不要提交；通用配置请同步到 example 文件并使用占位符。
- 不小心提交敏感配置：
  - 立即更换相关密码或密钥，清理仓库历史与当前索引中的敏感文件，补充 .gitignore 规则。
