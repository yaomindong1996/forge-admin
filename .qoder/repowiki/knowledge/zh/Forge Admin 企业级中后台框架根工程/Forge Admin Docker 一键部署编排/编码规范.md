- 所有外部依赖（MySQL、Redis、Flowable 客户端 URL、加密密钥等）一律通过环境变量 `${VAR:-默认值}` 注入，不在镜像内硬编码生产凭据。
- 每个 Java 服务采用双阶段 Dockerfile：builder 阶段用 JDK 执行 `mvn clean package -pl <module> -am -DskipTests -Pprod`，运行阶段仅拷贝 jar 到 JRE 镜像。
- Compose 中所有服务均声明 `restart: unless-stopped`、`healthcheck`（mysql 用 mysqladmin ping、redis 用 redis-cli ping）以及独立的 `forge-network` bridge 网络。
- Nginx 统一暴露 80 端口，将 `/forge/` 作为前端 alias，并按路径前缀区分 `/forge-api/api/flow/` → forge-flow 与 `/forge-api/` → forge-admin 的反向代理规则。
- `docker-forge-admin` 通过 volume 将宿主 `application-datasource.yml` 映射为 `/app/application-prod.yml`，并以相同方式挂载 `../forge-server/db/migration`，使数据源与迁移脚本与镜像解耦。
