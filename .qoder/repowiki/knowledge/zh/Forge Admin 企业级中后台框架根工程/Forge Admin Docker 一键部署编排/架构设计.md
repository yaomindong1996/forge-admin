本模块是 Forge Admin 的容器化部署层，按用途拆分为两个并列目录：
- `docker/`：基础一键部署编排，使用多阶段构建（builder 镜像 + JRE 运行镜像），通过 `docker compose up -d` 启动 mysql、redis、forge-flow、forge-admin、forge-ui 五个服务，统一走 bridge 网络 `forge-network`；Nginx 在 `/forge/` 下提供静态页面，并将 `/forge-api/api/flow/` 反向代理到 forge-flow:8081，其余 `/forge-api/` 代理到 forge-admin:8580。
- `docker-forge-admin/`：生产增强版编排，除镜像相同外，额外通过 volume 将宿主的 `application-datasource.yml` 映射为 `/app/application-prod.yml`，并把 `../forge-server/db/migration` 挂载进应用以支持 Flyway/Liquibase 迁移；MySQL 通过挂载 `init-sql/01-init.sql` 到 `/docker-entrypoint-initdb.d` 完成首次建库建表（26000+ 行 DDL，覆盖 AI Agent、业务对象、能力授权、数量余额等核心域）。
依赖方向严格由 Compose `depends_on` 与 `condition` 控制：mysql/redis 健康检查通过后启动 forge-flow，forge-flow 启动后再启动 forge-admin，最后启动 forge-ui；所有敏感配置（MYSQL_PASSWORD、REDIS_PASSWORD、FORGE_CRYPTO_* 等）通过 `.env` 注入，默认值集中在 Compose 中 `${VAR:-default}`。
