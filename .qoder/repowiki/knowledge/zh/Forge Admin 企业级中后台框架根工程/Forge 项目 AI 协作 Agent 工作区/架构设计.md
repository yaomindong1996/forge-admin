该模块是面向已有 Java/Vue 工程的 AI 协作约定与知识库，按职责划分为五个目录：
- `agents/`：定义 Agent 角色与命令协议（如 `copilot-prompt.md` 中的 `/propose`、`/apply`、`/fix`、`/review`、`/test`、`/archive`），并附带 code-quality-reviewer、spec-reviewer 等专用 prompt。
- `changes/`：以“变更名”为单位组织需求生命周期文档，每个变更目录通常包含 `spec.md`、`tasks.md`、`execution-log.md`、`test-spec.md`，部分归档在 `changes/archive/`；`templates/` 提供新变更的模板。
- `rules/`：存放工程级约束，包括 `coding-style.md`、`automated-testing-standard.md`、`project-context.md`（由 `/spec:init` 自动生成）。
- `knowledge/`：专题技术知识索引（`index.md` 指向各 `tech-*.md`），用于沉淀公式引擎、多租户隔离、Spring Boot 自动配置等技术约定。
- `memory/`：长期记忆层，含 `decisions.md`、`pitfalls.md`（按 frontend/lowcode/flow/security/db-flyway/capability/backend 分类索引）、`preferences.md`（用户偏好清单）。

优先级链路由根 `AGENTS.md` 明确：根 AGENTS > 当前变更 spec > tasks/log/test-spec > rules > 本文件。Agent 启动时按顺序加载 preferences + pitfalls 索引，再按需打开具体分类，避免通读全部记忆。变更流程遵循 No Spec No Code 原则，所有代码修改必须同步更新对应 changes 文档并通过 git commit 记录。
