- 客户端所有 HTTP 调用统一通过 `FlowClient` 的私有 `get/post/put` 方法封装，统一设置 `X-Inner-Call: true` 头并序列化/反序列化为 `FlowResult<T>`。
- 认证令牌优先从 `FlowTokenProvider` 动态获取，失败时降级到静态 `token` 字段，再为空则不携带 Authorization。
- Controller 按领域职责拆分为独立的类文件（如 Instance、Task、Model、Form、Notify 等），每个控制器对应一组 REST 资源。
- DTO 集中在 `dto` 包下，以 `*DTO` 命名表示单一操作请求体（如 `FlowTaskApproveDTO`、`FlowInstanceStartDTO`）。
- 自动装配通过 `@AutoConfiguration` + `@EnableConfigurationProperties` + `@ConditionalOnMissingBean` / `@ConditionalOnProperty` 组合实现可选功能开关。
- 桥接适配器采用 `*Adapter` / `*AdapterImpl` 命名约定，将外部系统能力（AI、权限、菜单、业务对象运行时、监控用户）解耦注入。
