模块为 Maven 多模块聚合工程（pom.xml），包含两个子模块：
- forge-flow-client：面向调用方的 Spring Boot Starter，通过 `FlowClientAutoConfiguration` 在 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中注册自动装配，提供 `FlowClient`（基于 RestTemplate 封装对 `/api/flow/**` 的 HTTP 调用）、`FlowTokenProvider` 抽象及默认 `RequestContextFlowTokenProvider` 实现，支持静态 token 与动态上下文透传；`helper` 包提供注解式流程启动切面（`FlowStartAspect`、`FlowCallback`、`FlowComplete`、`FlowEventContext`、`FlowBind`），`job` 包提供远程任务执行器 `RemoteJobFlowExecutor`，`spi` 包暴露业务列表展示适配接口。
- forge-flow-server：Spring Boot 可执行应用（`ForgeFlowApplication`，扫描 `com.mdframe.forge` 并 `@MapperScan` MyBatis mapper），依赖 `forge-plugin-flow` 核心业务逻辑以及 ORM/Tenant/Web/Auth/ID/AI/Generator/Collaboration 等 Forge Starter/Plugin，通过 `controller` 层按领域拆分（Instance/Task/Model/Form/Category/Comment/Notify/Org/Monitor/SpelTemplate/Workspace/JobFlow 等 20+ Controller）对外暴露 REST API，`bridge` 包作为外部能力适配器（AI、权限、菜单、业务对象运行时、监控用户查找），`dto` 集中定义请求体，`identity` 提供会话身份封装。
依赖方向：server 依赖 client（供生成器反向调用），client 不依赖 server；两者均通过 Spring Boot 自动装配机制集成到宿主应用。
