- 迁移脚本统一采用 `V<语义化版本>__<下划线分隔英文说明>.sql` 命名，版本号严格递增且仅允许小写英文、数字与下划线。
- 新建表必须包含 `tenant_id`、`create_by`、`create_time`、`create_dept`、`update_by`、`update_time` 等 Forge 标准审计字段，并使用 `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci`。
- 种子数据文件按用途分目录并以特定前缀命名：必需数据用 `R__`、演示数据用 `D__`、可选数据用 `O__`，且要求幂等、不含本地测试或敏感数据。
- 迁移脚本中对已有数据的回填/对齐操作使用 `INSERT INTO ... SELECT ... WHERE NOT EXISTS (...)` 模式保证幂等性。
- 新增表结构变更一律以增量 `ALTER TABLE` 形式追加到 `migration/`，禁止直接修改历史文件或手工执行完整 SQL。
