目录按职责划分为四个子空间：
- `migration/`：Flyway 增量迁移脚本集合，以 `V1.0.x__描述.sql` 命名，首个 `V1.0.0__baseline.sql` 仅声明基线（历史结构由 `forge-admin-server/sql/初始化脚本.sql` 提供），后续所有表结构变更通过版本号递增追加。
- `seed/required|demo|optional`：三类种子数据，分别对应系统启动必需数据（如字典、配置、资源）、演示数据、可选模块数据，文件前缀 `R__`/`D__`/`O__` 区分类型。
- `backup/`：用于社区版同步时隔离的历史备份迁移集，独立于主 `migration/`。
- `community-export/`：由 `export-community-db.sh` 导出的产物目录（含 `schema-summary.json`、`seed-summary.json`、`summary.md` 及对应的 `migration/`、`seed/` 子集），默认被 `.gitignore` 忽略。

运行期依赖外部脚本 `forge/scripts/db/init-db.sh` 串联执行顺序：建库 → 初始化脚本 → `migration/*.sql` → `seed/required/*.sql`，并通过 `--with-demo` / `--with-optional` 开关控制演示与可选数据导入；Flyway 自动迁移默认关闭，需设置环境变量 `FORGE_FLYWAY_ENABLED=true` 并在 Spring Boot 中指向 `./db/migration`，使用 `forge_schema_history` 表记录版本。
