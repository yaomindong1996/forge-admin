首次初始化需先复制 `application-dev.example.yml` 为 `application-dev.yml` 并填写 MySQL/Redis 连接信息，再执行 `bash forge/scripts/db/init-db.sh --host ... --database forge_admin --user root --password ... [--with-demo] [--with-optional]`；启用 Flyway 自动迁移需设置 `FORGE_FLYWAY_ENABLED=true`；社区导出使用 `bash forge/scripts/db/export-community-db.sh [--dry-run]`，白名单/黑名单/敏感字段规则在 `forge/scripts/db/community-db.config.json` 中配置。
