- 所有 Bash 脚本以 `#!/usr/bin/env bash` 开头并使用 `set -euo pipefail` 严格模式，通过 `SCRIPT_DIR` 相对路径解析项目根目录。
- CLI 参数统一采用 `--flag VALUE` 长选项风格，通过 `while [[ $# -gt 0 ]]; do case ... esac` 循环解析，并提供 `usage()` 帮助函数。
- 数据库字符集与排序规则统一硬编码为 `utf8mb4_0900_ai_ci`，并在建库、改库、连接层多处显式声明以保证一致性。
- Node 脚本通过 `fileURLToPath(import.meta.url)` 定位自身目录后，从同级的 `community-db.config.json` 动态加载配置，避免硬编码路径。
- 敏感数据与运行时表通过集中数组/正则白名单管理（如 `sensitive_tables`、`log_regex`、`allowedPrefixes`），新增条目只需修改常量而非逻辑分支。
- 导出/检查脚本均支持 `--dry-run` 模式，在不落盘的情况下打印计划命令或汇总信息以便审计。
