- 对来自其他插件接口但本服务不应实现的抽象，统一在 `bridge` 包下以 `App*Adapter` 命名并提供 `@Component` 空实现或失败关闭实现，用于完成 Spring 容器装配。
- 适配器中对不支持的能力采用两种策略：抛出 `UnsupportedOperationException`（如权限管理）或返回 `AiClientResult.fallback(...)` / 记录 debug 日志后静默跳过（如菜单注册、AI 调用）。
- 配置文件使用 `@...@` 形式的 Maven 资源过滤占位符（如 `@profiles.active@`、`@logging.level@`）在构建期注入环境差异。
