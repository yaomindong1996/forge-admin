模块为独立的 Spring Boot 可执行应用，入口 `ForgeAppServerApplication` 使用 `@SpringBootApplication(scanBasePackages = {"com.mdframe.forge"})` 扫描整个 forge 包，并通过 `@MapperScan("com.mdframe.forge.**.mapper")` 与 MyBatis-Plus 集成，依赖父工程 `forge-server`。

- 依赖方向：仅作为运行时消费者引入 `forge-plugin-system`、`forge-starter-web/auth/config/id/crypto/api-config`、`forge-plugin-message`、`forge-plugin-collaboration`、`forge-plugin-generator` 以及可选的 `forge-flow-client`；不引入 `forge-plugin-job`，因此 Quartz 调度器不会启动。
- 边界隔离：`bridge` 子包提供三个 `@Component` 适配器实现——`AppAiClientAdapter`、`AppApplicationPermissionAdapter`、`AppMenuRegisterAdapter`，分别实现 `AiClientAdapter`、`ApplicationPermissionAdapter`、`MenuRegisterAdapter`，将 App 服务中不应暴露的 AI 生成、应用权限管理、菜单注册等 Admin 能力以失败关闭或无操作方式注入容器，避免 App 服务错误引入管理插件。
- 配置层：`application.yml` 基于 Undertow 提供 HTTP 服务（端口 8583），启用 Sa-Token + Redis 会话、MyBatis-Plus 多 mapper 扫描、Jackson/Spring MVC 基础设置，并通过 `profiles.active: @profiles.active@` 与 `logging.level: @logging.level@` 在构建期注入 profile 与日志级别；同时暴露 Actuator health 端点。
- 部署产物：通过 `spring-boot-maven-plugin` 打包为可执行 jar，并额外配置 `maven-war-plugin` 支持 war 发布。
