- 每个 Starter/Plugin 均为独立 Maven 模块，拥有独立的 `src/main/java`、`resources`、`sql` 目录及 `pom.xml`，并通过 `flattened-pom.xml` 发布。
- 业务代码统一采用 controller/service/mapper/entity/dto/vo 分层结构，SQL 映射放在 `resources/mapper`，建表脚本放在 `resources/sql`。
- Spring Boot 自动装配通过 `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明，而非 XML 配置。
- 数据库变更使用 SQL 脚本（如 `*_tables.sql`、`init_data.sql`）配合 MyBatis Mapper 进行版本化迁移。
