- 每个 starter 在 `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中注册一个或多个 `@AutoConfiguration` 类，由 Spring Boot 自动发现装配
- starter 内部按 config/controller/domain/entity/mapper/service 标准包结构组织代码，并通过 `@ConfigurationProperties` 绑定配置项
- 需要持久化的 starter 在自身 `sql/` 目录下提供建表与菜单脚本，与应用主库脚本分离管理
- 对外扩展点统一采用接口 + 工厂/注册中心模式（如 EncryptorFactory、CollaborationProviderRegistry、MessageChannel），避免硬编码依赖具体实现
