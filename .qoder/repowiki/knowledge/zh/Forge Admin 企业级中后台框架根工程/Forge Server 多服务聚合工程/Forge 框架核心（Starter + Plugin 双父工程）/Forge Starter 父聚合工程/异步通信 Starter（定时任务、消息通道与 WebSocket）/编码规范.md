- 每个 Starter 通过 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动装配类，由 Spring Boot 自动发现。
- 可插拔组件采用「接口 + 条件装配」模式：如 `MessageChannel` 接口配合 `@ConditionalOnProperty` 和 `@ConditionalOnBean` 按需注册 Email/SMS/Web 实现。
- 配置集中使用 `@ConfigurationProperties(prefix = "forge.xxx")` 绑定 YAML 属性，并通过嵌套 `ChannelConfig` 等内部类组织渠道级配置。
- 对外能力先定义接口（如 `JobFlowExecutor`、`IMessagePushService`、`MessageChannel`），再由具体实现类承载业务逻辑，便于扩展新渠道或流程引擎。
- 安全与访问控制通过 Spring 拦截器/注解实现：WebSocket 使用 `ChannelInterceptor` 校验 Bearer Token 并匹配订阅白名单，定时任务通过 `@ScheduledJob`/`@JobHandler` 元数据声明调度策略。
