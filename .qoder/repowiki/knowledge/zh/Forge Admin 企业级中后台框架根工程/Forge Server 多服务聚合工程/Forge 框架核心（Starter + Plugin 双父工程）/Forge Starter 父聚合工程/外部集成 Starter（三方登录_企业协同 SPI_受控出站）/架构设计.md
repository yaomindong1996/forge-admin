本模块由三个相互协作的 starter 组成：
- forge-starter-social：基于 JustAuth 实现微信、钉钉等第三方登录，通过 `SocialAutoConfiguration` 自动装配，使用 `SocialOAuthLoginService` 协调授权码换取流程；凭据通过 `SocialAppCredentialService` 从持久化加密或 `ExternalSecretResolver`（来自 collaboration）解析，并兼容回退到连接旧明文字段；数据层按 entity/mapper/service/controller 分层，SQL 初始化位于 `sql/sys_social_config.sql`。
- forge-starter-collaboration：纯 SPI 包，定义 `CollaborationProvider`（声明 platform + capabilities）、`CollaborationCapability`（LOGIN/DIRECTORY/MESSAGE/TODO）以及各能力 Connector 接口（`LoginConnector`、`DirectoryConnector`、`MessageConnector`、`TodoConnector`），并通过 `CollaborationProviderRegistry` 注册与查找；`CollaborationExecutionContext` 作为调用上下文在 Connector 间传递，避免读取全局状态。
- forge-starter-outbound：提供 `SecureOutboundClient` 抽象及 OkHttp 实现 `OkHttpSecureOutboundClient`，通过 `OutboundAutoConfiguration` 装配 `OutboundPolicyService`（默认 `DefaultOutboundPolicyService`）执行域名白名单、DNS 解析与 IP 分类校验，配合 `SysOutboundWhitelist` 实体与 MyBatis Mapper 完成策略存储。
依赖方向：social → collaboration（SPI）+ core/auth/trans/cache/file/crypto；outbound 独立依赖 core/orm/tenant；collaboration 仅依赖 core，保持为无实现的契约层。
