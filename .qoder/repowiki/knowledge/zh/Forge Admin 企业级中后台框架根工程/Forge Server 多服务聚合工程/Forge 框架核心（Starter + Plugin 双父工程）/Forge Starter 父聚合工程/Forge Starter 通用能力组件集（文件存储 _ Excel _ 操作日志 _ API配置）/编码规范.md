- 每个 Starter 提供独立的 `*AutoConfiguration` 类，并使用 `@ConditionalOnMissingBean`、`@ConditionalOnProperty`、`@ConditionalOnWebApplication` 等条件注解控制 Bean 的按需装配。
- 对外扩展点统一以 `spi/` 包下的接口形式暴露（如 `FileStorage`、`StorageConfigProvider`、`ExcelMetadataProvider`、`ExcelConfigProvider`），具体实现放在 `storage/impl` 或同级目录下。
- 通过 `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动配置类，使 Starter 可被 Spring Boot 自动发现。
- 数据库相关能力配套提供 `sql/*.sql` 建表/菜单脚本，并与 Mapper XML 一起纳入资源目录，便于一键初始化。
- 配置项集中放在 `config/*Properties` 类中，通过 `@ConfigurationProperties` 绑定，并在自动配置类中以 `@RequiredArgsConstructor` 注入使用。
- 对可能影响性能的 I/O 操作（日志保存、异步导出）统一采用异步线程池执行，避免阻塞主业务流程。
