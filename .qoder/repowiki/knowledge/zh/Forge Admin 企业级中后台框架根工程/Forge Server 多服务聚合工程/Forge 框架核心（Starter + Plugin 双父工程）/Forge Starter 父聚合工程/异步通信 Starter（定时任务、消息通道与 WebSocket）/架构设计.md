本模块由三个相互独立的 Spring Boot Starter 组成，均继承自 `forge-starter-parent` 并依赖 `forge-starter-core`：
- `forge-starter-job`：通过 `@ScheduledJob`/`@JobHandler` 两个自定义注解标记方法或类，启动时扫描并登记到数据库期望配置，再统一同步至 Quartz 调度器；`flow/` 包定义 `JobFlowExecutor` 接口以中立方式对接 Flowable 流程引擎，`scheduler/QuartzJobExecutor` 为执行入口，`sql/job_tables.sql` 提供持久化表结构。
- `forge-starter-message`：以 `MessageChannel` 抽象统一短信、邮件、Web 三种渠道，具体实现 `SmsMessageChannel`、`EmailMessageChannel`、`WebMessageChannel` 分别委托 SMS4J 及 Jakarta Mail；`config/MessageAutoConfiguration` 通过 `@ConditionalOnProperty` 按需装配各渠道 Bean，并通过 `ReadConfig` 初始化 `SmsFactory.createSmsBlend`；对外暴露 `MessageClient` 作为统一发送门面，模板渲染由 `MessageTemplateEngine` 承担。
- `forge-starter-websocket`：基于 `spring-boot-starter-websocket` 提供 STOMP 推送能力，`WebSocketConfig` 注册拦截器链，`AuthenticatedWebSocketChannelInterceptor` 在 CONNECT/SEND/SUBSCRIBE 阶段校验 Bearer Token 并限制订阅目标白名单；`IMessagePushService` 及其 `impl.MessagePushServiceImpl` 封装用户/群组/主题广播推送，`domain.WebSocketMessage` + `enums.MessageType` 定义消息模型。
三者均以 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露自动装配入口，彼此无直接依赖，仅共享 core 基础能力。
