本模块由三个相互独立的 Spring Boot Starter 组成，均通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`（或 `spring.factories`）实现自动装配：
- `forge-starter-auth`：基于 Sa-Token + Redis/JWT 实现统一认证，`SaTokenConfig` 注册两级拦截器（登录校验 `order=1`、基于资源表的权限校验 `order=2`），并通过 `AuthController` 暴露 `/auth/**` 登录、注册、SSO 票据交换、验证码、租户选项等入口；`strategy/IAuthStrategy` 配合 `AuthStrategyFactory` 按 `AuthType` 分发密码/短信/邮箱等多种登录方式；`sql/` 下提供锁表、在线用户、菜单、客户端等初始化脚本。
- `forge-starter-crypto`：通过 `CryptoAutoConfiguration` 装配 `EncryptorFactory`（SM4/AES/AES_GCM）、`DesensitizeStrategyFactory`（手机号、身份证、邮箱等内置策略）、`KeyExchangeController`（RSA 密钥协商 + 会话密钥存储）、`DecryptRequestBodyAdvice` / `EncryptResponseBodyAdvice`（Jackson 序列化层加解密）、`ReplayAttackFilter`（防重放）以及 `VersionedPersistentCryptoService`（持久化密文版本迁移）；依赖可选的 `forge-starter-cache` 以启用 Redis 缓存。
- `forge-starter-openapi-security`：在存在 `RedissonClient` 时装配 `OpenApiRateLimitManager`、`OpenApiIdempotencyManager`、`OpenApiReplayGuard`，分别基于 Redisson 的 `RRateLimiter`、分布式锁和 nonce 时间窗实现开放 API 的限流、幂等与防重放。
依赖方向单向向下：三者均依赖 `forge-starter-core`、`forge-starter-config`、`forge-starter-api-config`，其中 auth 额外依赖 `forge-starter-websocket`、`forge-starter-tenant`、`forge-starter-cache`，crypto 依赖 BouncyCastle/Hutool-crypto，openapi-security 依赖 Redisson。
