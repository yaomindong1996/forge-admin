模块由两个并列的 Maven 子模块组成：
- `forge-starter-core`：通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 自动注册 `JacksonConfig`（自定义时间/大数字序列化）和 `ExceptionAutoConfiguration`（注入 `GlobalExceptionHandler`），作为 Spring Boot 自动装配入口；内部按职责分层——`annotation` 定义 `ApiDecrypt`/`ApiEncrypt`、`OperationLog`、`RefreshScope`、`IgnoreTenant`、`ApiPermissionIgnore` 等横切注解；`config` 集中 Jackson、DemoWebMvc、异常处理配置；`context` 提供 `ExecutionIdentityContextHolder`（基于 ThreadLocal + AutoCloseable Scope 的显式执行身份上下文）、`AuthProperties`/`CryptoProperties`/`DemoProperties`/`LogProperties` 等配置绑定；`domain` 提供 `BaseEntity`（MyBatis-Plus `FieldFill` 填充 create/update 审计字段）、`RespInfo`、`PageQuery`、流程事件模型；`exception` 通过 `@RestControllerAdvice` 统一捕获校验、404、权限拒绝、数据库异常等并返回 `RespInfo`；`session` 提供 `LoginUser` 与 `SessionHelper` 承载登录态；`util` 提供分页参数解析、敏感数据脱敏、IP 定位等工具。
- `forge-starter-web`：仅声明 `spring-boot-starter-web`（排除 Tomcat）+ `spring-boot-starter-undertow` 及 actuator、hutool-captcha/crypto，作为 Web 容器的轻量依赖聚合层，不引入业务代码。
依赖方向：`forge-starter-web` 可复用 `forge-starter-core` 的公共能力；两者均向上继承 `forge-starter-parent`，对外以 Spring Boot Starter 形式被业务应用引入。
