本模块本身不引入运行时依赖，仅作为 Maven aggregator（packaging=pom）集中声明所有 starter 子模块，使上层 forge-framework 或业务工程通过单一依赖即可拉取全部能力。
- 每个子模块均为独立的 Spring Boot Starter：在 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中注册 `@AutoConfiguration` 类，由 Spring Boot 自动装配；部分老模块同时保留 `spring.factories` 兼容旧版本。
- 模块间按能力分层组织：core/orm/web 提供基础 JSON、异常、MyBatis-Plus、Undertow 等公共基座；auth/crypto/openapi-security 提供认证、加解密与开放 API 安全；config/datascope/tenant/idempotent 提供运行时配置、数据权限、多租户与幂等；cache/trans/id/job/message/websocket/file/excel/social/outbound/collaboration/api-config 各自封装单一领域能力，均通过 SPI（如 CollaborationProviderRegistry、EncryptorFactory、MessageChannel 等）对外暴露扩展点。
- 数据库相关 starter（auth/config/datascope/id/job/social/file）统一附带 `sql/` 目录脚本，供应用初始化时执行；各 starter 之间通过共享的 core 上下文（ExecutionIdentityContextHolder、SessionHelper 等）和注解（ApiDecrypt/ApiEncrypt、OperationLog、RefreshScope 等）进行松耦合协作，而非直接互相调用实现类。
