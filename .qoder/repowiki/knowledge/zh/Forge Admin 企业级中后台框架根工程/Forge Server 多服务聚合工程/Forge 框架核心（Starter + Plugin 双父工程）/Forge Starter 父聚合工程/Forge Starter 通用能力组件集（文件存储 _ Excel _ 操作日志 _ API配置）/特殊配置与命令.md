各模块通过 `pom.xml` 中的 `${revision}` 版本继承父工程；`forge-starter-file` 需显式引入 AWS S3 SDK 与腾讯 COS SDK 才能启用对应存储实现；`forge-starter-api-config` 默认开启（`forge.api-config.enabled` 默认为 true），可通过 `forge.api-config.auto-register=false` 关闭自动注册；`forge-starter-log` 依赖 `forge-starter-api-config` 且需要 `ILogService` Bean 才会激活切面。
