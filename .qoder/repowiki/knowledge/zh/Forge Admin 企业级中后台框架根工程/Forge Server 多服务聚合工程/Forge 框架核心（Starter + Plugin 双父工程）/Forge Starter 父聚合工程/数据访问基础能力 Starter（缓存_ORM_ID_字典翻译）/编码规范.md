- 每个 Starter 通过 `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 文件声明自动装配类，使模块可被 Spring Boot 自动发现。
- 配置类集中在 `config/` 包下，使用 `@Configuration` + `@Bean` 方式注册组件，并通过 `@ConditionalOnMissingBean` 等条件注解保证可插拔性。
- AOP 切面统一放在 `aspect/` 包，使用 `@Aspect` + `@Around` 围绕目标方法，并在异常时记录 warn 日志后返回原结果以保证业务健壮性。
- 可扩展点采用 Handler/SPI 模式：`TransHandler` 接口配合 `TransManager` 按优先级自动选择处理器；`DictValueProvider` 作为字典值来源 SPI。
- 对外 API 以 Service 接口 + `impl/` 实现类组织，Controller 仅负责 HTTP 路由，核心逻辑下沉到 Service/Generator 层。
- 所有远程调用（Redisson、数据库）均包裹 try-catch 并降级为本地状态或空结果，同时通过计数器（LongAdder）统计 hits/misses/failures 等指标。
