本模块由四个相互独立的 starter 子模块组成，均通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册自动装配类，遵循 Spring Boot 3 + MyBatis-Plus 生态：
- `forge-starter-config`：以 `ConfigAutoConfiguration` 为核心，通过 `JdbcTemplate` 读取数据库中的 `sys_config_group` 表实现配置中心，配合 `DbPropertySource`/`DbPropertySourcePostProcessor` 将配置注入 Spring Environment，并通过 `ConfigRefreshEvent` + `ConfigRefresher` 支持热更新；`CryptoConfigSanitizer` 对敏感字段做脱敏。
- `forge-starter-datascope`：基于 MyBatis-Plus `InnerInterceptor` 的 `DataScopeInterceptor`，在 `beforeQuery` 中用 JSqlParser 解析并改写 SELECT 的 WHERE 子句，按 `DataScopeType`（SELF/ORG/ORG_AND_CHILD/CUSTOM/TENANT_ALL/REGION）注入条件；通过 `DataScopeContextHolder` 传递上下文，`DataScopeIgnore` 注解跳过控制，`DataScopeProperties.UnconfiguredPolicy` 控制未配置 Mapper 时的严格/兼容策略。
- `forge-starter-tenant`：通过 `TenantContextHolder` 保存租户标识，`DefaultTenantLineHandler` 实现 MyBatis-Plus 多租户 SQL 改写；`TenantBusinessDataSourceAspect` 在事务边界前借助 `dynamic-datasource` 的 `DynamicDataSourceContextHolder` 切换租户业务数据源，并提供 `TenantBusinessDataSource` 注解与 `TenantBusinessDataSourceResolver` 进行动态解析。
- `forge-starter-idempotent`：以 `@Idempotent` 注解 + `IdempotentAspect` AOP 切入，通过 `IdempotentKeyGenerator` 生成键，按 `IdempotentStrategy`（STRICT/RETURN_CACHE/TOKEN_REQUIRED）委派给对应 `IdempotentStrategyHandler`，使用 Redisson 分布式锁与 `Redis*Service` 实现结果缓存与令牌校验。
依赖方向单向向下：各 starter 仅依赖 `forge-starter-core` 及各自所需的基础 starter（auth/orm/cache），彼此之间无直接耦合。
