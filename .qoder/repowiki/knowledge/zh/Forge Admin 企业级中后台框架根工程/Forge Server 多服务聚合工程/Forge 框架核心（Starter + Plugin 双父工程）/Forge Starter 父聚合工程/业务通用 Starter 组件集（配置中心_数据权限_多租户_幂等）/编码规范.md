- 每个 starter 通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动配置类，而非传统的 `spring.factories`。
- 自动配置类统一使用 `@ConditionalOnMissingBean` 包裹 Bean 定义，允许使用者覆盖默认实现。
- 上下文信息通过 ThreadLocal 持有（`DataScopeContextHolder`、`TenantContextHolder`），并在拦截器/AOP 入口处设置、出口处清理。
- 可插拔行为通过接口+策略 Map 注入（如 `Map<IdempotentStrategy, IdempotentStrategyHandler>`、`IDataScopeService` Supplier），便于扩展而不修改核心逻辑。
- SQL 改写类组件（数据权限、多租户）均以 MyBatis-Plus 拦截器/处理器形式实现，避免侵入业务代码。
- 对外暴露的配置项集中放在 `*Properties` 类中，并通过 Spring Boot configuration processor 生成元数据供 IDE 提示。
