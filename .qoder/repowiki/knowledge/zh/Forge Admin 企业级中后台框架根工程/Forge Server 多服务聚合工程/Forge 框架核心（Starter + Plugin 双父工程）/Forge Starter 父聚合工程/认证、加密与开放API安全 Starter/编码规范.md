- 每个 Starter 通过 `@AutoConfiguration` 类集中声明 Bean，并使用 `@ConditionalOnBean` / `@ConditionalOnClass` / `@ConditionalOnMissingBean` 控制可选依赖（如 Redis、Cache、Redisson）的装配。
- 对外暴露的配置项统一通过 `@EnableConfigurationProperties` 加载，并在配置类中提供默认值与校验（如 `CryptoConfigurationValidator`、`OpenApiSecurityProperties`）。
- 可插拔能力采用「接口 + 工厂」模式：`IAuthStrategy` + `AuthStrategyFactory`、`Encryptor` + `EncryptorFactory`、`DesensitizeStrategy` + `DesensitizeStrategyFactory`，新增算法/策略只需注册到工厂。
- Web 层统一返回 `RespInfo<T>` 包装，控制器方法通过 `@IgnoreTenant`、`@ApiDecrypt`、`@SaIgnore` 等注解声明免租户、免鉴权或加解密语义。
- 路径白名单集中在 `SaTokenConfig.addInterceptors` 中使用 `SaRouter.match(...).notMatch(...)` 集中排除登录、静态资源、健康检查、OAuth/MCP/OpenAPI 等公开端点。
- 测试目录结构与源码包一一对应（`src/test/java/com/mdframe/forge/starter/*/...`），针对配置、控制器、服务实现分别编写单元测试。
