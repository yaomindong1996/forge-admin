本模块由四个并列的 Maven 子模块组成，每个子模块都是自包含的 Spring Boot Starter，统一依赖 `forge-starter-core` 并通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露自动配置类。

- `forge-starter-file`：以 `FileAutoConfiguration` 为入口，定义 `storage/FileStorage` SPI 与 `spi/StorageConfigProvider`，内置 `LocalFileStorage`、`RustfsFileStorage`（AWS S3 SDK）、`TencentCosFileStorage`（腾讯云 COS SDK），由 `FileManager` 在启动时扫描并注册所有实现；SQL 脚本 `file_storage.sql`、`rustfs_config.sql` 提供元数据表。
- `forge-starter-excel`：以 `ExcelAutoConfiguration` 启用异步，核心 `DynamicExportEngine` + `ExcelExporter` 基于 EasyExcel 完成导出/导入/模板生成，`service/impl` 中 `AsyncExportServiceImpl`、`ExcelImportServiceImpl` 分别处理异步导出与导入监听，`spi/ExcelMetadataProvider`、`spi/ExcelConfigProvider` 允许外部扩展列元数据与配置。
- `forge-starter-log`：以 AOP 切面 `OperationLogAspect` 拦截 Controller 方法，结合 `ILogService` 异步落库；通过 `context/OperationAuditContext` 传递审计快照，依赖 `forge-starter-api-config` 获取接口元信息，依赖 Sa-Token 获取用户身份。
- `forge-starter-api-config`：以 `ApiConfigAutoConfiguration` 为核心，通过 `ApiConfigScanner` 扫描 `@RequestMapping` 自动发现接口并注册到 `IApiConfigManager`，配合 `ApiConfigRefreshListener` 监听刷新事件；使用 Caffeine + Redis 两级缓存，MyBatis Plus (`SysApiConfigMapper`) 持久化，并提供 `ApiConfigManageController`、`SysApiConfigController` 管理端点。

依赖方向：log → api-config → core；excel → core（可选 trans）；file → core；各模块之间相互独立，仅通过 `forge-starter-core` 共享基础能力。
