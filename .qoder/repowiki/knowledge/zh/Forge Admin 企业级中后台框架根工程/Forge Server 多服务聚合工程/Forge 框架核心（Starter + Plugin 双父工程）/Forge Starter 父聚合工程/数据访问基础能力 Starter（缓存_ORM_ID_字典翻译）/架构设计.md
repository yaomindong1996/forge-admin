本模块由四个相互独立的 Spring Boot Starter 子模块组成，均通过 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露自动装配入口，彼此无直接依赖：
- `forge-starter-cache`：以 `ForgeManagedCacheManager` 为核心，基于 Redisson 实现本地 Caffeine + Redis 的多级缓存，并通过 `@ForgeCacheable/@ForgeCachePut/@ForgeCacheEvict` 注解 + `ForgeCacheAspect` AOP 暴露编程式与声明式缓存；控制面使用 Redis Map/Topic 在应用间同步定义、策略覆盖与失效事件，支持 LOCAL/REDIS/MULTI 三种模式及运行时策略覆盖。
- `forge-starter-orm`：基于 MyBatis-Plus 的 `MybatisPlusConfig` 统一装配 `MybatisPlusInterceptor`，按顺序注册外部注入的自定义拦截器、分页拦截器（`CountOnePaginationInnerInterceptor` 将 COUNT(*) 改写为 COUNT(1)）、乐观锁拦截器，并配置 `InjectionMetaObjectHandler` 与网卡绑定的雪花 ID 生成器。
- `forge-starter-id`：提供数据库号段式序列服务，`SegmentSequenceGenerator` 通过 `SysIdSequenceMapper` 以乐观版本号 CAS 分配号段，进程内用 Caffeine 缓存 Segment 并按业务键串行消费，配合 `FusionDisposableWorkerIdAssigner` 做 Worker 节点分配，对外暴露 `IdController`/`SequenceController` REST 接口。
- `forge-starter-trans`：通过 `DictTranslateAspect` 对标注 `@DictTranslate` 的方法返回值进行 AOP 后处理，调用 `TransManager` 根据字段上的 `@TransField` 解析处理器（默认字典表/枚举/表达式），并以 SPI `DictValueProvider` 扩展字典值来源。
各 Starter 内部遵循 config → annotation/aop → manager/service → store/handler 的分层约定，所有 Bean 均通过 `@Configuration` + `@Bean` 或 `@Component` 注册，异常路径统一降级（如 Redis 不可用时回退到本地缓存或空策略）。
