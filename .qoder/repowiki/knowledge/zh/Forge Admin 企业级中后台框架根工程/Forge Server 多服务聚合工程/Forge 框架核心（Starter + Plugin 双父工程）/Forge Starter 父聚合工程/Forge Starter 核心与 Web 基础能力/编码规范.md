- 自动装配通过 `@AutoConfiguration` 标注配置类，并在 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 中显式列出，而非使用 `@EnableAutoConfiguration` 扫描。
- 领域实体统一继承 `BaseEntity`，借助 MyBatis-Plus 的 `@TableField(fill = FieldFill.*)` 自动填充创建人、创建时间、更新人、更新时间等审计字段。
- HTTP 响应体统一使用 `RespInfo` 包装，所有 `@RestControllerAdvice` 中的异常处理方法均返回 `RespInfo.error(...)` 或 `RespInfo.build(...)`，避免直接抛出原始异常。
- 配置项通过独立的 Properties 类（如 `AuthProperties`、`CryptoProperties`、`DemoProperties`、`LogProperties`）集中管理，配合 `spring-boot-configuration-processor` 生成元数据。
- 线程级上下文通过 `ThreadLocal` + `AutoCloseable` Scope 模式实现（见 `ExecutionIdentityContextHolder`），调用方在 try-with-resources 中打开/关闭作用域以自动恢复外层状态。
- 横切关注点（加密、日志、租户忽略、权限忽略、刷新作用域）以注解形式定义在 `annotation/*` 子包下，供 AOP 或其他拦截器消费。
