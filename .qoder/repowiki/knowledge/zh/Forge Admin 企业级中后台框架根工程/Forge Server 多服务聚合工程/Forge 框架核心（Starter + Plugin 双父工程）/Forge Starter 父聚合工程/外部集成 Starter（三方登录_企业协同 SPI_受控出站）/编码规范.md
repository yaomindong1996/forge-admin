- 通过 Spring Boot `@AutoConfiguration` 类集中装配 Bean，并使用 `@ConditionalOnMissingBean` 暴露可替换的接口（如 `SocialAppCredentialService`、`OutboundPolicyService`、`SecureOutboundClient`）。
- 对外扩展点以接口形式暴露（`CollaborationProvider`、`LoginConnector`、`OutboundPolicyService`、`SecureOutboundClient`），并提供 `Default*` 默认实现供开箱即用。
- 服务层采用 `I*Service` 接口 + `impl/*ServiceImpl` 实现的分层结构，配合 MyBatis Mapper 与 XML 映射文件组织数据访问。
- 敏感凭据统一通过 `PersistentCryptoService` / `SocialAppCredentialService` 解密后使用，并在 finally 中清零 char[] 防止内存残留。
- 连接器通过 `CollaborationCapability` 枚举声明支持的能力集，并由 `CollaborationProviderRegistry` 集中管理多平台 Provider 的注册与查找。
- 请求上下文以不可变 record（如 `CollaborationExecutionContext`）在组件间传递，禁止 Connector 自行读取全局上下文。
