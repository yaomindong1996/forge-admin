本模块通过两个并列的 Maven 聚合父工程组织框架能力：`forge-starter-parent` 聚合 21 个独立 Spring Boot Starter（如 auth、cache、orm、tenant、trans、file、message 等），每个 Starter 通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现自动装配，供上层应用按需引入；`forge-plugin-parent` 聚合 AI、capability、data、flow、generator、job、system、collaboration、external、mcp、message 等业务插件，每个插件作为完整可部署单元对外暴露 REST/内部 API。两者共同遵循同一分层约定（controller/service/mapper/entity/dto/vo），并通过共享的 `forge-dependencies` 统一依赖版本。Starter 提供横切能力，Plugin 基于 Starter 组合出具体业务能力，形成「基础能力 → 业务插件」的清晰依赖方向。
