本模块为知识检索子插件的 Web 接入层，按 Spring MVC 分层组织：controller 包下 AiKnowledgeController 暴露 /ai/knowledge 下的知识库 CRUD、文档上传/确认/重处理/分块查看/SSE 进度订阅及检索调试接口；AiStoreInstanceController 暴露 /ai/store 下的向量存储实例管理接口。所有接口统一通过 RespInfo 包装返回，并借助 Sa-Token 的 @SaCheckPermission 注解进行细粒度权限控制。mapper 包中每个实体对应一个继承 BaseMapper 的接口（AiKnowledgeMapper/AiKnowledgeDocumentMapper/AiKnowledgeChunkMapper/AiStoreInstanceMapper），除基础 CRUD 外还声明了 selectKnowledgePage、selectByIdForUpdate、countByName 等自定义 SQL 方法，由 MyBatis XML 实现。enums 包集中定义 AiDocumentProcessStatus 等状态枚举，供 controller/mapper/service 共享。依赖方向单向向下：controller → service（位于上层包）→ mapper → 数据库，本模块不直接访问数据库。
