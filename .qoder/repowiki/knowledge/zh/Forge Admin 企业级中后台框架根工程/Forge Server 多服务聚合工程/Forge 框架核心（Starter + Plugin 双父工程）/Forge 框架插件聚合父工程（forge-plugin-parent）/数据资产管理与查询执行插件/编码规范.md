- 每个实体均配套独立的 Mapper 接口与同名 XML 文件，XML 位于 resources/mapper 下并与 Java 包结构一一对应。
- 服务接口继承 MyBatis-Plus 的 IService<Entity>，实现类放在 service/impl 子包并以 ServiceImpl 后缀命名。
- 对外请求体统一使用 DTO（dto 包），对外响应使用 VO（vo 包），内部状态与持久化使用 entity，三者职责分离。
- 多数据库方言通过 DbDialectFactory + DbDialect 接口扩展，新增数据库只需实现 DbDialect 并在工厂中注册。
- 所有外部 SQL 必须经 SqlSafetyValidator 校验且通过 SqlParameterBinder 转为 PreparedStatement 参数绑定，禁止字符串拼接用户输入。
- 查询结果在返回前统一经过维度值翻译与敏感字段脱敏（MASK/HIDDEN）处理，由 DataQueryExecutor 集中编排。
