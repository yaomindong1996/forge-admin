模块以 `ReactLoop` 为核心执行器，在独立线程中运行 while 循环：调用 LLM → 解析 tool_call → 经 `PermissionEngine` 决策（ALLOW/ASK/DENY）→ 通过 `AgentToolRegistry` 查找并执行工具 → 将结果写回 `ReactContext` 继续下一轮，直至无 tool_call、达到最大轮次或被取消。
- 入口层：`AgentEngineController` 暴露 `/ai/engine/stream`、`/resume`、`/stop`、`/events/{sessionId}` 四个 SSE 端点；`AgentEngineService` 负责装配 `ReactContext`（系统提示、历史消息裁剪、图片附件 URL、ChatModel、绑定工具列表），并将事件包装为 `ServerSentEvent` 返回。
- 事件总线：`AgentEventPublisher.publish` 统一走三条路径——异步持久化（`AgentEventPersistence`）、同步转发 WebFlux SSE（`AgentEventWebFluxStream`）、回调 `AgentEventListener` 列表（如对话落库编排），所有路径均在 loop 线程内执行，与 HTTP 连接生命周期解耦。
- 工具体系：`tool/` 子包定义 `AgentTool` 接口与 `ToolContext`/`ToolResult` 值对象，`builtin/` 提供内置工具（HTTP、图像生成、RAG 检索、技能读取），`registry/AgentToolRegistry` 集中注册与按 key 查找；工具声明通过自定义 `AdvertisedToolCallback` 注入 OpenAI 兼容模型的 ToolDefinition，但执行由 ReAct 循环自控（`internalToolExecutionEnabled(false)`）。
- 权限与 HITL：`permission/PermissionEngine` 基于配置表 + 风险关键词启发式决定是否需要用户确认；需要确认时通过 `hitl/InterruptStore` 把 `ReactContext` 序列化到 Redis（TTL 10 分钟），等待 `/resume` 恢复。
- 上下文与裁剪：`context/ContextTrimmer` 按 token 预算裁剪历史消息，避免撑爆模型上下文窗口。
- 依赖方向：controller → service → ReactLoop → (tool registry / permission engine / event publisher / interrupt store)；ReAct 循环不直接依赖 HTTP，仅通过事件总线与外部交互。
