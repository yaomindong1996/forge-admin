模块以 Spring Boot Starter 形式集成到 forge-framework，依赖 forge-starter-core/orm/auth/log/tenant/crypto/cache 等基础能力，通过 controller/dto/entity/mapper/service/support/vo/enums 分层组织：
- controller 层暴露 REST 接口（DataConnectionController、DataDatasetController、DataDimensionController 等），仅做参数校验与转发。
- service 层按领域划分（DataConnectionService、DataDatasetService、DataDimensionService、DataBusinessDefinitionService、DataDatasetAccessService、DataDatasetRowScopeService、DataQueryExecutor），实现类位于 impl 子包；所有持久化通过 MyBatis-Plus 的 Mapper 接口 + resources/mapper/*.xml 完成。
- support 层封装跨领域的基础设施：JdbcDataSourceProvider 基于 HikariCP 按 DataConnection.id 缓存 DataSource，并通过 PersistentCryptoService 解密密码；DbDialectFactory + MySqlDialect 抽象方言；SqlSafetyValidator、SqlParameterBinder、TableQueryBuilder、DatasetParamSchemaParser 负责 SQL 安全校验、预编译参数绑定、表模式 SQL 构建与参数 Schema 解析；DataQueryRuntimeCache 提供运行时查询结果缓存。
- 数据模型以 entity 对应 ai_report_* 系列表（data_tables.sql 定义），枚举集中描述 DB 类型、访问模式、敏感级别等。
- 查询执行主路径在 DataQueryExecutor.execute：根据 datasetType(TABLE/SQL) 选择 buildTableQuerySql/buildSqlQuery，注入行权限条件（/*DATA_SCOPE*/ 占位符或 WHERE 拼接），经 DbDialect.buildLimitSql 分页后通过 PreparedStatement 只读执行，再依次进行维度值翻译、敏感字段脱敏，最终组装为 DataDatasetQueryResultVO。
- 资源脚本 resources/sql 包含建表与增量升级脚本（*_upgrade_*.sql），resources/mapper 存放 XML SQL 映射。
