模块以 Spring Boot 自动装配入口 `HighRiskApprovalAutoConfiguration`（通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册）为核心，受 `forge.capability.high-risk.enabled` 开关控制；配置项集中在 `HighRiskApprovalProperties`（含嵌套 `Crypto` 子属性）。内部按职责分层：
- `publish/`：`HighRiskActionPublisher` 将高风险动作发布到能力目录并持久化策略（风险等级 HIGH、候选组、过期时间）。
- `service/`：核心业务流程，`HighRiskApprovalSubmissionService` 负责幂等提交、载荷加密、创建工作流实例；`HighRiskApprovalCallbackService` 处理审批结果回调并执行业务动作；`HighRiskBusinessStateService` 快照业务状态；`HighRiskApprovalFlowModelService` 确保流程模型存在；`CapabilityPolicyService` 管理策略。
- `crypto/`：基于版本化 KEK 的载荷加密方案，`VersionedKekCapabilityPayloadCrypto` 实现 `CapabilityPayloadCrypto`，使用 AAD 绑定租户/ID/客户端/能力标识与请求摘要。
- `mcp/`：通过 `McpToolContributor` SPI 暴露 `capability.approval.get` 工具，由 `HighRiskApprovalQueryService` 查询审批状态。
- `domain/mapper/resources/mapper`：MyBatis Mapper + XML 映射 `AiCapabilityApproval` / `AiCapabilityPolicy` 表。
依赖方向单向向外：本模块依赖 `forge-plugin-capability-actions/platform/generator/mcp/flow-client` 等基础能力插件，不反向依赖上层应用。
