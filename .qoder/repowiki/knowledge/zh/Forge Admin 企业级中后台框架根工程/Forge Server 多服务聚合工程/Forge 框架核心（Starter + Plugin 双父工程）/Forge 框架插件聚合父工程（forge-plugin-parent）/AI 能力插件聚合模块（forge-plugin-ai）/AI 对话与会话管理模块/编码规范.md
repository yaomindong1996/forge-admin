- Controller 统一使用 RespInfo 包装返回，并通过 StpUtil.getLoginIdAsLong() 获取当前登录用户 ID 进行权限校验。
- SSE 流式接口采用 Flux.map(...).concatWith(Flux.just("[DONE]")) 模式，并在 onErrorResume 中返回 event="error" 的消息片段。
- 实体类使用 Lombok @Data/@Builder/@TableName/@TableId 注解配合 MyBatis-Plus，时间字段用 @JsonFormat 格式化，逻辑删除通过 @TableLogic 标记。
- Service 层对写操作（删除、重命名、置顶）均先查询实体并校验 userId 归属后再执行更新，失败时返回 false 或抛出业务异常。
- 会话标题在创建和重命名时统一截断为 50 字符并追加省略号，避免超长内容入库。
- 分页与统计查询委托给 Mapper XML（selectSessionPage、selectStatistics、selectDailyTrend、selectExperienceMetrics），Service 仅负责参数拼装与结果归一化。
