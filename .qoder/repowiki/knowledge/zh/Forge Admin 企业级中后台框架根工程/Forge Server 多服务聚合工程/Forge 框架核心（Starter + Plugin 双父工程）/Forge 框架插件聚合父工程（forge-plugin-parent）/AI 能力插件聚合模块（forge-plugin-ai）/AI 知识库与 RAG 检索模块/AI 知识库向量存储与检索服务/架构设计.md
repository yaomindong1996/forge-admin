模块按三层组织：domain 层定义 MyBatis-Plus 实体 AiKnowledge、AiKnowledgeDocument、AiKnowledgeChunk、AiStoreInstance，承载知识库、文档、分块及向量存储实例的持久化；service 层以 Spring Service 暴露业务接口（AiKnowledgeService、AiStoreInstanceService、DocumentProcessService、KnowledgeSearchService），封装分页、事务性 CRUD、文档两步上传确认、SSE 进度订阅（Flux<ServerSentEvent<DocumentProcessEvent>>）和检索编排；vectorstore 层通过抽象接口 VectorStoreService 屏蔽底层差异，当前仅实现 MilvusVectorStoreService（直接调用 io.milvus.v2.client.MilvusClientV2），由 VectorStoreFactory 根据 AiStoreInstance.storeType（MILVUS/PG_VECTOR/ELASTICSEARCH）路由到具体实现，新增向量库只需新增实现并注册到工厂 switch。依赖方向严格自下而上：service → domain mapper + vectorstore → Milvus SDK，DTO 位于 service/dto 作为对外请求/响应契约。
