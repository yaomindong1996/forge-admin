- 路由入口统一收敛在 `AiModelRouter` 接口的 `route` 与 `preview` 两个方法，实际策略由 `PolicyBasedAiModelRouter` 实现
- 跨子域通信通过不可变 record（`RouteRequest`、`RouteDecision`、`RoutedInvocation`）传递上下文，避免直接耦合领域对象
- 租户隔离在路由阶段强制校验：provider、model、policy 的 tenantId 必须与请求一致，否则抛出业务异常
- 模型可用性通过 `AiModelHealthLease` 租约机制管理，`RoutedInvocation` 实现 `AutoCloseable` 确保租约释放
- 能力与类型使用枚举/常量集中定义（`AiModelType`、`AiModelCapabilityCode`、`AiModelSelectionMode`），禁止硬编码字符串
