- 事件发射采用「先 publish 再 emit」模式：`AgentEventPublisher.publish` 同时触发持久化、SSE 转发与监听器回调，保证各消费者互不阻塞。
- 工具调用遵循「声明与执行分离」：通过 `AdvertisedToolCallback` 仅向模型暴露 ToolDefinition，实际执行由 `ReactLoop.executeTool` 经 `AgentToolRegistry` 查找并调用。
- 权限决策统一经 `PermissionEngine.decide` 返回 `PermissionDecision`（ALLOW/ASK/DENY），再由循环分支处理拒绝或进入 HITL 流程。
- 所有异常路径最终汇聚到 finally 块记录埋点并关闭 sink，确保 `AGENT_END` 事件必定发出且不影响主流程。
- 对外暴露的 JSON 字段通过 `escapeJson` 统一转义反斜杠、引号与换行，防止事件数据污染 SSE 协议。
- Redis 存储键采用固定前缀加 UUID 的形式（如 `agent:interrupt:`），并统一设置 TTL，避免脏数据残留。
