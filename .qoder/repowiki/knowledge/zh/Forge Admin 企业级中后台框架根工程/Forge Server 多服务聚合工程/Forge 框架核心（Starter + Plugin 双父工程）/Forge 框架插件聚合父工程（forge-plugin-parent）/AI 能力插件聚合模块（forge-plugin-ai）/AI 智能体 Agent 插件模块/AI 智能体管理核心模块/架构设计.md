模块采用典型的 Controller → Service → Mapper 三层结构：`controller/AiAgentController` 暴露 `/ai/agent` 下的 REST 端点（分页、列表、CRUD），统一通过 `RespInfo` 返回并叠加 `@ApiDecrypt/@ApiEncrypt` 加解密；`service/AiAgentService` 继承 MyBatis-Plus 的 `ServiceImpl<AiAgentMapper, AiAgent>`，封装业务校验（如固定模型模式必须选择供应商、路由策略模式必须选择有效策略），并通过 `AiModelRoutePolicyMapper` 跨包校验路由策略可用性；`domain/AiAgent` 为实体类，继承租户基类 `TenantEntity`，映射到 `ai_agent` 表并使用 `@TableLogic` 软删除；`mapper/AiAgentMapper` 扩展 BaseMapper，定义按编码查询启用 Agent、分页查询及启用列表等自定义 SQL 入口。依赖方向单向向下：Controller 仅依赖 Service，Service 依赖 Mapper 及同插件内 `routing` 子模块的策略实体，无反向依赖。
