模块以 `JobAutoConfiguration` 为入口，通过 `@ComponentScan("com.mdframe.forge.plugin.job")` 和 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 暴露为可插拔的 Spring Boot 自动配置。

内部按职责分层组织：
- `config/`：`JobProperties`、`ScheduleConfig`、`JobOpenApiSecurityConfiguration` 负责属性绑定、Quartz 调度器装配与 OpenAPI 安全策略；
- `controller/`：管理端 REST（`JobConfigController`、`JobLogController`、`JobMonitorController`、`JobApiTokenController`、`JobExecutorEndpoint`）与 `openapi/` 下的 `JobOpenApiController`、`JobExecutionOpenApiController` 对外暴露任务管理与触发接口，统一经 `JobOpenApiExceptionHandler` 处理异常；
- `service/`：领域服务层，按功能拆分为 `JobExecutionLifecycleService`（执行生命周期）、`JobScheduleDomainService`（调度域）、`JobFlowOrchestrationService`（流程编排）、`JobApiAuthorizationService` 等，每个服务聚焦单一职责；
- `scheduler/`：封装 Quartz 核心操作，`JobScheduler` 提供 add/update/delete/pause/resume/trigger/updateCron/synchronize/rebuild 等原子 API，`QuartzJobExecutor` 作为 Quartz Job 实现，`JobStartupReconciler` 负责启动时数据库与 Quartz 状态对齐；
- `executor/`：定义 `IJobExecutorRouter` 抽象，由 `LocalJobExecutorRouter`（BEAN/HANDLER）与 `RemoteJobExecutorRouter`（RPC）两种实现，通过 `JobExecutorRouterManager` 按 `executeMode` 分发；
- `manager/`：横切关注点，包括 `JobApiIdempotencyManager`、`JobApiRateLimitManager`、`JobExecutionLockManager`、`JobScheduleCoordinator`、`JobObservabilityManager` 等；
- `entity/mapper/model/vo/dto/constant/support/spi`：数据模型、MyBatis Mapper、DTO/VO、常量、工具类与 SPI（`IJobAlarmNotifier`、`IJobLogStorage`）；
- `registry/`：`JobAutoRegistrar` 用于动态注册外部定义的 Job Bean。

依赖方向自顶向下：controller → service → scheduler/manager → mapper/entity，并通过 SPI 解耦日志存储与告警通知。
