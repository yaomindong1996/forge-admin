模块按 image 与 voice 两个子域组织，每个子域遵循统一的 Controller → Service → Adapter 分层：
- controller 层：`AiImageGenerateController` 暴露 `/ai/image-generate` 接口，`AiVoiceController` 暴露 `/ai/voice/{asr,tts}` 接口，统一使用 Sa-Token `@SaCheckPermission` 做权限校验并返回 `RespInfo`。
- service 层：`AiImageGenerationService`、`AiAsrService`、`AiTtsService` 负责参数校验、从 Agent/Model/Provider 解析目标模型、解密 API Key，并通过 `AiModelAdapterRegistry` 路由到具体适配器；图片生成采用 Spring `@Async` 异步执行，状态机由 `AiImageGenerateStatus` 驱动（PENDING→GENERATING→SUCCESS/FAILED）。
- adapter 层：定义 `AiImageModelAdapter`、`AiAsrModelAdapter`、`AiTtsModelAdapter` 三个接口，当前提供 `OpenAiCompatible*` 实现，新增供应商只需新增实现类并由注册中心发现。
- 数据层：图片生成记录以 MyBatis-Plus 实体 `AiImageGenerateRecord` + `AiImageGenerateRecordMapper` 持久化，支持租户隔离（继承 `TenantEntity`）；文件结果统一通过 `FileManager` 上传至外部存储。
依赖方向单向向外：controller → service → (adapter + model/provider mapper) → 文件系统，不反向依赖上层业务。
