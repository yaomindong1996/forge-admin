模块采用典型的分层+策略扩展架构：
- 表现层 `controller` 暴露 `/external/proxy` 等REST端点（ExternalProxyController、ExternalApiController等），统一使用 `@ApiEncrypt/@ApiDecrypt` 加解密注解。
- 核心编排在 `service/impl/ExternalProxyServiceImpl`，串联权限校验、限流、缓存、参数映射、请求体构建、认证注入、加密传输、重试执行、响应解析与脱敏日志落库的完整调用链路。
- 可扩展点通过工厂模式解耦：`strategy/ExternalAuthStrategyFactory` 按 `authType` 分发到 Basic/Token/OAuth2/ApiKey/CurrentToken/Custom/None 等实现；`adapter/DataAdapterFactory` 按 `adapterType` 分发 JsonPath/Script/None 数据适配与脚本转换。
- 横切能力集中在 `support` 包：`ExternalRetryExecutor`（基于状态码与网络异常的重试）、`ExternalRateLimitManager`、`ExternalResponseCache`、`ExternalPermissionGuard`、`ExternalSensitiveDataMasker`、`ExternalSecretService`。
- 数据持久化通过 MyBatis-Plus 实体（`entity/ExternalApi`、`ExternalSystem`、`ExternalApiLog`）+ Mapper XML + `resources/sql/external_proxy_tables.sql` 建表脚本完成，支持租户隔离。
- 出站请求统一走 `forge-starter-outbound` 的 `SecureOutboundClient`，并内置与目标系统的 RSA+SM4 会话密钥交换流程（`prepareExternalCrypto`）。
- 依赖方向单向：controller → service → (strategy/adapter/support) → mapper/entity，不反向依赖上层业务。
