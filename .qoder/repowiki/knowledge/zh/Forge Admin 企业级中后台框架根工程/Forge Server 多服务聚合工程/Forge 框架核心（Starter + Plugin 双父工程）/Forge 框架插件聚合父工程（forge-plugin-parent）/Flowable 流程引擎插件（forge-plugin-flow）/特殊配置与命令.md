通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明 `FlowAutoConfiguration` 实现零配置接入；启用 Redis 时需在类路径引入 `spring-boot-starter-data-redis`，否则 `FlowEventPublisher` 不会注册；Flowable 引擎行为通过 `flowable.*` 前缀的 application.yml 配置（如 `database-schema-update`、`async-executor-activate`、`history-level`）。
