- 每个解析器/分块器实现类标注 `@Component` 并通过接口方法返回固定字符串标识（`getSupportedType` / `getStrategy`），由对应 Registry 在启动时收集并构建映射表。
- Registry 采用延迟初始化 Map：首次访问时通过 Stream.collect 将注入的策略列表转为 `Map<key, strategy>`，键冲突时保留先注册的实例。
- 解析失败或未知类型统一抛出 `BusinessException`，而非返回空或异常对象，便于上层统一错误处理。
- DTO 提供静态工厂方法（`ParsedDocument.of`、`ChunkResult.of`）用于快速构造只读字段组合。
- 分块策略通过 `configJson` 字符串传入参数，各实现自行解析，保持配置与策略解耦。
