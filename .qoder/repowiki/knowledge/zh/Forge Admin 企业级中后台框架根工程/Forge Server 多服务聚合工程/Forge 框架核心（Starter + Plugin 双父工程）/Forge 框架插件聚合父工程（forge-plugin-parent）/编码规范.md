- 每个插件为独立 Maven 模块，拥有自己的 `src/main/java`、`resources/mapper`、`resources/sql` 与测试包结构
- 通过 `resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 注册 Spring Boot 自动装配类
- 数据库变更以 SQL 脚本置于 `resources/sql/` 或 `sql/` 目录，配合 MyBatis Mapper XML 完成持久化映射
- 对外暴露的接口统一采用 Controller + Service + Mapper + Entity/DTO/VO 的分层组织方式
- 安全与权限控制基于 Sa-Token，并通过统一的 Permission 注解或策略模式在各插件中复用
