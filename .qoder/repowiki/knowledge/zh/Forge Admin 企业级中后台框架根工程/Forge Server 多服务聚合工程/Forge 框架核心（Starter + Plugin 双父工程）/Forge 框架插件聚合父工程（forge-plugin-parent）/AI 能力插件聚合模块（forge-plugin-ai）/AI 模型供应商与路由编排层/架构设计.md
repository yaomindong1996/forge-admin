本模块作为 AI 插件的编排层，串联三个子域：`provider/adapter` 提供按厂商（OpenAI Compatible、DashScope 等）抽象的 `AiProviderAdapter` 及注册表；`model/adapter` 提供按能力（Chat/Embedding/Rerank 等）抽象的 `AiModelAdapter` 及注册表；`routing` 通过 `AiModelRouter` 接口与 `PolicyBasedAiModelRouter` 实现，依据 Agent 配置、显式参数或租户级 `AiModelRoutePolicy` 从候选集中筛选可用模型，并借助 `healthRegistry` 获取带租约的 `RoutedInvocation` 以完成熔断保护。路由决策统一产出 `RouteDecision`（含 provider、model、source、reason），调用方再经 model adapter 注册表按 modelKey 选择具体能力适配器，最终委托给对应 provider adapter 创建模型实例，形成「路由 → 能力适配 → 供应商适配」的三层分发链。所有跨子域的共享契约集中在 `routing` 包（`RouteRequest`、`RouteDecision`、`RoutedInvocation`、`AiModelCapabilityCode` 等常量），使 provider 与 model 子模块无需感知彼此的具体实现。
