本模块以 `agent/` 为核心，自顶向下分为三层：
- 接口层：`controller/AiAgentController` 暴露智能体 CRUD，`engine/controller/AgentEngineController` 暴露 ReAct 引擎的启动/暂停/停止等运行时控制。
- 领域与服务层：`domain/AiAgent` + `service/AiAgentService` + `mapper/AiAgentMapper` 负责智能体元数据持久化；`engine/service/AgentEngineService` 作为编排入口，协调 ReAct 循环、权限审批、HITL 中断与事件发布。
- 引擎内核：`ReactAgent` / `ReactLoop` / `ReactContext` 实现基于 Spring AI 的推理-行动循环，通过 `tool/registry/AgentToolRegistry` 动态发现并调用内置或扩展工具（HTTP、图片生成、RAG 检索、技能读取），并通过 `event/` 包以 `AgentEventPublisher` + `AgentEventListener` 发布 SSE 流式事件，由 `persistence/AgentChatPersister` 落盘。
- 横向能力：`permission/` 提供工具级权限决策，`hitl/InterruptStore` 支持人机回环中断恢复，`create/` 提供智能体字段自动生成与绑定推荐。
该模块与同父级的 `chat/`、`provider/`、`model/`、`skill/`、`knowledge/` 等子模块通过共享的 Spring AI 抽象与数据库表协作，自身不直接依赖具体模型实现。
