模块以 Spring Boot 插件形式组织，依赖 `forge-starter-message`（提供 `MessageClient`、`MessageTemplateEngine`、`MessageChannel` 等 SDK）、`forge-starter-orm`、`forge-starter-auth`、`forge-starter-tenant` 及 `forge-plugin-system`。
- 分层结构：`controller` 暴露 `/api/message` 系列 REST 接口；`service` 定义业务接口并由 `impl` 实现，核心 `MessageServiceImpl` 继承 MyBatis-Plus `ServiceImpl`，封装发送、幂等、标记已读、分页查询等逻辑；`mapper` 通过 XML 映射 SQL，对应 `resources/mapper/*.xml`；`domain/entity` 为 MyBatis-Plus 实体（均继承 `TenantEntity` 支持多租户），`dto/vo` 用于入参出参。
- 发送流程：`send()` 在事务内完成模板渲染、创建主记录与批量接收人记录，随后通过 `ApplicationEventPublisher` 发布 `MessageSendEvent`；`@TransactionalEventListener(phase = AFTER_COMMIT)` 监听事件并在事务外调用 `MessageClient` 执行渠道发送，失败仅落库失败状态不回滚，避免长事务占用 DB 连接。
- 渠道抽象：通过 `MessageChannel` 区分 WEB/SMS/EMAIL/PUSH/COLLABORATION，协同渠道采用逐人投递并回写 `delivery_status`、`next_retry_time` 供补偿任务重试。
- 配置入口：`config/MessagePluginConfiguration` 作为插件装配点，当前为空，预留扩展 Bean 注册。
- 数据初始化：`resources/sql/message_tables.sql`、`message_biz_extension.sql` 提供建表脚本。
