- 控制器使用 @RestController + @RequestMapping 定义 RESTful 路径，方法参数通过 @RequestParam/@RequestBody/@PathVariable 注入，返回值统一封装为 RespInfo.success(...)。
- 需要权限控制的接口在方法上标注 @SaCheckPermission("ai:<domain>:<action>") 形式的细粒度权限码。
- Service 继承 MyBatis-Plus ServiceImpl，CRUD 与复杂逻辑集中在 Service 层，Mapper 仅暴露基础或自定义 SQL 方法。
- 涉及多表写入的方法统一使用 @Transactional(rollbackFor = Exception.class) 保证事务一致性，并在失败时抛出 BusinessException。
- 对外部输入进行边界校验与截断：字符串使用 trim(value, maxLength) 限制长度，数值使用 normalizeLimit/normalizePageSize 限制范围，ID 使用 normalizeId 过滤非法值。
- 领域实体与 DTO/VO 分离：controller 接收 DTO，service 内部转换为 domain 实体，返回 VO 给前端，避免将数据库模型直接暴露到接口层。
