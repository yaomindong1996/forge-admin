- 每个能力域通过独立的 `*AutoConfiguration` 类集中声明 Bean，并将运行期组件放入嵌套的 `RuntimeConfiguration` 静态内部类中以 `@ConditionalOnProperty` 条件化加载。
- 能力发布由 `*CapabilityPublisher` 统一负责：从 SourceService 获取已发布元数据，校验 suiteCode/objectCode/actionCode 等段符合 `^[A-Za-z0-9_-]{1,64}$` 正则后组装 `CapabilityPublishDTO` 并提交到 `CapabilityCatalogService`。
- 输入/输出 JSON Schema 通过 Jackson `ObjectNode`/`ArrayNode` 动态构建，统一设置 `$schema` 为 `CapabilitySchemaValidator.DRAFT_2020_12`、`additionalProperties=false`，并在 policy 中写入 `allowedFields`、`requiredFields`、`confirmationMode=MCP_ELICITATION` 等元信息。
- 字段描述采用组合策略：优先取 label，再拼接 remark/helpText/placeholder/dictType/businessType/precision/dateFormat 等扩展属性生成面向调用方的说明文本。
- 所有业务校验失败统一抛出 `BusinessException`，并通过语义化错误码或中文消息区分（如“当前阶段只允许发布…流程动作”“必填字段必须属于允许字段”）。
- 测试结构与源码包一一对应，针对 AutoConfiguration、Publisher、SourceService、Gateway/MCP Handler 等关键类编写单元测试，覆盖条件装配与发布逻辑。
