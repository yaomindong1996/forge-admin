- Mapper XML 统一使用 `<sql id="...Columns">` 片段声明字段列表并通过 `<include>` 引用，避免在多个查询中重复书写列名。
- 软删除与状态过滤在所有查询中固定追加 `del_flag = '0'` 与 `status = '0'` 条件，保证只返回启用且未删除的记录。
- SQL 脚本采用分节注释（-- =============================================）组织建表、菜单、按钮权限、字典、迁移等不同阶段，并使用 `SET @xxx_id = LAST_INSERT_ID()` 串联父子菜单关联。
- 字典类型与字典数据成对插入，键名遵循 `ai_xxx_type` / `ai_xxx` 命名约定（如 ai_provider_type、ai_model_type、ai_status、ai_is_default）。
- 常量集中在单一工具类中以 `public static final String` 形式暴露，并在构造函数中使用私有构造防止实例化。
