本模块由两部分组成：
- `resources/mapper/`：存放 25 个 MyBatis Mapper XML 文件（如 AiAgentMapper.xml、AiModelMapper.xml、AiKnowledgeMapper.xml 等），每个文件对应一个业务实体（Agent、Provider、Model、Knowledge、Skill、ChatSession、Dashboard、PromptTemplate 等），通过 `<sql id="...Columns">` 片段复用字段列表，并集中实现分页查询、按 code/status 筛选等常用 SQL。
- `resources/sql/`：存放 7 个独立 SQL 脚本，负责建表（如 ai_model.sql）、菜单与按钮权限注入（sys_resource）、字典类型与字典数据初始化（ai_provider_type、ai_model_type、ai_status、ai_is_default），以及跨表迁移（如 ai_provider.models JSON → ai_model 表）。
- `java/com/mdframe/forge/plugin/ai/constant/AiConstants.java`：以不可实例化工具类形式集中声明状态码（STATUS_NORMAL/STATUS_DISABLED = '0'/'1'）与是否默认标记（IS_DEFAULT_YES/NO = '1'/'0'），供 Java 层与 SQL 共用同一套枚举值。
依赖方向单向向下：Java 常量被 Mapper XML 和 SQL 共同引用，SQL 仅作用于数据库，Mapper XML 仅描述 SQL 映射，三者互不耦合。
