- 控制器方法统一使用 `@SaCheckPermission` 进行细粒度权限控制，并通过 `@OperationLog(module=..., type=OperationType.X, desc=...)` 记录操作审计。
- 对外 API 请求体与响应体统一通过 `@ApiDecrypt` / `@ApiEncrypt` 注解启用端到端加解密，敏感字段（如 Secret）不在请求中明文传递，由服务层加密落库。
- 跨租户资源访问前调用 `CollaborationTenantHelper.currentTenantId()` 并结合 `SessionHelper.isAdmin()` 做归属校验，非管理员禁止跨租户操作。
- 可选基础设施（如调度器）通过 `ObjectProvider<T>` 或 `@ConditionalOnClass` 条件装配，确保在不部署该能力的服务中仍可正常启动。
- 目录同步采用分阶段状态机：通过 `SocialSyncLog` 记录 stage(FETCH/VALIDATE/PLAN/APPLY/FINALIZE) 与 status(RUNNING/SUCCESS/PARTIAL/FAILED)，失败路径统一收敛为 FAILED 并截断错误摘要。
- Provider/Connector 通过实现 `CollaborationProvider` 并在 `capabilities()` 中声明能力集合，由 `CollaborationProviderRegistry` 在启动期校验能力与 Connector 的一致性。
