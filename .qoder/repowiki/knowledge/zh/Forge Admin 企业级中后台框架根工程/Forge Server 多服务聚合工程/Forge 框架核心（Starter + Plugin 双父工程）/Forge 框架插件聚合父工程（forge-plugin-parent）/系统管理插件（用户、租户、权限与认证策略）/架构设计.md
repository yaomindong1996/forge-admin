模块以 Spring Boot Starter 形式集成到 forge-starter-* 生态中，通过 pom.xml 依赖 core/orm/auth/cache/log/trans/excel/file/datascope/tenant/crypto/social/message/outbound 等 starter，对外暴露 REST API 与可插拔的认证策略。
- 分层结构：controller → service(I*Service) → service.impl → mapper(MyBatis 接口) → entity(实体类)，SQL 映射在 resources/mapper/*.xml，建表/升级脚本在 resources/sql。
- 认证子系统独立于业务 CRUD：strategy 包实现 IAuthStrategy（AbstractAuthStrategy 模板方法封装账号锁定、失败计数、状态检查），具体策略 UsernamePasswordAuthStrategy / PhoneCaptchaAuthStrategy / SocialAuthStrategyImpl 等；auth 包提供验证码策略（LoginCaptchaPolicy + Resolver）、密码编解码（LoginPasswordDecoder）、短信/邮件发送器（MessageSmsCaptchaSender / MessageEmailCaptchaSender）及 RecoveryChannelSupport；listener.SystemSaTokenListener 监听 Sa-Token 事件同步在线用户、封禁/解封状态。
- 安全扩展点：security.ClientCredentialPolicy + ClientSecretCodec 统一处理客户端凭据的 auth_method 校验与密钥编码；constant.OnlineUserPermissions/SystemConstants 集中定义权限常量。
- 数据源与多租户：datasource.SysTenantBusinessDataSourceResolver 按租户解析业务数据源；listener.DictChangeEventListener 监听字典变更事件刷新缓存；listener.ManagedCachePolicyBootstrap 启动时加载缓存策略。
- 依赖方向：controller 仅依赖 service 接口；service.impl 依赖 mapper 与外部 starter；strategy 通过 IUserLoadService 解耦避免循环依赖；listener 仅依赖 ISysUserService / ISysOnlineUserService 做副作用更新。
