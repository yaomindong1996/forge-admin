- 领域实体继承 TenantEntity 并使用 @TableName/@TableId/@TableLogic(value="0", delval="id") 实现多租户与逻辑删除。
- Service 方法对写操作统一使用 @Transactional(rollbackFor = Exception.class) 包裹，并在更新/删除前通过 selectByIdForUpdate 做存在性校验后抛出 BusinessException。
- 向量存储通过 VectorStoreService 抽象 + VectorStoreFactory 按 storeType 字符串 switch 路由，新增后端只需实现接口并扩展 switch 分支。
- Milvus 客户端在 try/finally 中创建并关闭 MilvusClientV2，所有异常统一包装为 BusinessException 并记录日志。
- 集合 schema 通过显式 CreateCollectionReq.CollectionSchema 添加字段与 BM25 Function，而非快速创建模式，以保证 title/content 等字段具备 analyzer 与稀疏向量索引。
- 对外请求/响应数据集中在 service/dto 包下的独立 DTO 类（如 DocumentUploadRequest、KnowledgeSearchRequest、KnowledgeSearchResult），与服务层解耦。
