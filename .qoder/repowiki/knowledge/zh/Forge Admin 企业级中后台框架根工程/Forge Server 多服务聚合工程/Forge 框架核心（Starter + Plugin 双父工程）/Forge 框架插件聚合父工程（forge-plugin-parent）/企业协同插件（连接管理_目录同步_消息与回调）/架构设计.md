模块以 Spring Boot 插件形式装配，入口为 `CollaborationPluginConfiguration`，通过 `ObjectProvider` 收集所有 `CollaborationProvider` 与 `CollaborationConnector` 并注入 `CollaborationProviderRegistry`，在构造期完成 Provider/Connector 能力一致性校验。

- 控制器层 (`controller`)：按职责拆分为连接管理 (`CollaborationConnectionController`)、登录回调 (`CollaborationCallbackController`/`CollaborationLoginController`)、操作与测试 (`CollaborationOperationsController`/`CollaborationMessageTestController`)、凭据迁移 (`CollaborationCredentialMigrationController`)，统一通过 `@SaCheckPermission` 鉴权、`@OperationLog` 记录操作日志、`@ApiDecrypt/@ApiEncrypt` 加解密传输。
- 服务层 (`service`)：`DirectorySyncOrchestrator` 是目录同步核心编排器，严格按 FETCH→VALIDATE→PLAN→APPLY→FINALIZE 五阶段执行，使用 Redisson 分布式锁保证同一连接串行；子组件 `DirectorySnapshotValidator`、`DirectorySyncPlanner`、`ForgeDirectoryWriter`、`UserIdentityMatchPolicy` 分别负责快照校验、差异计划、写入适配与身份匹配策略；另有 `CollaborationDeliveryRetryService`、`CollaborationCallbackInboxService`、`CollaborationIdentityMigrationService` 等独立服务。
- 任务层 (`job`)：`CollaborationSyncJobManager` 基于 `@ConditionalOnClass(ISysJobConfigService.class)` 条件装配，将连接维度的 Cron 映射到 `forge-plugin-job` 的 `COLLABORATION` 分组任务，具体执行由 `CollaborationDirectorySyncJobHandler`、`CollaborationCallbackRetryJobHandler`、`CollaborationDeliveryRetryJobHandler` 承担。
- 适配器层 (`provider/wecom`)：以 `WeComProvider` 声明能力集合，配合 `WeComApiClient`、`WeComCallbackConnector`、`WeComDirectoryConnector`、`WeComLoginConnector`、`WeComMessageConnector` 等企业微信专用 Connector，封装加密、签名、Token 获取与端点解析。
- 数据层 (`domain/entity` + `mapper` + `resources/mapper/collaboration/*.xml`)：MyBatis-Plus Mapper 接口与 XML 映射文件对应 `SocialOrgMapping`、`SocialTag`、`SocialSyncLog`、`SocialCallbackEvent` 等实体；`domain/model` 存放同步命令、计划、结果等无状态值对象；`vo` 用于 API 响应脱敏。
- 依赖方向：controller → service → (provider registry / mapper)；job 仅依赖 service 与 job starter；wecom 适配器仅依赖 starter-collaboration 抽象，不反向依赖上层业务。
