- Controller 统一使用 @RestController + @RequestMapping 分组，并以 RespInfo 包装返回值，写操作通过 @OperationLog(module=..., type=...) 记录审计日志。
- 对外 API 入口统一添加 @ApiDecrypt/@ApiEncrypt 注解，启用加解密拦截。
- 代码生成采用策略模式：定义 CodegenStrategy 接口并由 Velocity/AI/Lowcode 多实现类通过 supports() 方法注册，由上层根据 codegenType 自动路由。
- 领域模型（如 FormulaConfig）采用不可变设计：final 字段 + Builder 构造 + 构造函数内 validate() 校验必填/互斥关系，集合字段返回 Collections.unmodifiableXxx。
- MyBatis 实体统一以 Ai* 前缀命名（AiBusinessObject、AiCrudConfig 等），Mapper 接口与 XML 文件一一对应存放于 mapper/ 和 resources/mapper/。
- DTO/VO 按业务域分包（businessapp/businessprocess/formula/lowcode），请求与响应类型分离，避免直接暴露实体。
