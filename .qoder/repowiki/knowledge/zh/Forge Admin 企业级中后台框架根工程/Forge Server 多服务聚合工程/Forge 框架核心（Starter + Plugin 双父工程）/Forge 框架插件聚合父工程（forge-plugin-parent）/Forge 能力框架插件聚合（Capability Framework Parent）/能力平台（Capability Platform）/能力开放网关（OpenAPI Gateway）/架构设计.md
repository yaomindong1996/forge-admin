模块以 Spring Boot AutoConfiguration 为装配中心：`OpenGatewayAutoConfiguration` 通过 `@ConditionalOnProperty(prefix="forge.capability.open-gateway", name="enabled")` 条件启用，并按依赖顺序在 `CapabilityIdentityAutoConfiguration` 之后加载，复用 openapi-security 的防重放、限流、幂等组件。
- 入口层：`CapabilityOpenGatewayController` 仅负责接收原始字节请求体（便于签名验签）、解析 payload 并委托编排器；所有响应统一为 `OpenGatewayResponse`，不混用框架 RespInfo。
- 认证层：`OpenGatewayAuthenticator` 支持两种模式——Bearer 短令牌（USER/SERVICE 委托）与 HMAC-SHA256 客户端签名（仅 SERVICE），并通过 `OpenApiReplayGuard` 做防重放，最终产出统一的 `AuthenticatedCapabilityIdentity`。
- 编排层：`CapabilityInvokeOrchestrator` 实现九步流水线（scope→授权目录→主体类型→RBAC→限流→幂等→输入 Schema 校验→策略校验→适配器执行→输出 Schema 校验→审计），失败路径统一映射为 `OpenGatewayException` 错误码与 HTTP 状态码。
- 适配层：`OpenGatewayCapabilityResolver` 从不可变发布版本快照中按 `sourceType+behavior` 匹配唯一的 `GovernedOpenGatewayAdapter`，将业务动作与平台解耦。
- 数据层：`mapper` 包通过 MyBatis 访问能力目录与幂等快照表（`AiCapabilityOpenapiIdempotency`），`job.OpenapiIdempotencyCleanJob` 作为定时任务分批清理过期幂等记录。
- 配置层：`OpenGatewayProperties` 集中管理开关、读写限流配额与幂等 TTL，默认关闭（失败关闭策略）。
