本模块以 Spring Boot 自动装配为核心编排方式，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 依次加载 controlplane、identity、opengateway 三个子模块的 `AutoConfiguration`，使它们在同一个应用上下文中协同工作：controlplane 负责能力元数据、客户端与授权的持久化与 REST 管理；identity 在控制面之上提供 MCP OAuth2、短期 Access Token、外部 OIDC/客户端断言身份映射及基于能力的权限校验；opengateway 作为统一外部入口，复用 identity 的认证能力并调用 controlplane 的能力目录与服务编排。三者共享同一套 MyBatis Mapper/XML 与数据库表（AiCapability/AiCapabilityVersion/AiCapabilityClient/AiCapabilityGrant/AiCapabilityAccessToken/AiCapabilityExternalIdentity 等），并通过 service 层与 VO/DTO 契约进行跨子模块通信，形成“控制面治理 → 身份鉴权 → 网关编排”的分层协作。
