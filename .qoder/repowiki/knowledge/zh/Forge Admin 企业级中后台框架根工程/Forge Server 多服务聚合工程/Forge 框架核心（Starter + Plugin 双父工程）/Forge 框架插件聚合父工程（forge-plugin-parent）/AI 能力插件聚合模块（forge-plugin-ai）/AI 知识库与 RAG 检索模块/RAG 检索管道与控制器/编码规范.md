- 检索步骤以 `RagSearchHandler` 接口抽象并通过 `@Component` 注册，由 `RagSearchPipeline` 构造期注入并按固定顺序编排执行。
- 各 Handler 通过读写 `RagSearchContext` 中的 typed 字段（vectorResults/bm25Results/hybridResults/fusedResults/finalResults）传递中间结果，而非方法返回值。
- 对下游依赖（向量存储、Rerank 模型、Provider）的异常与缺失均做降级处理：记录 warn/debug 日志并将结果置为空列表或直接透传，保证管道不中断。
- 对外暴露的 Controller 统一使用 `@RestController` + `@RequestMapping` 前缀 + `@SaCheckPermission` 权限注解，并以 `RespInfo.success(...)` 包装返回。
- 可插拔算法（如 RRF、加权求和）以独立工具类形式放在 `fusion/` 包下，不包含 Spring 注解，便于被不同 Handler 复用。
