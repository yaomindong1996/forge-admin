- 每个多模态能力拆分为 controller/service/adapter/domain 等子包，职责单一且边界清晰。
- 对外部模型厂商的调用通过 `*ModelAdapter` 接口抽象，具体实现由 `AiModelAdapterRegistry` 按 modelId 动态选择，新增厂商无需改动服务代码。
- Service 中先解析 Agent/Model/Provider，再经 `AiSecretCrypto.isEncrypted` 判断后解密 apiKey，统一处理敏感信息。
- 图片与语音结果统一通过 `FileManager.upload` 写入文件系统，service 只返回 fileId，不直接操作 IO。
- Controller 方法统一使用 `@SaCheckPermission` 标注资源级权限，并以 `RespInfo.success(...)` 包装返回值。
- 图片生成采用 `@Async` 异步执行，通过 `AiImageGenerateStatus` 枚举维护 PENDING/GENERATING/SUCCESS/FAILED 状态流转。
