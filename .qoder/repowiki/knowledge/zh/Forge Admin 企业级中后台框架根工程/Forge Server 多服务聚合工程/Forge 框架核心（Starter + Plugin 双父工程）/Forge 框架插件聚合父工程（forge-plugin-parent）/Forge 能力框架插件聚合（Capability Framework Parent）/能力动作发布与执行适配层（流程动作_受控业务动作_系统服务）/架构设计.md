模块以 Spring Boot 自动装配为核心，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明两个独立的能力域：`flowaction`（流程动作）和 `secureaction`（受控业务动作 + 系统服务）。每个域对应一个 `*AutoConfiguration`：`FlowActionAutoConfiguration` 与 `SecureActionAutoConfiguration` 均将“控制面”Bean（SourceService、Publisher、Catalog 映射）无条件注册，而“运行面”Bean（执行适配器、MCP Handler、目录服务等）通过嵌套 `@Configuration(proxyBeanMethods = false)` + `@ConditionalOnProperty(prefix = "forge.capability.*-actions", name = "enabled")` 条件化加载，使能力发布在外部执行不可用时仍可工作。

内部按职责划分为固定子包：`config` 装配 Bean；`source` 提供 `RegistrationSource` / `SourceService` 用于从生成器模型读取已发布对象并导出字段元数据；`publish` 中的 `*CapabilityPublisher` 负责把 Source 信息转换为 `CapabilityPublishDTO`（含 JSON Schema input/output 与 policy），调用 `CapabilityCatalogService` 完成发布；`system` 暴露平台内置系统服务（如启动流程、系统服务目录）；`gateway` / `mcp` 提供对外网关与 MCP 工具贡献者；`service` 封装执行适配（如 `FlowActionExecutionAdapter`、`FlowApplicationSubmissionService`）；`mapper` + `resources/mapper/*.xml` 使用 MyBatis 访问持久层。依赖方向单向指向 `forge-plugin-capability-core`、`forge-plugin-capability-platform`、`forge-plugin-mcp`、`forge-plugin-generator`、`forge-flow-client`，不反向依赖上层业务。
