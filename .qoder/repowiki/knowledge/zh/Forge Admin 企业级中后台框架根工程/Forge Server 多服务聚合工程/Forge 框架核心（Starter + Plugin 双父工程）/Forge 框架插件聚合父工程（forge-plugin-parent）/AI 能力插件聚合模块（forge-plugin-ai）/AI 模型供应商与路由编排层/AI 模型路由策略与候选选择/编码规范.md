- 路由决策通过不可变 record（`RouteRequest`、`RouteDecision`、`RoutedInvocation`）在层间传递，避免可变状态泄漏。
- 所有跨租户访问均通过 `requireTenantId` / `requireSameTenant` 校验，确保策略、供应商、模型三者租户一致。
- 业务异常统一抛出 `BusinessException` 并附带中文描述，用于向控制器层暴露错误原因。
- 策略与目标实体的 JSON 字段（如 `requiredCapabilities`）通过 `ObjectMapper` + `TypeReference` 在 DTO/Entity/VO 之间序列化为 List<String>。
- CRUD 操作使用 `@Transactional(rollbackFor = Exception.class)` 包裹，并在 Service 层集中做参数校验（非空、唯一性、存在性）。
- 控制器方法统一使用 `RespInfo.success(...)` 包装返回值，并通过 `@SaCheckPermission("ai:model-routing:*")` 声明细粒度权限。
