- 所有对外暴露的服务类使用 Lombok `@RequiredArgsConstructor` 注入依赖，并通过 AutoConfiguration 中的 `@Bean` 方法组装复杂构造参数。
- 业务异常统一通过 `BusinessException` 抛出，错误码使用字符串常量（如 `INVALID_ARGUMENT`、`APPROVAL_PAYLOAD_INVALID`、`IDEMPOTENCY_CONFLICT`），并在 MCP 层映射为标准错误码。
- 对敏感输入（审批请求体）在落库前通过 `CapabilityPayloadCrypto` 进行加密，并使用包含 tenantId/id/clientId/capabilityId/version/digest 的 AAD 绑定防篡改。
- 幂等性通过 `idempotencyKey` + 唯一索引实现，提交前先查后插，捕获 `DuplicateKeyException` 走复用或恢复分支。
- 需要独立事务边界的操作使用 `TransactionTemplate` 配合 `PROPAGATION_REQUIRES_NEW` 显式开启新事务，而非依赖声明式事务。
- JSON 入参在计算摘要前经 `canonicalize` 递归排序 Map 键，保证相同语义的请求产生一致 SHA-256 摘要。
