- Service 层统一继承 MyBatis-Plus 的 `ServiceImpl<M, T>`，并通过 `@Service` + `@RequiredArgsConstructor` 注入 Mapper。
- 业务异常统一抛出 `BusinessException`，并在 Controller/Client 层捕获后转换为 `RespInfo` 或 `AiClientResponse.fallback`。
- 上下文注入按 `configType`（RULE/SPEC）分类查询，并按 `sort` 升序拼接为 systemPrompt，同时限制最大长度截断。
- 流式调用通过 `doOnSubscribe`/`doOnError`/`doFinally` 钩子统一记录观测指标与释放健康租约，区分 SUCCESS/FAILED/CANCELLED 等结果。
- 模板操作方法以 `@Transactional(rollbackFor = Exception.class)` 包裹，并对输入进行 trim/长度限制/默认值填充等归一化处理。
