- 可插拔扩展通过「接口 + Factory」模式实现：策略类实现 `ExternalAuthStrategy`/`DataAdapter`，由对应 `*Factory` 在构造时收集所有实现并按类型键注册，缺失时回退到 None 实现。
- 控制器统一使用 `@RestController` + `@RequestMapping` 分组，并通过 `@ApiEncrypt`/`@ApiDecrypt` 注解启用框架级加解密，返回值封装为 `RespInfo`。
- 实体继承 `TenantEntity` 并使用 MyBatis-Plus 的 `@TableName`/`@TableId`/`@TableField` 注解，字段命名与 SQL 建表脚本一一对应。
- 敏感信息（请求/响应体、错误消息、URL）在落库前一律经 `ExternalSensitiveDataMasker` 脱敏，并对超长文本做 truncate 截断。
- 服务实现通过 `@RequiredArgsConstructor` 注入依赖，关键流程方法用 `@Slf4j` 记录耗时与失败告警，异常统一包装为 `BusinessException`。
- 配置项（JSON字符串）统一通过 `parseJsonObject` 安全解析，解析失败抛出 `BusinessException`，避免脏配置导致运行时异常。
