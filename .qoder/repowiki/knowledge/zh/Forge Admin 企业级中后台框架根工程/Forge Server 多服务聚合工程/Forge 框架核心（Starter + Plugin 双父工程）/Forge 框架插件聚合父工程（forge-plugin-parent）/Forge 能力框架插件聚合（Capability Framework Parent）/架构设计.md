本聚合模块以 Maven parent POM 组织四个子模块，形成分层协作：
- capability_core 定义 `CapabilityDefinition`/`CapabilityExecutor`/`CapabilitySource`/`CapabilityRegistry` 等 SPI 与运行时模型，是所有上层模块共享的协议层。
- capability_actions 基于 core 的 SPI 提供流程动作、受控业务动作和系统服务的 Source/Executor/Publisher/MCP 适配，作为具体能力实现的载体。
- capability_platform 通过 controlplane（注册发布、授权、审计）、identity（OAuth/OIDC、外部身份映射、令牌）、opengateway（统一调用编排）三个子包装配 Spring Boot 插件，消费 core 的注册表并调度 actions 的执行。
- capability_high_risk_approval 在 actions 之上叠加人工审批策略，通过 `HighRiskApprovalExecutionAdapter` 包装 executor，并在 platform 的控制面暴露审批查询与回调接口。
各子模块均通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动配置，由父工程统一依赖管理版本；actions 与 high-risk 模块依赖 core，platform 同时依赖 core、actions 与 high-risk，从而形成单向依赖链，避免循环引用。
