模块以 `AiModelRouter` 接口为对外边界（`route`/`preview`），由 `PolicyBasedAiModelRouter` 实现核心路由逻辑：当 Agent 未显式指定 provider/model 且模式为 POLICY 时走策略分支（`selectPolicy`），否则按请求参数、Agent 默认或 Provider 默认回退；策略分支通过 `AiModelRoutingQueryMapper` 查询候选并按租户、启用状态、能力集过滤，再经 `AiModelHealthRegistry` 进行熔断/健康检查与租约获取。数据层采用 MyBatis-Plus 实体（`AiModelRoutePolicy`、`AiModelRouteTarget`）配合独立 Mapper（`AiModelRoutePolicyMapper`、`AiModelRouteTargetMapper`、`AiModelRoutingQueryMapper`）；业务编排由 `AiModelRoutePolicyService` 负责策略 CRUD 与校验；HTTP 入口 `AiModelRoutingController` 暴露 `/ai/model-routing` 下的分页、详情、增删改、预览接口，并通过 Sa-Token 权限注解保护。常量集中在 `constant/`（能力码、路由来源、原因、选择模式），DTO/VO 用于入参出参隔离。依赖方向单向：controller → service/router → mapper/provider/service/health，不反向引用上层。
