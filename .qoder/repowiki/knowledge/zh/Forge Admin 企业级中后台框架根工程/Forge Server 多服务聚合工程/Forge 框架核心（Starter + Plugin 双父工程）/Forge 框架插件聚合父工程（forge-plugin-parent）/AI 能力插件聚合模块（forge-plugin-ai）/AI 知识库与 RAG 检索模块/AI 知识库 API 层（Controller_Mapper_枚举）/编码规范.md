- 控制器类使用 @RestController + @RequestMapping 定义资源路径，并通过 @RequiredArgsConstructor 注入 Service 依赖。
- 每个业务接口方法均标注 @SaCheckPermission("ai:xxx:action") 以声明式控制操作权限。
- 所有接口返回值统一封装为 RespInfo<T>，通过 RespInfo.success(...) 返回成功响应。
- 分页查询方法参数固定包含 pageNum/pageSize 默认值，并支持可选的筛选条件字符串参数。
- Mapper 接口继承 BaseMapper<Entity> 并在需要时扩展自定义分页与锁查询方法，参数通过 @Param 命名。
- 状态类以枚举形式集中定义，同时保存 code 与 label 两个字段并提供 matches(value) 匹配方法。
