- 每个业务域按 controller/domain/dto/service/mapper/vo 分层组织，并通过同名 Mapper XML 文件进行 SQL 映射。
- 可插拔能力（工具、文档解析器、分块器、向量存储、模型/供应商适配器）均以接口 + Registry 形式注册，新增实现只需放入对应包即可被发现。
- 跨子模块的并发安全通过 `AiProviderService.lockForModelSummary` / `lockAllForDefaultSwitch` 在事务内显式加锁后再操作 model/provider 表。
- 对外暴露的 API 统一经 Controller → Service → Mapper 三层，VO/DTO/Domain 严格分离，枚举集中放在 enums/ 或 constant/ 包下。
- 异步与流式处理优先使用 WebFlux 的 ServerSentEvents 与 Reactor 类型（如 AgentEventWebFluxStream），避免阻塞 I/O。
