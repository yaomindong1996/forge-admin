- 所有 Bean 通过 `@Bean @ConditionalOnMissingBean` 暴露，便于上层 capability 插件替换实现（如 `ExactRedirectUriRegistry`、`DelegationAuthorizationCodeStore`）。
- HTTP 控制器统一加 `@RequestMapping("/ai/capability/oauth")` 并通过 `@Conditional(CapabilityIdentityRequiredCondition.class)` 条件启用，配合 `@OperationLog(module="MCP用户授权", ...)` 记录审计日志。
- 敏感时间参数统一通过 `java.time.Clock` 注入而非直接调用 `LocalDateTime.now()`，便于测试与跨时钟域验证。
- 数据库操作使用 `@Transactional(rollbackFor = Exception.class)` 包裹，并在并发冲突或状态变化时抛出 `CapabilityIdentityInfrastructureException` 明确区分基础设施异常。
- 租户隔离通过 `CapabilityTenantContext.execute(tenantId, ...)` 包裹关键逻辑，确保 token 查询、用户加载等操作在正确租户上下文中执行。
- 外部输入（client_id、token、scope 等）一律经 `OAuthRequestValidator.requireLength` 等校验器进行长度与格式检查，非法值统一转为 `BusinessException` 返回标准错误码。
