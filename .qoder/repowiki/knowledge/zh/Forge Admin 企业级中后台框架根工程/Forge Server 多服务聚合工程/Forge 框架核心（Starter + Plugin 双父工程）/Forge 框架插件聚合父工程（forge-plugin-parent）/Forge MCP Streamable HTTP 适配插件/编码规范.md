- 通过 `@ConditionalOnProperty(prefix = "spring.ai.mcp.server", name = "enabled", havingValue = "true")` 控制整个 MCP 子系统的按需启用。
- 对外扩展点采用函数式接口（`McpToolContributor`、`McpRequestLifecycle`），并提供 `noop()` 默认实现以便无感知接入。
- 所有错误响应统一通过 `writeError`/`writeUnauthorized`/`writeForbidden` 等私有方法生成包含 `requestId`、`errorCode`、`message` 的 JSON 结构，并附加 `X-Request-Id` 响应头。
- 工具定义通过 `McpToolContributor` 贡献并由 `McpToolContributorAggregator` 集中去重与排序，禁止直接注册重复的工具名。
- JSON Schema 投影一律经由 `McpToolSchemaProjector` 进行，并在遇到 nullable 类型时抛出 `CapabilityDefinitionException` 以阻止不支持的 schema 进入 MCP 层。
