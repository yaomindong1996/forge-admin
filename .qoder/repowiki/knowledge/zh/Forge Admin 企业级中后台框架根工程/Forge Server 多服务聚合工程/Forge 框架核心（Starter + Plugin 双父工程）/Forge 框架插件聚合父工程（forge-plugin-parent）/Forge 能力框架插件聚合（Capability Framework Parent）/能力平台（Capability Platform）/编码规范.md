- 每个子模块通过独立的 `*AutoConfiguration` 类暴露能力，并由顶层 `AutoConfiguration.imports` 统一注册。
- 数据库访问统一使用 MyBatis Mapper 接口配合 `resources/mapper/*.xml` 映射文件，实体以 `AiCapability*` 前缀命名。
- 跨子模块的数据交换通过 DTO/VO 对象传递，避免直接暴露 domain 实体。
- 安全相关逻辑集中在 `security/` 或 `authorization/` 包中，通过策略接口（如 CapabilityGrantPolicy、ForgeCapabilityAuthorizationPolicy）实现可插拔。
