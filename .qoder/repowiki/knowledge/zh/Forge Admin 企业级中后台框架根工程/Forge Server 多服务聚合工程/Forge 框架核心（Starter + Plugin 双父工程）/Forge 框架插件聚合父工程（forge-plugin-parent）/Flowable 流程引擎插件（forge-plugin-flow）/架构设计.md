模块以 `com.mdframe.forge.starter.flow` 为根包，采用分层 + 领域聚合的组织方式：
- 入口与装配：`config/FlowAutoConfiguration` 通过 `@AutoConfiguration` 注册到 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`，在 `ApplicationReadyEvent` 中动态向 Flowable `ProcessEngineConfiguration` 注册 `FlowTaskEventListener`，并定义名为 `flowEventExecutor` 的异步线程池供事件发布使用。
- 领域实体与数据层：`entity/` 下按流程域划分（Entry/Form/Model/Task/Business 等），对应 `mapper/` 下的 MyBatis-Plus Mapper 接口及 `resources/mapper/*.xml` SQL；`sql/` 目录提供建表脚本（含 v2 演进脚本）。
- 服务层：`service/` 定义领域接口（如 `FlowRuntimeService`、`FlowTaskService`、`FlowInstanceService`、`FlowModelService` 等），`service/impl/` 实现业务编排，依赖 Flowable 的 `RuntimeService`/`TaskService` 完成流程启动、流转、审批、超时处理，并通过 `FlowBusinessObjectRuntimeAdapter` SPI 对接外部业务对象。
- 事件与扩展：`event/` 提供 `FlowEventPublisher`（基于 Redis Pub/Sub，`@ConditionalOnClass(StringRedisTemplate.class)` 可选）、`FlowWebhookNotifier` 以及 `FlowModelPublishEvent`/`FlowTaskNotifyEvent`；`listener/` 中的监听器消费 Flowable 引擎事件；`spi/FlowMonitorUserLookup` 暴露用户查询扩展点。
- 辅助组件：`helper/` 解析 BPMN XML 与节点策略；`job/` 集成 `forge-starter-job` 提供定时任务执行器；`delegate/FlowCcNodeDelegate` 作为 Flowable 委托节点；`template/` 提供模板工厂；`dto/vo/enums` 承载入参、出参与状态枚举。
依赖方向单向向下：配置 → 服务 → 实体/Mapper → Flowable 引擎，事件通过 Spring 事件与 Redis 解耦向外广播。
