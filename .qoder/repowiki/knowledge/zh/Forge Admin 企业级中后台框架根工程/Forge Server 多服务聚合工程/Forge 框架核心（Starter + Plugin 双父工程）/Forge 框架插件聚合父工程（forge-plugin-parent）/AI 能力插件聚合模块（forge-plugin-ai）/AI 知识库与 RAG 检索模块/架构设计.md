本模块以 `knowledge/` 与 `rag/` 两个子包构成知识入库与检索的双阶段流水线：
- 入库阶段（knowledge）：Controller → Service → Parser/Chunker 策略注册表 → VectorStoreFactory/MilvusVectorStoreService，完成文档解析、分块、向量化并持久化到 MyBatis-Plus 实体（AiKnowledge/AiKnowledgeDocument/AiKnowledgeChunk/AiStoreInstance），同时通过 SSE 推送 DocumentProcessEvent。
- 检索阶段（rag）：RagSearchPipeline 按 searchType 路由到 VectorSearchHandler/BM25SearchHandler/HybridSearchHandler，经 Fusion（RRF/WeightedSum）、Rerank、Finalize 等 Handler 链式处理，最终由 RagSearchController 暴露调试与搜索结果。
- 两阶段共享同一套 domain 实体与 AiStoreInstance 配置，使知识库文档在入库后直接参与 RAG 多路检索；ParserRegistry、ChunkerRegistry、VectorStoreFactory 均以“接口 + Registry/Factory”形式实现可插拔扩展。
