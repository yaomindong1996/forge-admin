- 每个业务域采用 controller → I*Service → impl/*ServiceImpl → *Mapper → entity 的标准分层，Controller 仅负责参数接收与响应包装。
- 服务接口以 I 前缀命名（ISysUserService、IClientService 等），实现类放在 service.impl 子包并以 ServiceImpl 后缀。
- MyBatis Mapper 接口与 XML 一一对应，XML 文件置于 resources/mapper 下并按 Sys*Mapper.xml 命名。
- 认证流程通过 AbstractAuthStrategy 模板方法统一编排 validateRequest → doAuthenticate → checkUserStatus → handleLoginSuccess，子类仅实现参数校验与具体认证逻辑。
- 可插拔能力通过策略模式实现：验证码策略（LoginCaptchaPolicyResolver）、客户端认证方式（ClientCredentialPolicy）、登录策略（IAuthStrategy 多个实现）均提供默认值并在异常时抛出 IllegalArgumentException。
- 跨领域副作用（登录/登出、踢下线、封禁、缓存刷新、字典变更）通过 Spring 组件监听器（SystemSaTokenListener、DictChangeEventListener）订阅事件完成，避免在核心流程中硬编码。
