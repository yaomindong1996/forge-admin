模块按职责划分为三个子包：
- `client`：对外暴露 `AiClient` 接口及 `AiClientImpl` 实现，封装请求路由、会话记忆、流式响应、观测记录与健康租约释放；`AiClientController` 通过 `/ai/client/{call,stream}` 暴露 REST/SSE 接口，`ChatClientCache` 缓存底层 ChatClient，`ContextInjector` 在构建 systemPrompt 时注入编码规范与 SPEC 上下文。
- `context`：基于 MyBatis-Plus 的 `ServiceImpl` 模式维护 `AiContextConfig`（规则/规范类上下文），由 `AiContextConfigService` 提供按 agentCode 查询能力，供 `ContextInjector` 使用。
- `prompt`：独立 CRUD 服务 `AiPromptTemplateService`，管理 `AiPromptTemplate` 模板的增删改查、分页、启用计数（use/test/download）与模板渲染参数校验，通过 `AiPromptTemplateController` 暴露管理接口。
依赖方向单向：`client` → `context` + `prompt`（仅读取上下文/模板数据），`context` 与 `prompt` 之间无相互依赖，均通过各自的 Mapper 直接访问数据库。
