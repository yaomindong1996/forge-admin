模块以 `adapter` 子包为核心：定义 `AiEmbeddingModelAdapter`、`AiRerankModelAdapter` 等抽象接口，每个具体供应商实现一个 `@Component`（如 `OpenAiCompatibleEmbeddingModelAdapter`），通过 Spring 自动注入到 `AiModelAdapterRegistry`；注册表在构造时收集所有同类型适配器列表，调用方传入 `modelKey` 后由适配器 `supports()` 匹配，找不到则抛出 `BusinessException`。`constant/AiModelType` 枚举集中维护模型分类（chat/vision/embedding/rerank/image_generation/video_generation/asr/tts）并提供 `fromCode` 与基于 modelId 启发式推断的 `inferFromModelId`。持久化层遵循 MyBatis-Plus 标准分层：`domain/AiModel` 实体映射 `ai_model` 表，`mapper/AiModelMapper` 负责分页/启用查询，`service/AiModelService` 继承 `ServiceImpl` 封装增删改、默认模型互斥、能力表 `AiModelCapability` 的替换写入，并在事务提交后通过 `TransactionSynchronizationManager` 异步重置健康状态。`controller/AiModelController` 暴露 `/ai/model` REST 接口，委托 `AiModelProviderManager` 完成跨供应商的创建/更新/删除，并通过 `AiModelConnectionTestService` 提供连接测试。依赖方向单向：controller → service → mapper/domain；adapter 仅被 registry 消费，不反向依赖上层。
