- 控制器方法统一使用 `@SaCheckPermission("ai:capability:...:")` 声明细粒度权限，并通过 `@OperationLog(module = ..., type = OperationType.X, desc = ...)` 记录操作日志，返回值封装为 `RespInfo.success(...)`。
- Service 层对写操作方法统一标注 `@Transactional(rollbackFor = Exception.class)`，并在方法开头通过 `requireTenant(tenantId)` 校验租户上下文有效性。
- 领域对象通过 `@RequiredArgsConstructor` 注入依赖，DTO/VO 采用 record 或静态 `from(...)` 工厂方法进行转换，避免在 Controller 中直接操作实体。
- 安全判定结果统一通过 `CapabilityGrantDecision.allow/deny(code)` 返回，由调用方根据 code 抛出对应的 `BusinessException`，将权限拒绝原因标准化。
- JSON 策略字段（如 fieldPolicy、policySnapshot）统一通过 Jackson `ObjectMapper` 读写为 `JsonNode`，并提供私有 `readJson` 包装方法以统一异常消息。
- 配置项通过 `@EnableConfigurationProperties` 集中声明，关键可插拔组件（`CapabilityClientSecretCodec`、`CapabilityGrantPolicy`）以 `@ConditionalOnMissingBean` 暴露默认实现，便于上层覆盖。
