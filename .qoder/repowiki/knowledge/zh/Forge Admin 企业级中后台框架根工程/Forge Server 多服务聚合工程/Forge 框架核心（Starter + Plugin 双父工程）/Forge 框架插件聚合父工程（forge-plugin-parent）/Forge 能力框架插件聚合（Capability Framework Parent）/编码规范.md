- 每个子模块通过 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动配置类，由 Spring Boot 按需加载。
- 能力实现遵循 core 定义的 SPI：Source 负责注册来源，Executor 负责执行，Publisher 负责生成发布 DTO，Controller 仅做 HTTP 适配。
- 数据库访问统一使用 MyBatis Mapper + XML 映射，实体命名采用 `AiCapability*` 前缀并与 platform 层的领域模型对应。
- 跨模块通信通过 core 的 `CapabilityRegistry` 与 `CapabilityExecutor` 抽象，而非直接耦合具体 action 实现。
