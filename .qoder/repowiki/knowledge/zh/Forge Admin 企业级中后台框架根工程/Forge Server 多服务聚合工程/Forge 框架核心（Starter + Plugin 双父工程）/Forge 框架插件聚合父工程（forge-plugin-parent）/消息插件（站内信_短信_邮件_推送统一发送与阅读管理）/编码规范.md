- Controller 统一返回 `RespInfo.success(...)`，并对公开查询接口标注 `@ApiPermissionIgnore`，请求体加解密通过 `@ApiDecrypt` / `@ApiEncrypt` 全局处理。
- Service 层继承 MyBatis-Plus `ServiceImpl` 并实现自定义接口，所有写操作方法使用 `@Transactional(rollbackFor = Exception.class)` 声明事务。
- 实体类继承 `TenantEntity` 并使用 `@TableName`、`@TableId`、`@TableField(typeHandler = JacksonTypeHandler.class)` 等注解进行 ORM 映射。
- DTO/VO/Entity 三件套分离：入参用 `dto`、内部查询条件也用 `dto`、对外展示用 `vo`，禁止直接暴露实体。
- 发送流程将数据库写入与远程渠道调用解耦：事务内落库后通过 `ApplicationEventPublisher` 发布 `MessageSendEvent`，由 `@TransactionalEventListener(phase = AFTER_COMMIT)` 在事务提交后执行实际发送。
- 租户上下文通过 `TenantContextHolder.executeWithTenant(tenantId, ...)` 包裹关键查询，`resolveTenantId()` 从 `TenantContextHolder` 或 `SessionHelper` 兜底解析默认租户。
