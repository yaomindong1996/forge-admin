- 新增供应商需实现 `AiProviderAdapter` 接口并标注 `@Component`，同时在 `AiProviderAdapterCode` 枚举中登记唯一 code，由注册表自动装配。
- 适配器实现中 Base URL 一律通过 `AiProviderBaseUrlPolicy.normalizeAndValidate(adapterCode(), baseUrl)` 获取，禁止直接使用原始字符串。
- 公共参数校验抽取到私有 `validateCommon` 方法，对 provider/options/apiKey/model 为空场景统一抛出 `BusinessException`。
- 密钥处理遵循“存储密文、使用明文”原则：仅在 `AiProviderAdapterRegistry.decryptProvider` 中解密一次后再传递给适配器，适配器自身不接触加密逻辑。
- 对外暴露的适配器标识统一通过 `AiProviderAdapterCode.require(...)` 解析，避免散落字符串常量导致的不一致。
