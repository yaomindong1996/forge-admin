- 领域模型统一使用 Java record 表达不可变数据结构（如 `CapabilityDefinition`、`CapabilityCallerContext`、`CapabilityPage`），并在构造函数中对必填字段进行非空与格式校验。
- 对外暴露的 JSON 字段（`inputSchema`、`outputSchema`）在 record 中通过 `deepCopy()` 返回副本，防止调用方修改内部状态。
- SPI 接口集中在 `spi` 包下，采用函数式或极简方法签名（如 `@FunctionalInterface CapabilitySource`、`CapabilityExecutor.supports/invoke`），由注册表在启动期组装而非运行时反射。
- 异常体系按职责拆分到 `exception`、`schema`、`execution` 等子包，并通过统一的 `CapabilityErrorCode` 枚举编码错误类型，便于上层统一处理。
- 可插拔组件（`CapabilitySource`、`CapabilityExecutor`、`CapabilityInvocationObserver`、`CapabilityAuthorizationPolicy`）均以 `List<T>` 注入并由 `CapabilityAutoConfiguration` 提供默认实现，用户可通过 `@ConditionalOnMissingBean` 覆盖。
- 注册表中的关键计算（游标签名、快照版本、客户端引用哈希）统一使用 `MessageDigest` SHA-256 配合 `HexFormat` 输出固定长度十六进制摘要，避免明文泄露敏感上下文。
