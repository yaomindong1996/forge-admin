- 领域状态与轻量数据统一使用 Java record 表达（如 `AiInvocationObservation`、`AiModelHealthSnapshot`），避免可变实体泄露。
- 对外暴露的控制器方法统一使用 `@ApiDecrypt` / `@ApiEncrypt` 加解密，并以 `RespInfo.success(...)` 包装返回。
- 健康状态变更通过 `AiModelHealthLease` 的 `success/failure/cancel/abort` 在 finally 语义中结束，内部用 `AtomicBoolean` 保证单次生效。
- 写操作采用「先加锁 → 读快照 → 校验 → 执行业务 → 同步下游」的事务模式，并发冲突通过抛出 `BusinessException` 提示重试。
- 定时任务类标注 `@Component` 并使用自研 `@ScheduledJob(name=, group=, cron=, description=)` 声明调度元信息。
