- 每个模型能力（Embedding/Rerank/Image/ASR/TTS）均通过独立接口 + `@Component` 实现 + 注册表注入 `List<接口>` 的模式扩展新供应商。
- 适配器通过 `getSupportedProvider()` 声明供应商标识，并通过 `supports(modelKey)` 基于 modelId 前缀或关键字（如 `text-embedding*`、`bge-*`）进行匹配。
- 未找到匹配适配器或非法参数时统一抛出框架 `BusinessException`，错误消息包含缺失的 modelKey 或业务上下文。
- DTO→Domain 转换使用 `BeanUtils.copyProperties` 并显式排除 `capabilityCodes` 等非持久化字段，再单独处理能力集合。
- 写操作（新增/修改/删除）使用 `@Transactional(rollbackFor = Exception.class)` 包裹，并在事务提交后通过 `TransactionSynchronizationManager.registerSynchronization` 触发健康状态重置。
- `AiModelType` 枚举集中维护模型分类与从 code/modelId 反推类型的规则，避免在各处散落字符串判断。
