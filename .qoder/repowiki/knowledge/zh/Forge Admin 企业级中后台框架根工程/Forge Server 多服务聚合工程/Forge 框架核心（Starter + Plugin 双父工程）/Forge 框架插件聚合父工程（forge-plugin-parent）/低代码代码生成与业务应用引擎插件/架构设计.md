模块以 Spring Boot Starter 形式集成到 forge-starter-* 生态，通过 `pom.xml` 依赖 core/web/orm/tenant/datascope/crypto/trans/excel/file/job/id 等 starter，并可选依赖 message、flow-client 实现触发器动作扩展。

内部按职责分层组织：
- `controller/`：暴露 REST API（GenController、Business*Controller、Lowcode*Controller、FormulaController 等），统一使用 RespInfo 返回并通过 @OperationLog/@ApiEncrypt/@ApiDecrypt 标注。
- `service/`：领域服务层，按 businessapp/businessprocess/formula/lowcode/crypto 子包划分，封装业务编排；底层通过 `mapper/` MyBatis 接口访问数据库，SQL 映射在 `resources/mapper/*.xml`。
- `domain/entity/`：持久化实体（Ai* 前缀命名）；`domain/formula/` 为纯领域模型（如 FormulaConfig、AggregateEngine），不耦合 ORM。
- `codegen/`：代码生成策略抽象，`CodegenStrategy` 接口由 `VelocityCodegenStrategy`、`AiCodegenStrategy`、`LowcodeStaticCodegenContributor` 实现，通过 supports() 路由选择。
- `businessprocess/schema` + `validation`：业务流程图元数据（Node/Edge/Schema）及校验上下文解析。
- `manager/coderule/`：编码规则引擎（CodeRuleEngine、RadixCodec、SequenceKeyFactory）。
- `constant/`、`enums/`、`dto/`、`vo/`：常量、枚举、请求 DTO、响应 VO 集中管理。
- `util/`：VelocityUtils、DynamicQueryGenerator、GenUtils 等通用工具。
- 模板资源位于 `resources/templates/vm/`，默认模板引擎为 Velocity，可通过 `GeneratorConfig`（`forge.generator.*`）切换 AI/Freemarker。

依赖方向单向：controller → service → (mapper/domain/util)；codegen 策略独立于业务服务，仅依赖 entity/dto；formula 引擎自包含，被 service 调用。
