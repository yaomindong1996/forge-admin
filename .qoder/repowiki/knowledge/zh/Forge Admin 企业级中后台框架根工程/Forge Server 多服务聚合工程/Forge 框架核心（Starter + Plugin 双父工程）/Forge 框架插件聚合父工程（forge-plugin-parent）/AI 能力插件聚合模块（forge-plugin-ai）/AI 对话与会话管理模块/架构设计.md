模块按 chat/、session/、admin/controller/ 三个子包划分职责：
- chat/ 面向用户侧 REST 入口（AiChatController），暴露 /ai/chat/stream、/ai/generate 等 SSE 接口，通过 AiChatService 组装提示词并调用外部 AiClient 进行流式/非流式生成；DbChatMemory 实现 Spring AI 的 ChatMemory 接口，将对话历史持久化到 ai_chat_record 表，并在 get() 中按 DEFAULT_CONTEXT_WINDOW=20 条限制上下文窗口。
- session/ 维护 ai_chat_session 实体及分页、统计、体验指标（AiExperienceMetricsVO）等能力，AiChatSessionService 继承 MyBatis-Plus ServiceImpl，提供 getOrCreate、rename、pin、userPage/adminPage、getStatistics、getExperienceMetrics 等方法，并对删除/置顶等操作做 userId 归属校验。
- admin/controller/AiSessionAdminController 提供 /ai/admin/session 管理端点，复用 session 层服务并以 @ApiDecrypt/@ApiEncrypt 加解密。
依赖方向：controller → service → mapper/domain；chat 与 session 通过 AiChatRecordService 交叉访问消息记录；DTO/VO/Enum 在各包内作为请求响应契约隔离。
