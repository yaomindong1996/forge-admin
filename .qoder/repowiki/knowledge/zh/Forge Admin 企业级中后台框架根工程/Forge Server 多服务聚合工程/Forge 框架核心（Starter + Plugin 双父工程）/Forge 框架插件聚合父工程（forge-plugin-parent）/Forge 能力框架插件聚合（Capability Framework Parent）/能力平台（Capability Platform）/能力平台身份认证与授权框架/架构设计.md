模块以 Spring Boot `@AutoConfiguration`（`CapabilityIdentityAutoConfiguration`）为中心，通过 `@Conditional(CapabilityIdentityRequiredCondition.class)` 按需装配，并在 `CapabilityControlPlaneAutoConfiguration` 之后、`CapabilityAutoConfiguration` 之前执行，从而在控制面与能力面之间注入身份能力。

按职责划分为若干子包：
- `config`：配置属性 `CapabilityIdentityProperties`（含严格 TTL/URI 校验）、启动守卫 `CapabilityIdentityStartupGuard`、条件装配；
- `oauth`：实现 MCP 用户委托授权流程，包含 `CapabilityAuthorizationController`（`/ai/capability/oauth`）、`OAuthRequestValidator`、`DelegationAuthorizationCodeStore`（默认 Redis 实现 `RedisDelegationAuthorizationCodeStore`）及重定向 URI 注册表；
- `token`：短期 Access Token 的签发、校验、撤销与清理，由 `CapabilityAccessTokenService` + `CapabilityAccessTokenCodec` 完成，持久化到 `AiCapabilityAccessToken`；
- `external`：外部身份桥接，`OidcExternalIdentityVerifier` 验证 OIDC ID Token，`ClientUserAssertionVerifier` 验证客户端签名断言，`ExternalIdentityMappingService` 负责首次登录或预绑定映射到内部用户；
- `security`：定义 `CapabilitySecurityPrincipal`、`AuthenticatedCapabilityIdentity`、`CapabilityTenantContext` 等安全上下文载体；
- `authorization`：将能力粒度权限映射到 `CapabilityAuthorizationPolicy`，由 `ForgeCapabilityAuthorizationPolicy` 实现；
- `audit`：`CapabilityInvocationAuditObserver` 记录能力调用审计；
- `mapper` / `domain`：MyBatis Mapper 与实体，对应 `AiCapabilityAccessToken`、`AiCapabilityExternalIdentity`、`AiCapabilityOAuthRedirectUri` 等表；
- `mcp`：MCP 场景下解析 Access Token 并管理执行上下文生命周期。

依赖方向单向向外：本模块依赖 control-plane（`AiCapabilityClientMapper`、`CapabilityGrantService`）、system（`IUserLoadService`）和 openapi security（`OpenApiReplayGuard`），不反向依赖上层能力实现；所有对外暴露的控制器均通过 `@Conditional(CapabilityIdentityRequiredCondition.class)` 屏蔽，确保可被其他 capability 插件覆盖。
