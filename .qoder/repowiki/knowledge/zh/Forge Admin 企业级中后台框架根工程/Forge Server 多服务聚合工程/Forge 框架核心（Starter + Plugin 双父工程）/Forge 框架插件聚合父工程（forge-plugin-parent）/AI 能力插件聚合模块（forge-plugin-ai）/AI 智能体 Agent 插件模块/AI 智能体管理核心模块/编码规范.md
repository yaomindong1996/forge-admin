- Controller 方法统一返回 `RespInfo.success(...)` 或 `RespInfo.success()`，并通过 `@RequiredArgsConstructor` 注入 Service。
- 实体类继承 `TenantEntity` 并标注 `@TableName`、`@TableId`、`@TableLogic`，以支持多租户与软删除。
- Service 层对写入操作使用 `@Transactional(rollbackFor = Exception.class)` 包裹，并在失败时抛出 `BusinessException`。
- 业务参数在 Service 中通过私有 `normalize` 等方法进行归一化与校验（如枚举转换、必填字段检查、关联策略有效性验证）。
