- 所有对外异常统一封装为 `OpenGatewayException`，携带固定 errorCode、HTTP status 与 message，由编排器与控制器统一转换为契约响应，禁止异常外溢到全局处理器。
- 关键流程阶段通过 `AtomicReference<String> stage` 或日志前缀标记（如 SCOPE_AUTHORIZATION、GRANT_RESOLUTION、RATE_LIMIT 等），在成功与失败路径均输出带 requestId 的结构化日志。
- 可插拔的能力执行适配器通过 `List<GovernedOpenGatewayAdapter>` 注入并由 `OpenGatewayCapabilityResolver` 按 snapshot 唯一匹配，避免硬编码分支。
- 配置类使用 `@ConfigurationProperties(prefix = "forge.capability.open-gateway")` 集中声明，并通过 `@EnableConfigurationProperties` 在 AutoConfiguration 中显式启用。
- 所有需要网关功能的组件（Controller、AutoConfiguration）均加 `@ConditionalOnProperty(prefix = "forge.capability.open-gateway", name = "enabled", havingValue = "true")` 实现失败关闭。
- 幂等写入采用 `OpenApiIdempotencyManager.execute(IdempotencyCommand, supplier)` 模式，通过 keyHash 读取/持久化 `OpenGatewayResponse` 快照，并由独立 Job 分批物理清理过期记录。
