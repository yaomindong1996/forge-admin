本模块作为 Maven Parent POM，仅承担依赖与版本收敛职责，不引入运行时逻辑；各子模块均为独立的 Spring Boot 插件，通过各自的 `resources/META-INF/spring/` 自动装配文件暴露能力，由上层应用按需引入对应插件坐标即可启用。跨插件协作遵循统一约定：所有插件共享 forge-framework 基座提供的 MyBatis Mapper、Sa-Token 认证、统一 DTO/VO、数据库迁移脚本（sql/ 目录）与日志/观测基础设施；AI 插件通过 provider/adapter 抽象对接模型供应商，capability 家族通过 core/actions/platform/high-risk-approval 分层解耦协议与实现，其余插件（data/flow/generator/job/system/collaboration/external/mcp/message）各自维护独立的数据表与 REST API，彼此之间不直接耦合，仅在需要时通过平台已暴露的 OpenAPI 或事件进行横向调用。
