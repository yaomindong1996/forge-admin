模块以 Spring Boot `@AutoConfiguration`（`ForgeMcpServerAutoConfiguration`）为入口，通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 自动装配，并声明在 `CapabilityAutoConfiguration` 之后、`McpServerStreamableHttpWebMvcAutoConfiguration` 之前执行，从而在 Spring AI MCP 启动前注入 Forge 定制逻辑。

- 配置层：`ForgeMcpProtocolGuard` 在构造期强制 MCP 协议为 `STREAMABLE`、API 类型为 `SYNC` 且禁用 `stdio`，确保调用方身份在工具线程中完整生效；`ForgeMcpAuthenticationFilter` 作为 `OncePerRequestFilter` 拦截 `spring.ai.mcp.server.endpoint` 路径，解析 `CapabilityCallerContext` 并通过 `McpRequestLifecycle` 包裹请求生命周期。
- 安全上下文传递：`ForgeMcpTransportContextExtractor` 将解析出的 caller 写入 `McpTransportContextKeys`，由 `McpServerFeatures.SyncToolSpecification.callHandler` 经 `exchange.transportContext()` 取回，形成从 Servlet → Transport → Tool 调用的单向依赖。
- 适配器层：`McpCapabilityAdapter` 把 Forge 的 `CapabilityRegistry`/`CapabilityDefinition` 投影为 `McpSchema.Tool`，默认暴露 `ping` 固定工具；`McpToolSchemaProjector` 负责将 JSON Schema 投影为 MCP 输入/输出 schema 并拒绝 nullable 类型；`McpCapabilityResultMapper` 将 `CapabilityResult` 映射为 `CallToolResult`。
- SPI 扩展：`McpToolContributor` 是业务模块贡献稳定工具的唯一入口，`McpToolContributorAggregator` 在启动阶段聚合所有贡献者、校验工具名非空且唯一，并按名称排序输出。
- 依赖方向：本模块依赖 `forge-plugin-capability-core` 与 `forge-starter-web`，仅向上暴露 SPI 给其他 forge 插件使用，不反向依赖业务实现。
