- 所有 Quartz 相关操作集中在 `JobScheduler` 中，方法统一采用 try-catch 将底层异常包装为 `JobScheduleException` 并记录错误日志。
- OpenAPI 控制器统一通过 `JobApiTokenService.authenticate` 解析鉴权、`JobApiAuthorizationService.requireScope` 校验权限、`JobApiRateLimitManager` 做限流，再调用业务服务。
- 执行生命周期通过 `JobExecutionLifecycleService` 集中管理，从 `accept` 到 `markSuccess/markFailed/markSkipped` 的状态转换均经由 Mapper 原子更新，并在终态后回调 `failureAlarmService`。
- 跨进程/远程执行通过 `IJobExecutorRouter` 接口抽象，具体实现按 `executeMode`（BEAN/HANDLER/RPC）在 `JobExecutorRouterManager` 中注册并由 `support()` 匹配。
- 数据访问层遵循 entity → mapper → service 三层结构，实体类位于 `entity/`，MyBatis Mapper 接口在 `mapper/`，XML 映射文件放在 `resources/mapper/` 同名目录下。
- 对外返回统一使用 `RespInfo` 包装，VO 与 DTO 分离：请求入参放 `dto/`，响应出参放 `vo/`，枚举值集中定义在 `constant/`。
