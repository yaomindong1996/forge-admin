模块按 agenttool、dashboard、skill 三个子域组织，每个子域遵循 controller → service → mapper/domain 的分层结构：
- agenttool：AgentToolController 暴露 /ai/agent-tool 下的工具配置与权限管理接口，AgentToolService 继承 MyBatis-Plus ServiceImpl，通过 AiAgentToolConfigMapper/AiAgentToolPermissionMapper 维护工具绑定与权限，并在删除时级联清理权限。
- dashboard：AiDashboardGenerateRecordController 暴露 /ai/dashboard-generate-record 接口，使用 @ApiDecrypt/@ApiEncrypt 加解密；AiDashboardGenerateRecordService 负责生成记录的持久化、最近查询、管理员分页审计、数据集影响分析，并通过 AiDashboardComponentLineageMapper 维护组件血缘，所有写操作带 @Transactional。
- skill：AiSkillController 暴露 /ai/skill 接口，支持 ZIP 技能包上传、SKILL.md frontmatter 解析、Agent 绑定/解绑，以及调用 Spring AI ChatModel 进行 SKILL.md 生成与优化；AiSkillService 依赖 AiProviderService/AiProviderAdapterRegistry/AiSecretCrypto 获取默认 Provider 并构造 ChatModel。
依赖方向单向：controller → service → mapper，service 之间通过 provider 插件能力间接耦合，不跨子域直接调用。
