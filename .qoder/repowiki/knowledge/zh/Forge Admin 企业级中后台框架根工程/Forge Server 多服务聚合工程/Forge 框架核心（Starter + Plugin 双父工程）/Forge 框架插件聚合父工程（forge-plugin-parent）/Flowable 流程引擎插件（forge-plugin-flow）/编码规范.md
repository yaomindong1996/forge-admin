- 每个领域实体在 `entity/` 下对应一个 MyBatis-Plus Mapper 接口，并在 `resources/mapper/` 中提供同名 XML 映射文件，形成一一对应的数据访问约定。
- 服务层统一采用 `XxxService` 接口 + `XxxServiceImpl` 实现的二分结构，实现类使用 `@Service` + `@RequiredArgsConstructor` 注入依赖，事务方法标注 `@Transactional(rollbackFor = Exception.class)`。
- 对外暴露的输入输出分别收敛到 `dto/`（请求 DTO）和 `vo/`（响应 VO），避免将 entity 直接暴露给调用方。
- 所有流程相关状态集中定义在 `enums/` 下的枚举（如 `FlowTaskStatus`、`FlowFormInstanceStatus`、`FlowModelStatus` 等），并以 `getCode()` 形式与数据库存储值对齐。
- 可选依赖通过 `@ConditionalOnClass`（如 `FlowEventPublisher` 对 `StringRedisTemplate`）或 `@Autowired(required = false)` 实现优雅降级，保证未引入 Redis 时模块仍可正常启动。
- 异步事件统一通过 `@Async("flowEventExecutor")` 提交到配置文件中定义的专用线程池，避免阻塞 Flowable 引擎线程。
