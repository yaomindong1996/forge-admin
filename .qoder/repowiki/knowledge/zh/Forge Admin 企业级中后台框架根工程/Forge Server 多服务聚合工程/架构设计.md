forge-server 是顶层 Maven 聚合工程，按职责拆分为多个独立可部署的 Spring Boot 子模块：forge-admin-server（管理后台）、forge-app-server（低代码运行时）、forge-flow/forge-flow-server（流程引擎）、forge-report-server（报表大屏），以及业务示例 forge-business-core；所有子模块共同依赖 forge-framework 下的 starter-parent（认证、租户、数据域、缓存、文件、消息等横切能力）和 plugin-parent（AI、能力平台、协作、外部调用等业务插件）。跨服务通信采用 HTTP 客户端 + 桥接适配器模式（如 AppServer 通过 AppApplicationPermissionAdapter/AppMenuRegisterAdapter 屏蔽 Admin 侧实现），而非直接耦合。数据库层面由 db/migration 与 db/backup 提供统一 Flyway 版本化脚本，各服务启动时共用同一套 schema 与种子数据。scripts/db 提供初始化、安全导出与社区版 schema/seed 导出等运维脚本，贯穿所有子模块的数据库生命周期。
