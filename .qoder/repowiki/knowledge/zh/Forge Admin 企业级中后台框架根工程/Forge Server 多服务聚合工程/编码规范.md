- 每个对外服务均为独立 Spring Boot 应用，拥有自己的 Application 入口与 resources/application.yml 配置
- 横切能力通过 forge-starter-* 组件以 Spring Boot Starter 形式引入，业务扩展通过 forge-plugin-* 插件装配
- 数据库变更统一以 V1.0.N__描述.sql 命名放在 db/migration 或 db/backup 下，由 Flyway 顺序执行
- 跨服务调用通过 HTTP 客户端 + Adapter/Client 接口抽象，避免子模块间直接耦合
- 租户隔离与数据权限通过 starter-tenant 与 starter-datascope 在请求上下文中透传
