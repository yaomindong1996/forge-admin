- Controller 统一使用 `@RestController` + `@RequestMapping` 定义资源路径，并以 `RespInfo.success(...)` 包装返回结果，同时通过 `@ApiEncrypt` / `@ApiDecrypt` 注解开启接口加解密。
- Service 继承 `ServiceImpl<M, T>` 并使用 `@RequiredArgsConstructor` 构造器注入依赖，写操作通过 `@Transactional(rollbackFor = Exception.class)` 声明事务边界。
- 业务校验失败统一抛出 `BusinessException` 并携带中文错误消息，而非返回错误码。
- 目录采用 `parent_id` + `ancestors` 祖级链设计，根节点 `parent_id=0`、`ancestors='0'`，移动目录时批量更新子孙节点的 ancestors 前缀。
- 实体类放在 `domain` 包，请求 DTO 放 `dto`，响应 VO 放 `vo`，三者分离且不与数据库表一一对应。
- SQL 映射以 XML 形式存放在 `resources/mapper/<领域>/<Entity>Mapper.xml`，Java 接口仅保留方法签名，复杂查询通过 XML 编写。
