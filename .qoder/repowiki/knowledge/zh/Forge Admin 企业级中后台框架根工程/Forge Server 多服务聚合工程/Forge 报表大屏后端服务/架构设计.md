模块以 `ForgeReportApplication` 为启动入口，通过 `@MapperScan("com.mdframe.forge.report.**.mapper")` 扫描所有 Mapper，并默认启用 `dev` profile。代码按业务域划分为三个子包：`material`（报表素材 CRUD）、`project`（大屏项目管理）及其子域 `directory`（树形目录）、`template`（模板复制与发布），以及 `mock.controller`（Mock 数据接口）。每个领域遵循 controller → service → mapper/domain/dto/vo 的分层结构，Service 继承 MyBatis-Plus 的 `ServiceImpl`，持久化 SQL 集中在 `resources/mapper/**/*Mapper.xml` 中。依赖方向单向向下：Controller 仅依赖 Service，Service 通过注入其他 Service（如 `ReportProjectService` 依赖 `ReportDirectoryService`）实现跨表事务；外部能力（文件、认证、加密、租户、AI、外部接口代理等）通过 `forge-starter-*` 和 `forge-plugin-*` 依赖引入，本模块不直接实现这些横切能力。数据库脚本位于 `sql/`，使用 MySQL InnoDB，主键采用雪花 ID（`ASSIGN_ID`），并通过 `tenant_id` 字段实现多租户隔离。
