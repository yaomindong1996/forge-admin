模块以 `ForgeAdminApplication` 为启动入口，通过 `@SpringBootApplication(scanBasePackages = {"com.mdframe.forge"})` + `@MapperScan("com.mdframe.forge.**.mapper")` 扫描全部子包；依赖方向自上而下为 controller → service(impl) → mapper(MyBatis-Plus)，并通过 resources 下的 `application.yml` 统一装配 Undertow、MyBatis-Plus、Sa-Token、Flyway、AI/MCP、Capability 等平台能力。

内部按业务域划分子包：
- `admin/bridge`：实现 `AiClientAdapter`、`ApplicationPermissionAdapter`、`MenuRegisterAdapter` 等接口，将本服务作为外部插件的能力提供方接入 Forge 生态。
- `admin/crypto`：暴露 `/api/config/manage/crypto/migration` REST 接口，由 `CryptoMigrationCoordinator` 驱动持久化密文的盘点与执行迁移，并以 `SessionHelper.assertAdmin` 限制超级管理员访问。
- `employee`、`leave`：标准 CRUD 业务域，各自包含 controller/dto/entity/mapper/service 分层结构。
- `mock`：报表测试数据生成控制器。
- `task`：基于 `@Scheduled` 的在线用户清理任务，使用 `TenantContextHolder.executeIgnore` 忽略租户上下文执行跨租户清理。
- `FeatureConfig`：通过 `@ConditionalOnProperty("feature.enabled=true")` 条件启用特性开关。

构建产物同时支持可执行 jar 与 war（`spring-boot-maven-plugin` + `maven-war-plugin`），并集成 Flyway (`flyway-core`/`flyway-mysql`) 进行数据库版本管理。
