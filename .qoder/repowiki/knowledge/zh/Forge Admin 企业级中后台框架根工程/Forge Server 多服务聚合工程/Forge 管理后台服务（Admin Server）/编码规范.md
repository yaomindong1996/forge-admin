- Controller 统一使用 `@RestController` + `@RequestMapping` 定义 REST 端点，所有请求/响应均通过 `RespInfo` 包装返回。
- 对外敏感接口使用 `@ApiEncrypt` / `@ApiDecrypt` 注解声明加解密策略，如 `EmployeeController`、`CryptoMigrationController`。
- 写操作通过 `@OperationLog(module = "...", type = OperationType.X, desc = "...")` 记录审计日志，查询类方法标注 `QUERY`，增删改分别标注对应类型。
- 业务域按 controller/dto/entity/mapper/service(impl) 六层分包组织代码，每个领域（employee、leave 等）遵循相同目录结构。
- 跨租户清理类定时任务在 `TenantContextHolder.executeIgnore` 中执行 Mapper 调用，避免租户上下文干扰。
- 适配器实现类位于 `admin/bridge` 包下，以 `*AdapterImpl` 命名并注册为 `@Component`，用于对接 Forge 插件体系。
