- 超级能力相关文档采用「specs 总设计 + plans 分期实施计划」成对命名，文件名以 `YYYY-MM-DD-主题[-design].md` 形式组织，plans 通过 Spec 引用关联。
- 实施计划使用 `- [ ] Step N:` 复选框任务格式，每个 Task 明确列出 Files、Interfaces（Consumes/Produces）、Run/Expected 验证步骤与 git commit 命令。
- 数据库变更一律通过 Flyway 迁移脚本表达，要求版本单调递增、SQL 幂等（`NOT EXISTS` / `CREATE TABLE IF NOT EXISTS`），并在计划中给出完整 SQL 片段。
- 架构与流程说明统一使用 Mermaid 图表（graph、sequenceDiagram）描述系统交互、认证授权、多租户隔离、RBAC 权限模型等核心流程。
- Global Constraints 段落集中声明跨任务约束（如查询必须写 Mapper XML、`tenant_id=1`、逻辑删除默认 `del_flag bigint`、API Key 脱敏规则、禁止 Service 互相注入等）。
