根目录作为 Forge Admin 的顶层聚合点，将后端（forge_server：Maven 多模块 Spring Boot 聚合工程）、前端（forge_admin_ui / forge_h5_ui / forge_report_ui：Vue3 + Vite/NaiveUI/uni-app 三套独立 SPA）、运行编排（docker_deploy：Compose + Nginx + MySQL/Redis）以及协作资产（docs_and_specs、code_copilot_agents、agents_skills）组织在同一仓库。后端通过 Starter/Plugin 分层装配横切能力，前端各自独立构建并通过 Nginx 反向代理在统一域名下暴露；数据库变更由 Flyway 在 forge/db/migration 集中管理并由 init-db.sh 脚本驱动执行；根 package.json 仅提供 forge:create 脚手架命令，实际开发由各子模块自行 pnpm/Maven 启动。
