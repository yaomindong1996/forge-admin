- 插件与全局能力通过 `src/plugins` 下的 setup 函数集中装配（setupNaive/setupDirectives/setupCustomComponents/initFunction），在 main.ts 中按固定顺序调用。
- API 按业务域拆分目录（ai/auth/data/file/project），每个模块导出独立方法，统一基于 `src/api/http.ts` 的 axios 实例发起请求。
- Pinia store 按功能拆分为 `store/modules/*` 子目录，每个模块包含 index.ts 与类型定义，通过 `setupStore` 统一注入应用。
- 路由采用模块化拆分，`router/modules/*.ts` 分别导出 projectRoutes/chartRoutes/previewRoutes/editRoutes，再在 `router/index.ts` 中聚合为 RootRoute children。
- 组件遵循 Fg* 命名约定并以 `index.vue` + `index.ts` 形式对外暴露，便于按需 import 与类型推导。
- 样式使用 SCSS，并通过 Vite 的 `preprocessorOptions.additionalData` 全局引入 `src/styles/common/style.scss`，公共变量集中在 `_light.scss`/`_dark.scss`。
