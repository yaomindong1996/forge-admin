本模块是 .agents 体系下的 skills 目录，每个子目录代表一个独立 Skill，由 SKILL.md 作为入口描述名称、用途与工作流，并辅以 references/ 存放领域参考文档。
- forge-business-flow-development：面向 Flowable 业务审批流的完整开发流程，以 sample_purchase_order 为参考，覆盖实体/DTO/Service/Controller、FlowDefinition、BusinessCodeFormProvider、BPMN 节点配置、Flyway SQL、App Center 绑定与校验清单，强调 businessKey 格式、状态机幂等性与回调安全等不可协商规则。
- forge-codegen-crud：约束 CRUD 代码生成产物（后端 Java、前端 Vue、Flyway SQL、字典/Excel/资源种子），明确页面模式（single-table / master-detail / left-tree-right-table）、API 契约（POST-safe 的 getById/add/edit/remove/{id}）、逻辑删除与枚举使用规范。
- web-content-fetcher：通过 scripts/fetch.py（Scrapling + html2text）将任意 URL 提取为 Markdown，内置 fast/stealth 双模式与域名路由表，失败时回退到 Jina Reader；依赖安装与调用命令在 SKILL.md 中声明。
依赖方向：SKILL.md → references/ 参考文档 → 外部脚本或工具（fetch.py），Skill 之间相互独立，不互相引用。
