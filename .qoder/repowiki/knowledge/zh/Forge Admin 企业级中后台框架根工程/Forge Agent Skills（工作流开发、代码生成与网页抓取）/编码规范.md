- 每个 Skill 以 YAML front-matter（name/description）开头的 SKILL.md 作为唯一入口，并在正文中按 Overview/Workflow/Non-Negotiables/Deliverables 的结构组织说明。
- 领域知识集中放在同 Skill 目录下的 references/ 子目录中，SKILL.md 通过相对路径引用，避免把规则散落在多处。
- 对关键约束使用 Non-Negotiables 章节显式列出禁止项（如禁止 Map 入参、禁止硬编码字典、禁止 tenant_id=0 等），作为生成或审查时的硬性边界。
- 业务状态与开关统一使用枚举（EnableStatus、业务状态 enum 的 getCode()/matches()），禁止在生成的生产代码中使用字符串或数字字面量。
- 数据库变更一律通过 Flyway 脚本管理，且内置数据必须使用 tenant_id = 1，禁止向 tenant 0 写入业务数据。
- 查询类 SQL 放入 Mapper XML，不在 Service 层拼装 LambdaQueryWrapper 链式查询（仅保留 MyBatis-Plus 基础 CRUD 方法）。
