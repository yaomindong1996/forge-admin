- 视图组件统一使用 `<script setup>` 语法，并通过 `defineOptions({ name, title })` 声明组件名与页面标题。
- 登录相关状态（用户名、密码、验证码、手机号）集中维护在 `loginInfo` 与 `resetForm` 两个 ref 对象中，表单校验通过 computed 派生正则表达式进行。
- 所有后端交互统一通过 `@/utils/http` 的 `request` 或各子模块 `api.js` 发起，并以 `{ code: 200 }` 作为成功判断约定，失败分支统一 `console.error` 并用 `$message` 提示用户。
- 多租户上下文通过 `selectedTenantId` 与 `lStorage` 中的 `login_selected_tenant_id`、`login_social_tenant_map` 持久化，并在切换工作区时触发 `refreshLoginContext` 刷新品牌与登录配置。
- 错误页与通用页面统一包裹在 `CommonPage` 中，并使用 Naive UI 的 `n-result` 展示标准错误信息，导航回首页统一通过 `window.$homePath` 或 `router.replace`。
- 布局与页面标题由 `settings.js` 集中声明（`defaultLayout`、`layoutSettings.layouts`、`validLayoutNames`），`App.vue` 通过 `normalizeLayout` 做安全回退到默认布局。
