模块以 Vue 3 + Naive UI 单页应用形式组织，分为三层：
- 应用入口层：`main.js` 负责创建 Vue 实例、初始化 store/directives/router、加载运行时加密配置并执行企微免登；`App.vue` 作为根组件，通过 `import.meta.glob('./layouts/*/index.vue')` 动态按需加载布局（top-menu/normal/full/app-portal 等），配合 `KeepAlive` 与 `SystemPageLayout` 渲染路由视图，并通过水印、全局 loading、主题覆盖完成壳能力。
- 认证流程层：`views/login/index.vue` 实现用户名密码登录、图形/滑块/短信验证码、忘记密码重置、多工作区选择、三方平台 OAuth 弹窗授权；`views/login/callback.vue` 处理第三方回调，解析 state 中的 platform/bind 前缀，调用 `/social/bind` 或 `api.socialCallback` 换取 ticket 后走统一登录流程，再拉取菜单并跳转首页。
- 业务视图层：`home/index.vue` 为工作台仪表盘，聚合审批待办、公告、访问趋势图表（ECharts）与应用快捷入口；`error-page/403.vue`、`404.vue` 通过 `CommonPage` + `n-result` 展示无权限/不存在页；`external/*` 复用 `manage.vue` 承载外部系统管理页；`base/unocss.vue`、`business/*`、`iframe/index.vue` 分别用于 UnoCSS 演示、业务调试页和 iframe 内嵌页面。
依赖方向单向：视图 → `@/store` / `@/utils/http` / `@/api`，不反向依赖路由守卫或布局组件，布局由 `App.vue` 根据 route meta 动态装配。
