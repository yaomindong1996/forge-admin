- 每个 API 文件仅导出纯函数，内部直接调用 `request.get/post/put/delete`，不封装额外状态。
- 敏感写操作通过 `{ encrypt: true }` 配置或 `postEncrypt` 显式开启加密，读操作默认明文。
- HTTP 实例按用途拆分：`request` 带 baseURL 前缀、`noPrefixRequest` 用于登录等无前缀接口、`mockRequest` 指向 `/mock-api`。
- 加密相关能力（算法、开关、路径匹配）集中通过 `crypto-config` 管理，业务代码不直接持有密钥。
- 所有网络错误经 `resolveResError` 统一处理，并通过 `needTip` 控制是否弹出提示。
- 测试用例与源码同目录放置于 `__tests__/`，使用 `.spec.js` 命名约定。
