模块分为两层：`src/api/` 按业务域组织 API 调用文件（如 `ai/`、`data/`、`system/`、`business/`、`external/`），每个文件导出若干函数，统一通过 `@/utils` 暴露的 `request` 发起 HTTP 请求；顶层 `api/index.js` 聚合用户、菜单、租户、组织等全局接口，并支持开发期动态 `import` mock 数据。

HTTP 基础设施集中在 `src/utils/http/`：`index.js` 基于 axios 创建带 baseURL、超时、拦截器的实例，并导出 `request`、`noPrefixRequest`、`mockRequest` 三个实例；`interceptors.js` 实现请求/响应拦截链，负责注入 Authorization、traceId、页面审计头、防重放参数、全局 loading、错误提示、二进制响应处理、以及根据 URL 匹配决定是否加密/解密（AES/SM4）和密钥协商失败重试。

加密能力由 `src/utils/crypto/` 提供，按算法拆分为 `aes.js`、`rsa.js`、`sm4.js`，并通过 `crypto-config.js`、`key-exchange.js`、`crypto-interceptor.js` 组合出 `encryptRequest` / `decryptResponse` 等对外 API，被 http 拦截器在请求前/响应后调用。

其他通用工具（`storage`、`sse`、`websocket`、`tab`、`collaboration-runtime`、`offline-draft-runtime`、`menu-utils`、`field-permissions` 等）通过 `utils/index.js` 统一 re-export，供上层组件按需引入。依赖方向单向：`api/*` → `utils/http` → `utils/crypto`，工具之间无循环引用。
