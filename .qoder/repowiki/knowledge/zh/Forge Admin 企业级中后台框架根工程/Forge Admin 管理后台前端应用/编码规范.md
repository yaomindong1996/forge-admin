- 业务功能按目录划分：`src/views/*` 放页面视图，`src/components/*` 放可复用组件，`src/api/*` 按领域分包封装 HTTP 请求，`src/store/modules/*` 按领域拆分 Pinia store。
- 跨模块共享能力通过 `src/composables/useXxx.js` 暴露组合式函数，组件与视图统一从 `@/composables` 引入。
- 路由采用 unplugin-vue-router 文件约定式注册，权限与登录态校验集中在 `src/router/guards` 中集中处理。
- UI 样式统一使用 UnoCSS 原子类，全局变量与主题通过 `src/styles/design-tokens.css`、`theme.css`、`variables.scss` 集中维护。
- HTTP 请求统一经 `src/utils/http` 封装的 axios 实例，并叠加 `encrypt-request`、错误弹窗、SSE/WebSocket 等拦截器。
- 测试文件与源码同级放置于 `__tests__/` 目录，使用 Vitest + @vue/test-utils 编写单元/集成测试。
