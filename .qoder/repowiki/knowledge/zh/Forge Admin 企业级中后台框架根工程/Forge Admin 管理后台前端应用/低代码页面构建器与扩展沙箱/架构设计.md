模块按职责划分为四个子目录：
- `designer-core`：核心引擎，`index.js` 聚合 field/layout/business/page/media/widget/zone-action 七类组件 spec，并通过 `spec/registry.js` 的全局 Map 注册表集中管理 105 个统一组件的 type/alias/scope/category；`dnd/protocols.js` 定义拖拽协议，`panel/` 提供属性面板与调色板，`spec/bridge.js` 将注册表转换为画布、表单、列表等场景的 catalog。
- `page/`：页面级设计器组合层，`LowcodePageBuilder.vue` 作为入口在 list/edit 两个 tab 间切换，协调 `ListPageGridDesigner`、`CanvasFormDesigner`、`ComponentPalette`、`ComponentPropertyPanel` 等子组件，并通过 `page-schema.js` 维护 zones（search/table/edit/detail）与 `listGridLayout` 的双向同步。
- `model/`、`domain/`、`publish/`、`preview/`、`shared/`：分别负责 ER 图建模、领域树编辑、发布版本时间线、预览窗格以及运行时规则/CRUD 属性等共享 UI 组件。
- `lowcode-extension/`：用户扩展子系统，`ExtensionSandboxHost.vue` 通过 Web Worker (`extension-sandbox.worker.js`) 以白名单 API（readField/setField/showMessage/triggerAction）运行用户 JS，Worker 内对全局对象进行 harden 并屏蔽 fetch/XMLHttpRequest/eval 等危险能力；`css/scoped-css.js` 与 `runtime/RuntimeScopedStyles.js` 实现 CSS 作用域注入；`extension-code-catalog.js` 集中声明钩子（PAGE_INIT/FORM_CHANGE/BEFORE_SUBMIT/AFTER_SUBMIT/ROW_ACTION）、示例代码与安全边界。
- `lowcode-runtime/`：仅一个薄壳 `LowcodeRuntimePage.vue`，把运行时配置透传给 `CrudPage` 渲染最终页面。
- `page-templates/`：预置 CRUD 模板（SimpleCrud/MasterDetailCrud/TreeCrud），配合 `ChildTableEditor` 生成默认 schema。
依赖方向单向：`page` → `designer-core` → `shared`；`extension` 独立于设计器，仅通过 Worker 通信；`lowcode-runtime` 不依赖设计器，只消费运行时配置。
