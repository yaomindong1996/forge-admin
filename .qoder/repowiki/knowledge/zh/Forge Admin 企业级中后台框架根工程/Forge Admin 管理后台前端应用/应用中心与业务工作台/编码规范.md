- 路由查询参数与本地 ref 双向同步：所有可过滤字段（keyword、status、pageNum、pageSize、suiteCode 等）在变更时调用 `syncRouteQuery` 写入 `router.replace`，并在 `watch(route.query)` 中反向恢复，保证浏览器前进后退与分享链接可用。
- 异步请求使用版本号防竞态：`loadApplications` 等函数通过递增 `applicationRequestVersion` 并在 finally 中判断当前请求是否仍为最新，避免并发或路由快速切换导致的旧数据覆盖。
- 危险操作统一通过 `confirmAction` 包装 `window.$dialog.warning`，集中处理标题、内容、确认文案与回调，缺失 `$dialog` 时降级直接执行。
- 设计器类组件采用 Shell + Slot 模式：如 `BusinessObjectDesignerShell.vue` 提供统一顶栏、侧边导航与主内容槽，具体面板通过 slot 注入，导航项通过 `navPanels` 数组配置。
- 子功能按目录划分职责：`application-workspace/`、`components/designer/`、`components/create/`、`components/publish/`、`components/settings/`、`components/portal/`、`in-app-builder/` 各自聚合相关组件与工具脚本，测试文件放在同级 `__tests__/`。
- UI 交互优先使用 Naive UI 原子组件（`NButton`、`NDropdown`、`NIcon`、`NSkeleton`、`NEmpty`）并配合 CSS 变量（`--n-*`、`--bg-*`、`--text-*`）实现主题适配，而非内联样式。
