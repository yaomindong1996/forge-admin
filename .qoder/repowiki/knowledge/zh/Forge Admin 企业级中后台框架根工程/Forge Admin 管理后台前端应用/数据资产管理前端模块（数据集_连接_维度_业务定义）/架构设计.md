模块按 views / components / api 三层组织：
- 视图层 `src/views/data/` 下每个文件对应一个资源页面（dataset.vue、connection.vue、dimension.vue、business.vue、dataset-category.vue），统一通过内部 `AiCrudPage` 组件声明式绑定 CRUD 路由（如 `get@/data/dataset/page`），并通过插槽自定义表单、详情与工具栏。
- 组件层 `src/components/data/DatasetParamSchemaEditor.vue` 是独立可复用的查询参数编辑器，负责解析 SQL 命名参数、拉取表字段并维护参数 schema 数组，通过 `modelValue` + `update:modelValue` 双向绑定回父表单。
- API 层 `src/api/data/` 中每个资源一个 TypeScript 文件（dataset.ts、connection.ts、dimension.ts、business.ts），集中定义接口类型与基于 `@/utils/request` 的 HTTP 函数；`src/api/business/purchase-order-test.js` 为示例业务 API 文件，沿用相同模式但使用 JS。
依赖方向单向：views → components → api → `@/utils/request`，不反向引用；视图之间相互独立，仅共享全局 UI 组件（Naive UI、SqlEditor、AiCrudPage 等）。
