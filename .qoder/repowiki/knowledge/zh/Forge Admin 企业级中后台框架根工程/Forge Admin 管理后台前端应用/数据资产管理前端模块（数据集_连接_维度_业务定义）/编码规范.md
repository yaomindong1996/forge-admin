- API 文件以 TypeScript 接口定义数据结构（如 DataDataset、DataConnection、DataDimension），并以同名导出函数封装 GET/POST/PUT/DELETE 调用，统一通过 `request.get/post/put/delete` 发起。
- CRUD 页面统一使用 `AiCrudPage` 组件，通过 `api-config` 字符串映射（如 `list: 'get@/data/dataset/page'`）声明后端路由，再配合 `columns`、`edit-schema`、插槽自定义表单与详情。
- 表单字段更新采用 `updateDatasetFormField(formData, fieldKey, value, updateValue)` 这类回调模式，由父容器注入以保持表单状态与校验逻辑集中。
- 列表页顶部统一放置搜索区（NInput + NSelect + 搜索/重置按钮），并通过 `queryForm` 对象聚合筛选条件后调用 `applySearch`。
- 可复用子组件（如 DatasetParamSchemaEditor）通过 `defineProps` + `defineEmits(['update:modelValue'])` 实现 v-model 双向绑定，并在内部用 `watch` 同步 props 与本地 rows。
- 资源 API 文件按领域拆分（dataset.ts、connection.ts、dimension.ts、business.ts），每个文件只暴露该资源的接口类型与函数，避免跨域耦合。
