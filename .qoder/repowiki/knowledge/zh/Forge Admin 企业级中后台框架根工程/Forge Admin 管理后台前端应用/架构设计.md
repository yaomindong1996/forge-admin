以 `src/main.js` 为唯一启动点，按固定顺序初始化：加载运行时加密配置 → 创建 Vue 实例 → 注册 Pinia Store（auth/permission/tab/tenant/user 等）→ 注入 Naive UI 全局 API → 注册自定义指令 → 应用主题配置 → 企微免登 → 挂载 Router → 挂载根组件。各业务子模块（ai_features、lowcode_builder、flow_management、app_center、system_admin、data_management）均通过 `@/api/*` 下的领域 API 客户端访问后端，并通过 `@/store/modules` 共享认证、权限、租户、Tab 等跨域状态；视图层由 `src/layouts/*` 提供多套布局模板（full/normal/bento/nexus/immersive/top-menu 等），由路由守卫根据菜单与权限动态装配。所有页面通过 `unplugin-vue-router` 自动路由注册，配合 `src/router/guards` 中的 auth、permission、tab、page-loading、page-title 守卫完成鉴权与导航控制。构建侧使用 Vite + UnoCSS + ESLint + Vitest，部署脚本位于 `deploy/index.js`，支持 stage/prod 多环境打包与发布。
