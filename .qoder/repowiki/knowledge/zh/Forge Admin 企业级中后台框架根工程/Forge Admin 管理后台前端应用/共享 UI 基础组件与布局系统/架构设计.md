本模块按职责划分为五个子目录，构成应用的基础设施层：
- `components/common/`：无业务依赖的通用 UI 组件（页面壳 AppPage/CommonPage、卡片 AppCard、树 PremiumTree、主题切换 ThemeConfig/ToggleTheme、用户选择 UserSelectPicker、通知增强 NotificationEnhancer 等），通过 `index.js` 统一按需导出。
- `layouts/`：按布局风格划分的多套 Shell，包括 normal、full、simple、top-menu、top-side-menu、bento、immersive、nexus、app-portal、empty 等；每套布局由 `index.vue` 组合 header/sidebar/content，并复用 `layouts/components/` 下的 SideMenu、TopMenuBar、BreadCrumb、MessageNotification、OrgSwitcher、TenantSwitcher、AppTab 等横切组件；`sidebar-menu-context.js` 暴露 `resolveSidebarMenuContext` 供各布局计算当前路由对应的菜单高亮上下文。
- `assets/`：静态资源集中存放，`icons/` 下为 SVG 图标集与 Iconify 动态图标清单 `dynamic-icons.js`，`images/` 存放登录页、Logo、表单图片等。
- `styles/`：全局样式分层——`design-tokens.css`/`variables.scss` 定义设计令牌（颜色、间距、圆角、阴影），`reset.css` 做浏览器重置，`global.css` 提供 page-wrapper/page-header/page-card/status-tag/table-actions 等页面级工具类与 n-data-table/n-tree 精品化覆盖，`animations.css` 与 `mixins.scss` 提供动画与 SCSS mixin。
- `directives/`：以 `setupDirectives(app)` 入口集中注册 v-permission、v-hasPermi、v-loading、v-copy、v-preview、v-watermark、v-table-scroll-enhance 等指令，并将 loadingService 挂载到 `app.config.globalProperties.$loading`。
- `catalog/index.js`：页面模板注册表，将 templateKey 映射到懒加载的渲染组件，并提供 `getTemplateComponent`/`getCatalogList` 两个查询 API。
依赖方向单向向下：layouts 依赖 common 组件与 styles；common 不反向依赖 layouts；catalog/directives/styles 被上层业务页面消费。
