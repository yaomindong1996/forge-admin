- 每个可复用目录（components/common、layouts/components、directives/modules）均提供 `index.js` 作为统一导出入口，对外只暴露命名导出而非默认导出。
- 布局按风格拆分为独立子目录（normal/full/simple/top-menu/bento/immersive/nexus/app-portal/empty），每个子目录以 `index.vue` 作为该布局的装配入口。
- 全局样式通过 `design-tokens.css`/`variables.scss` 中的 CSS 自定义属性（如 `--primary-color`、`--bg-primary`、`--radius-card`）统一管理，组件样式引用这些变量而非硬编码色值。
- 指令采用模块化拆分（每个功能一个 `modules/*.js`）+ `setupDirectives(app)` 集中注册的装配模式，并通过 `app.config.globalProperties` 暴露服务实例。
- 页面模板与图标等资源通过集中式清单（`catalog/index.js`、`assets/icons/dynamic-icons.js`）声明式注册，新增能力只需追加条目而不修改调用方。
- 组件普遍使用 `defineProps` + 具名 slot（如 AppPage 的 `footer` slot）进行扩展，保持单一职责且易于组合。
