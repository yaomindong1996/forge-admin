- 设计器主组件通过 props/xml + emit(change/ready/importStart/importEnd) 暴露统一 API，使 `design.vue` 可在 `DingFlowDesigner` 与 `FlowModeler` 之间切换而不改动上层逻辑。
- 节点类型以常量对象集中声明（如 `NODE_TYPE`、`BUSINESS_PROCESS_NODE_TYPE`），并通过 `createNodeTemplate` / `buildNode` 工厂函数生成默认配置，新增节点需同时更新类型常量与模板。
- 复杂状态与操作通过 Vue 3 Composable 封装（`useFlowDesigner`、`useFlowHistory`、`useBusinessProcessDesigner`），组件仅负责 UI 编排，数据变更经 `commit(next)` 不可变替换。
- 转换器按职责拆分到 `converter/` 下的独立文件（xml-utils、bpmn-to-json、json-to-bpmn、branch-parser、user-task-parser/writer、layout-algorithm），并通过 `index.js` 统一 re-export。
- 属性配置面板采用“配置渲染映射表”模式（`panel/config-renderer-map.js`），按节点类型动态选择对应 `*Config.vue` 组件，避免在单一大组件中写大量 if/switch。
- 所有可执行逻辑均配套同目录 `__tests__/` 单元测试，覆盖 layout-engine、converter、node-card、composables 等关键路径，测试与源码一一对应。
