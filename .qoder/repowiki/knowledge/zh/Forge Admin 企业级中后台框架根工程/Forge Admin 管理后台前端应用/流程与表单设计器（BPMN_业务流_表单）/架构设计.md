模块按职责拆分为四个并列子包，通过 `views/flow/*` 页面作为入口编排：
- `components/bpmn/`：基于 bpmn-js 的 Flowable BPMN 模型器（`FlowModeler.vue`、`BpmnModeler.vue`），封装自定义渲染、小地图、快捷键栏、节点属性面板等，负责传统 BPMN 流程的导入/导出/预览。
- `components/flow-designer/`：自研钉钉风格流程设计器，采用分层架构——`DingFlowDesigner.vue` 为对外门面（兼容原 `FlowModeler` 的 xml/change/ready 接口），内部由 `composables/useFlowDesigner.js` 管理 flowJson 状态与节点/边 CRUD，`canvas/` 提供画布、连线、节点渲染与布局引擎，`converter/` 实现 BPMN XML ↔ flowJson 双向转换（含分支解析、用户任务读写、自动布局），`panel/` 按节点类型注册配置抽屉（`config-renderer-map.js`），`nodes/` 定义各节点卡片，`viewer/` 提供只读查看能力。
- `components/business-process-designer/`：面向“业务流程”的轻量级流程图设计器，以 `business-process-node-types.js` 声明式定义节点类型、端口与默认配置，`BusinessProcessDesigner.vue` + `useBusinessProcessDesigner.js` 管理 schema 与撤销历史，`BusinessProcessCanvas.vue` 负责拖拽添加与渲染。
- `components/form-create/` 与 `components/form-designer/`：基于 form-create 的表单设计与渲染桥接，供流程节点绑定动态表单。
依赖方向单向：`views/flow` → 各 designer → composables/converter/canvas → 常量与工具；转换器与画布层不反向依赖 UI 组件。
