- API 文件按业务域拆分（agent.js、capability.js、provider.js 等），每个函数对应一个后端 REST 端点，并通过 `request.get/post/put/delete` 或 `postEncrypt` 调用。
- 视图页通过 `defineOptions({ name: 'xxx' })` 显式声明组件名，便于调试与错误定位。
- 动态表单字段通过 JSON schema 数组描述，由 `AiForm` + `AiFormLayoutNodes` 渲染，列/搜索条件也采用相同 schema 结构（如 `searchSchema`、`columns`）。
- 字典值统一通过 `useDict(...)` 组合式函数加载，并以 `computed` 映射为下拉选项（如 `publishStatusOptions`、`riskLevelOptions`）。
- 权限控制集中在视图中，通过 `userStore.isAdmin` 或 `permissions.includes('ai:*')` 判断后控制按钮可见性（`visible` 函数或 `v-if`）。
- 通用模态框统一通过 `ref.open({ title, width, onOk, onCancel, onClose })` 命令式打开，并在 `onAfterLeave` 中清理拖拽绑定。
