模块按职责划分为四层：
- 视图层 `src/views/ai/`：以功能域组织页面（agent、capability、knowledge、skill、model、provider、session、crud-generator、lowcode-builder 等），每个子目录对应一个业务页面；其中 `capability/` 下进一步拆出 `components/`（注册、调用引导、在线测试、客户端工作台等弹窗）和 `capabilityCredentialSession.js` 状态共享。
- 通用组件层：`src/components/ai-form/` 是核心动态表单引擎，通过 `AiForm.vue` + `AiFormLayoutNodes.vue` 解析 JSON schema 渲染字段，`config.js` 集中定义 `FIELD_TYPES`、`createField`、`FieldFactory` 工厂方法，并导出 `AiCrudPage`、`AiTable`、`AiSearch`、`AiCustomSelect`、`AiRecordSelectorModal` 等 CRUD 组合组件；`adapters/formCreate.js` 兼容 form-create 格式。`src/components/ai-modal/` 提供基于 Naive UI `n-modal` 的可拖拽、可配置确认/取消回调的通用模态框，通过 `defineExpose({ open, close })` 以命令式方式调用。
- API 层 `src/api/ai/`：按领域拆分文件（agent、capability、provider、session、engine、knowledge、skill、store、media、model-routing、context、lowcode），统一通过 `@/utils` 的 `request` / `postEncrypt` 发起 HTTP 请求，敏感接口使用 `postEncrypt` 加密。
- 依赖方向：视图 → ai-form/ai-modal 组件 → ai API → 全局 utils/store/composables；组件之间无循环依赖，ai-form 内部通过 `index.js` 聚合导出公共 API。
