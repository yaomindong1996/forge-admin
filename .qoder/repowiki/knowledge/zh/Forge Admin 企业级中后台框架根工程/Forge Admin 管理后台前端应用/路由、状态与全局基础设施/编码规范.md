- 路由采用“手动路由数组 + 自动路由合并 + 兜底 404”三段式结构，每个路由统一声明 name/path/component/meta，复杂页面使用懒加载 `() => import(...)`。
- 路由守卫以工厂函数形式封装（createXxxGuard），由 `setupRouterGuards` 集中装配，便于按序组合且单测友好。
- Pinia store 按领域拆分到 `store/modules` 下，通过 `modules/index.js` 统一 re-export，并在 `setupStore` 中启用 `pinia-plugin-persistedstate` 做本地持久化。
- Composables 统一以 `useXxx` 命名导出纯函数，返回包含 ref 状态与方法对象的组合式 API，并通过 `composables/index.js` 集中再导出。
- 主题与样式通过 `config/theme.config.js` 集中定义，并以 `applyThemeConfig` 将配置映射为 CSS 变量（如 `--primary-color`、`--layout-header-bg-color`）注入根节点。
- 字典数据通过 `composables/useDict.js` 的全局 Map 缓存并按 dictType 维度去重并发请求，失败时通过 `Promise.allSettled` 隔离错误并提供重试能力。
