模块按职责划分为五个子目录，构成应用启动期的基础能力层：
- `router/`：`index.js` 通过 `vue-router/auto-routes` 合并自动路由与 `manualRoutes`（登录、SSO、404、工作台、Nexus 等），并基于 `VITE_USE_HASH` 动态选择 Hash/History 模式；`guards/index.js` 统一装配页面加载、权限、标题、标签页四个守卫工厂，形成“入口 → 守卫链”的单向依赖。
- `store/`：`index.js` 创建 Pinia 实例并挂载 `pinia-plugin-persistedstate` 实现持久化；`modules/` 将 app/auth/permission/router/tab/tenant/user 等状态拆分为独立 store，由 `modules/index.js` 统一 re-export，供组件以 `useXxxStore()` 形式消费。
- `stores/`：存放业务级独立 store（如 `demo.js`），不纳入全局 modules 聚合，按需引入。
- `composables/`：以 `useXxx` 命名导出纯函数式逻辑（字典、表单、菜单、模态、水印、用户、流程、CRUD 生成器等），`index.js` 作为统一入口；内部通过 `@/utils/request` 访问后端，对外仅暴露响应式状态与操作方法。
- `config/`：`theme.config.js` 集中定义多布局主题色板并通过 `applyThemeConfig` 写入 CSS 变量；`whitelist.config.js` 维护免登录路径白名单，被路由守卫引用。
- `constants/`：静态常量（如字典选项）。
- `plugins/`：UnoCSS 自定义 preset `responsiveFontUnifiedPreset`，通过 `--font-scale` CSS 变量实现统一缩放字体。
- `copy/dict/`：兼容旧版 Vue2 风格的 Dict 插件（mixin + 生命周期钩子），保留给存量代码使用。
依赖方向：router 守卫依赖 config 白名单；所有 store/composables/plugins 均向下依赖 `@/utils`，不被业务视图反向依赖。
