本模块按业务域划分目录，每个子目录对应一个独立路由页面或一组相关页面：
- `system/`：核心系统管理能力，包含扁平的 CRUD 页面（menu.vue、role.vue、dictType.vue、user.vue、tenant.vue 等）以及按能力拆分的子目录——`collaboration/`（企业微信/钉钉/飞书连接、同步批次、问题单、映射、投递、回调事件，通过权限码控制 tab 可见性）、`job-config/`（任务配置表单分节组件 JobBasicSection/JobScheduleSection/JobExecutionSection 及权限/表单契约）、`cache/`（托管缓存策略）。大量页面复用 `@/components/ai-form` 中的 `AiCrudPage`，通过 `api-config`、`search-schema`、`columns`、`edit-schema` 声明式驱动表格与表单。
- `message/`：消息中心，`manage.vue` 基于 AiCrudPage 展示消息列表并弹出发送测试弹窗；`messageConfig/` 用 n-tabs 拆分短信与邮件配置子组件。
- `generator/`：代码生成器，`table.vue` 作为入口，通过 `defineAsyncComponent` + `delay` 懒加载 `AiSchemaModal`、`CodePreviewModal`、`ColumnConfigModal`、`ImportTableModal` 四个弹窗组件以减小首屏体积。
- `report/design.vue`：报告子系统 SSO 嵌入壳，通过 `createSsoTicket` 获取票据并以 iframe 或 `window.location.replace` 方式打开目标子系统。
- `workspace/index.vue`：工作台 Shell，左侧导航数组驱动 `/workspace/{summary,todo,done,started,cc}` 子路由，使用 `<RouterView />` 渲染具体子页。
- `leave/`：请假申请与审批列表，使用 Naive UI 原生组件组合，状态机驱动操作按钮显示。
- `nexus/role-management.vue`：独立的 Identity & Roles 管理页，采用自定义 bento grid 布局而非通用 CRUD 框架。
依赖方向单向向下：各页面仅依赖 `@/api/*`、`@/components/*`、`@/composables/*`、`@/store` 和 `@/utils`，不互相引用，跨页面协作通过共享 API 与 store 完成。
