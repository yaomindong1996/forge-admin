### 低代码设计器统一改造
- 定义：指 forge-admin-ui 中表单设计器与列表设计器的左侧物料面板、右侧属性面板、组件注册表与渲染器进行统一的工作：两侧共享同一份组件合集（去容器包装节点后约 101 项）、禁用态同显而非隐藏、spec 的 propsSchema 与渲染器消费 key 对齐、属性面板改为两列紧凑网格布局。
- 别名：designer unification、B1/B2/C1/C2/C3、低代码组件统一

### 统一组件注册表
- 定义：designer-core/spec/registry.js 维护的单一事实源，集中管理所有低代码组件的 ComponentSpec（type、label、group、scope、category、layout、meta 等），供表单、列表、页面三类设计器共同消费，替代各自独立的 catalog。
- 别名：component registry、统一注册表

### 桥接层（Bridge）
- 定义：designer-core/spec/bridge.js 提供的纯函数集合，将统一注册表转换为存量消费方（表单画布、列表区块、页面挂件、Zone 目录）所需的旧格式数据，使历史代码无需大规模改动即可接入新注册表。
- 别名：bridge.js、toFieldPaletteGroups、toListPageBlockCatalog、toPageWidgetCatalog

### 规格键（propsSchema key）
- 定义：组件 spec 中声明的属性键名（如 grid 的 cellMinHeight、alignItems、justifyItems、showCellBorder、cellBackground 等），必须与渲染器实际读取的 key 完全一致，否则属性修改不会生效。本轮修复了多处 spec key 与渲染器不一致的问题。
- 别名：spec key、属性键、consumption key

### 属性面板（SpecPropertyPanel）
- 定义：designer-core/panel/SpecPropertyPanel.vue 是低代码设计器右侧属性编辑面板的统一实现，本轮重写为两列紧凑网格布局，布尔开关内联一行，长文本/JSON 占满整行，section 分组标题分节，并补充 tooltip、placeholder 与 disabled 透传。
- 别名：SpecPropertyPanel、属性编辑面板、右侧面板

### 物料面板（UnifiedComponentPalette）
- 定义：designer-core/panel/UnifiedComponentPalette.vue 是表单与列表设计器左侧组件拖拽面板的统一实现，支持 scope='ALL' 显示同一份组件合集，并对不支持当前画布的组件以禁用态+原因徽标展示，拦截拖拽与点击。
- 别名：UnifiedComponentPalette、左侧面板、组件抽屉

### 列表画布待支持类型
- 定义：bridge.js 中 LIST_CANVAS_PENDING_TYPES 定义的列表渲染器暂无分支的类型（table、collapse、formSectionTitle），这些组件在列表设计器中以“待流式画布支持”的禁用态呈现，后续由流式画布放开。
- 别名：LIST_CANVAS_PENDING_TYPES、待流式画布支持

### Zone 专属组件
- 定义：bridge.js 中 PALETTE_ZONE_ONLY_TYPES 定义的旧 LowcodePageBuilder zone 画布专属操作组件（query-set、custom-query、import-button、export-button、add-button、reset-button），在新表单/列表画布中不支持直接拖入，仅以禁用态提示“页面画布专属”。
- 别名：PALETTE_ZONE_ONLY_TYPES、zone 操作组件

### AiFormItem
- 定义：表单预览入口组件，负责根据字段 spec 渲染具体表单控件（如 n-slider），是 Slider 预览崩溃的触发点；修复方式为在 resolveOptionValue 旁增加 slider 值归一化，避免 range+null 导致 map 报错。
- 别名：AiFormItem.vue、表单预览组件

### GridBlockRenderer
- 定义：列表区块渲染器，负责将列表侧 spec（grid-layout、box-layout 等）渲染为实际表格/布局 DOM；本轮修复了其消费 key 与 spec propsSchema 不一致的问题（如 alignItems、justifyItems、showCellBorder、cellBackground 等）。
- 别名：GridBlockRenderer.vue、列表渲染器

### ForgeFieldShelf
- 定义：表单设计器左侧物料面板的接入组件，本轮接入 UnifiedComponentPalette 的 scope='ALL' 模式与共用过滤函数 isPaletteUnionSpec，使表单侧与列表侧显示同一份组件合集。
- 别名：ForgeFieldShelf.vue、表单物料面板

### ListPageGridDesigner
- 定义：列表设计器主页面，本轮接入 UnifiedComponentPalette 的 scope='ALL' 模式，并使用 bridge.js 导出的禁用原因函数（字段类→由表单区块承载、表格/折叠/分隔线→待流式画布支持、表单专属→表单画布专属）替换原有白名单逻辑。
- 别名：ListPageGridDesigner.vue、列表设计器
