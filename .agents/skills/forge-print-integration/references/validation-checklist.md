# Print Integration Checklist

- [ ] Source type / binding matches page-follow vs standalone.
- [ ] CODE path: Provider registered; `code()` stable; authorize + load implemented.
- [ ] Catalog fields match schema / designer columns (incl. relation FKs).
- [ ] Runtime load respects tenant + datascope.
- [ ] Lowcode publish not gated on incomplete print catalog.
- [ ] Preview/PDF client red lines checked if touching print UI.
- [ ] New enums/dicts synchronized if execution events changed.
